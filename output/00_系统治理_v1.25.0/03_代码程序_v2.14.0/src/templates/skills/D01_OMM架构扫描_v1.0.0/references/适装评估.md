# 适装评估

- 结论：条件安装
- 建议范围：项目级试装
- 来源仓库：`oh-my-mermaid/oh-my-mermaid`
- 来源路径：`skills/omm-scan`

## 六项评估

- 新增知识价值：较高。补充 `.omm/` 架构文档生成、递归 Mermaid 视角拆解和 `omm write` 工作流。
- 能力重叠度：中等。和通用代码阅读、Mermaid 绘图有重叠，但提供了可落盘、可查看的固定流程。
- 运行环境耦合度：中等偏高。依赖 `oh-my-mermaid` 的 `omm` CLI 与 Node/npm 环境。
- 流程负担：中等。架构扫描是重流程，必须由用户明确触发。
- 触发范围：可控。只绑定 `omm scan`、架构扫描、刷新架构图和生成 `.omm/` 文档。
- 上下文成本：可控。入口薄化，原始长说明保留在 `references/原始技能说明.md`。

## 简短结论

适合保留为项目级试装 skill，用于需要持续维护架构图谱的代码仓库；不应作为普通代码问答的默认流程。
