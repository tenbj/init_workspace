# 原子拆解技能项目理解

## 项目定位

`.temp/2026-05-11/atomic-decomposition-skill` 是一个 Codex Skill 项目，核心能力是把一段混乱、含糊、多目标、带情绪负荷的表达，拆成可观察、可验证、可执行的研究与行动系统。

它不是普通建议模板，也不是医疗、减肥或内容创作的直接方案生成器；它更像一个“问题分离器”：先把事实、感受、判断、假设、目标、约束拆开，再生成原子课题、优先级、最小实验、记录模板和小红书内容选题。

## 核心流程

1. 保留原意：中性复述用户原始表达，避免道德化或过度解释。
2. 信息分类：把内容拆成事实、感受、判断、假设、目标、约束、行动意图、内容/商业意图和风险信号。
3. 模块分层：按身体健康、睡眠节律、精力情绪、减脂饮食、活动运动、执行力、内容创作、小红书定位、商业化、数据复盘等模块归类。
4. 原子课题化：每个课题只研究一个变量或一个因果关系。
5. 优先级排序：P0 健康安全，P1 睡眠精力，P2 减脂基础，P3 内容系统，P4 商业化。
6. 低能量执行：用最低配、标准配、满血配三档行动，避免给低能量用户增加压力。
7. 内容化：把“真实问题、拆解方式、最小实验、观察结果、给同类人的提醒”转成小红书选题。

## 文件结构理解

| 路径 | 作用 |
|---|---|
| `SKILL.md` | Skill 主规则，定义触发场景、边界、安全规则、输出契约和拆解算法。 |
| `README.md` | 项目简介、适用场景、安装方式和脚本用法。 |
| `INSTALL.md` | 面向用户的安装验证说明。 |
| `references/decomposition_framework.md` | 原子拆解方法论说明，强调一题一变量、一层一目标、先稳定后优化。 |
| `references/output_schema.json` | 机器可读 JSON 输出结构。 |
| `scripts/decompose_atomic.py` | 轻量初稿生成脚本，基于关键词把输入拆成组件、模块、课题、内容管线和日志模板。 |
| `assets/templates/*.md` | 原子课题卡、每日日志、每周计划、小红书帖子模板。 |
| `examples/*` | 减肥 + 小红书 + 低能量场景的输入和示例输出。 |
| `agents/openai.yaml` | Skill 展示名、简短描述和默认提示词。 |

## 适合场景

- 减肥、身体恢复、低能量状态记录。
- 复杂人生问题拆解。
- 自我提升计划拆解。
- 账号定位、内容选题、创作者项目拆解。
- 商业想法拆成可研究问题。

## 安全边界

- 不诊断医疗问题。
- 遇到持续疼痛、严重疲劳、失眠、头晕、胸痛、饮食障碍、自伤等信号时，必须建立 `健康风险/就医排查` P0 课题。
- 不开药、不推荐补剂、不设计极端饮食、断食或激进运动。
- 商业化不得压过健康安全与基础稳定。
- 不把假设写成事实。

## 页面介绍设计要点

HTML 页面突出这个项目的三个核心价值：

1. 把混沌表达拆清楚：从情绪化、多目标文字中分离可处理信息。
2. 把问题变成实验：每个原子课题必须可观察、可验证、可行动。
3. 把实验变成内容：将研究过程沉淀为每日记录、小红书选题和长期复盘素材。
