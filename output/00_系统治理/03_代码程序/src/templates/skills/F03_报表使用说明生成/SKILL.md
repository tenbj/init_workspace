# 报表使用说明生成

## 这项技能解决什么问题

- 将报表截图、操作资料和指标口径整理为业务用户可执行的使用说明。
- 默认交付同源 Markdown 与离线单文件 HTML，支持侧边目录、章节导航和打印。

## 先读哪些本地知识

- 先读 `references/本地适配说明.md`，确认路径、依赖及来源授权的适用范围。

- 先读 `references/内容编写规范.md`，按实际功能选择章节，确定已知事实与缺失项。
- 写文档前读 `references/输出契约.md`；使用 `assets/使用说明模板.md` 作为可裁剪起点。
- 用户明确指定格式、范围或流程时，以用户要求为准。

## 固定动作

1. 识别目标报表、读者及素材，区分报表自身、宿主系统和说明样例。核对同名控件所在页面。
2. 建立简短素材核对表：事实、来源位置、已核实/待确认/不适用。针对影响正确性的缺口询问，同时编写有依据的内容。
3. 按规范生成适用大纲与 Markdown。资料充分时直接完成；用户要求先确认时才等待确认。未知功能不能当成“不适用”。
4. 操作写清用途、入口、步骤、结果及注意事项；指标保留定义和证据。关键操作或口径未核实时标为草稿。
5. 按 `references/生成与验收.md` 调用 `scripts/build_manual.py`，从 Markdown 生成 HTML，再核对导航、表格和两份正文一致性。
6. 交付文件路径、文档状态及关键待确认项。工作区输出按 B04 定位子项目，修改按 B02，收尾按 B03 与 B08。

## 什么时候再读本 skill 的 references

- 裁剪大纲、写指标、处理素材冲突或 FAQ：读 `references/内容编写规范.md`。
- 确定最终件、中间件和失败交付：读 `references/输出契约.md`。
- 运行生成器、处理图片和打印、执行验收：读 `references/生成与验收.md`。
- 审查 Skill 能力结构：读 `references/结构融合索引.md`。

## 边界

- 截图可以证明可见标签和位置，不能单独证明公式、权限、联动范围、默认值和导出限制。
- 不把样例平台、店铺、币种、TOP N 等固化成所有报表必备功能。
- 不承诺解析任意 PBIX 等专有格式；无法读取时使用可读导出资料并说明缺口。
- 本技能生成文档；不隐含数据库访问、生产报表修改、网站部署或宿主系统集成授权。
