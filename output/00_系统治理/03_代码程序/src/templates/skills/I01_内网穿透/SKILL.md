# I01_内网穿透

## 这项技能解决什么问题

- 新增或调整现有 FRP TCP 代理，重启 Windows NSSM 服务并交付经过公网验证的入口。

## 先读哪些本地知识

- 先读 `references/执行流程.md`，定位本机环境时读 `references/本机环境.md`。
- 按 B08 记录进度，工作区修改按 B02 备份，结束按 B03 记录脱敏结果。

## 固定动作

1. 核对 NSSM 实际使用的程序、配置和目录，确认本地服务可访问。
2. 按原格式选择代理名及未占用端口；默认公网端口小于15000。
3. 用 `scripts/proxy_config.py plan` 查看脱敏计划，再用 `apply` 备份、校验并写入配置。
4. 必要时精确适配应用 Host 与同源访问；按授权执行 `nssm restart <服务名>`。
5. 核对代理启动日志、公网首页和健康接口，必要时用真实浏览器确认数据加载，再交付URL。

## 什么时候再读本 skill 的 references

- 调用脚本、回滚及处理端口拒绝、Host 400、页面/API故障时读 `references/执行流程.md`。
- 查询本机 FRP、NSSM 和拾序样例时读 `references/本机环境.md`。

## 边界

- 已授权配置和重启直接执行，不因技能重复问确认；仅询问缺失的必要信息。
- 不展示、搬运或改写认证秘密，不修改无关代理；外部配置备份留原文件同目录。
- 支持已有FRP及Windows NSSM的TCP代理；安装、服务端配置及其他协议需明确扩大范围。
- 服务重启成功不等于公网成功；失败必须保留诊断和恢复入口。
