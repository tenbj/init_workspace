# 本机环境定位

本技能不内置发布者的机器路径、域名或认证配置。优先从用户当前输入及已有会话获取环境，再核对实际服务。

| 项目 | 定位方法 |
|---|---|
| FRP程序 | `nssm get <服务名> Application` |
| 配置路径 | `nssm get <服务名> AppParameters` 中的 `-c` 参数 |
| 工作目录 | `nssm get <服务名> AppDirectory` |
| NSSM程序 | `Get-Command nssm` 或用户提供的安装路径 |
| 日志 | 从原配置log.to获取；相对路径以服务工作目录为准 |
| 公网域名 | 用户提供或已有会话确认的域名 |
| 端口约束 | 默认小于15000，核对原代理及服务器允许范围 |
| 目标应用 | 用户指定本地服务，先验证首页/健康接口 |

示例代理：`demo-home`，127.0.0.1:8765 → 11865；公网示例为 `http://example.com:11865/`。这些是占位示例，不是预先绑定的部署目标。

认证参数只从原文件读取，不在技能存副本。部署每个应用时核对各自Host白名单、同源API和健康接口；经验证的具体环境记录到本地项目文档，不随公共技能分发。
