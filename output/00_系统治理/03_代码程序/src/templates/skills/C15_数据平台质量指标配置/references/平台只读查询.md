# 平台监控记录只读查询

平台 MySQL 属于数据平台元数据库；本工作区“数仓”专指 Doris。查询平台监控列表或历史不使用 C02，也无需启动浏览器配置流程。

## 当前连接路径

- 连接 ID：`mysql.dataplatform.reader`。
- 清单：工作区 `.envs/catalog.json`；配置：`.envs/mysql.dataplatform.reader.env`。
- 通过 `.envs/env_manager.py route mysql.dataplatform.reader` 获取路径，用 `check` 检查本地完整性。只有路径查询需求时不读值、不联网。
- 实际查询已获授权时，优先 `python .envs/env_manager.py run mysql.dataplatform.reader -- python <只读查询脚本>`；也可在进程内调用 `load_connection(workspace, 'mysql.dataplatform.reader')`。使用 `MYSQL_HOST`、`MYSQL_PORT`、`MYSQL_USER`、`MYSQL_PASSWORD`，必要时在内存解析 `MYSQL_JDBC_URL`。不得输出完整连接串或凭据。
- 使用 MySQL 驱动独立连接；先检查授权库、目标表结构和状态编码。连接名 reader 不是权限已核验的证明，仅执行 SELECT/SHOW/DESCRIBE 等只读查询。

## 列表口径

已有源码线索是 `dmp_manage.dmp_govern_index`（指标与最新状态）和 `dmp_manage.dmp_govern_index_monitor_record_r`（历史记录）。以实际表结构和权限为准，不猜字段和枚举。先确认负责人 ID、租户/有效状态、监控启用字段和异常结果编码，再筛选。

“当前最新结果异常”不限制为今天。由历史表重建时先取每个指标最新一次，再筛异常；“今日出现过异常”是另一查询。展示监控时间和查询时间，防止把旧异常当今天新发生。

新连接配置缺失时不回退 `input/.env` 的 Doris 配置，不要求用户重复填写已经登记的配置。网页登录入口与数据库连接是两类认证；MySQL 可用不代表网页登录入口已经迁移。平台写入与运行仍遵守 C15 原有流程和授权范围。
