# 浏览器识别与恢复

## 会话入口与工具

优先发现当前可用的浏览器工具（枚举页面、快照、点击、填写、脚本求值、截图）。本平台曾使用 Chrome DevTools 工具；工具名称和参数以当次可用定义为准。工具缺失或无法接管窗口时，说明当前限制并请用户提供接管/打开窗口的操作帮助，不自行安装不相关插件。

默认平台：`https://data-platform.example.invalid`。模型页面路径 `/dap/market/manage`，质量指标路径 `/dmp/quality/index`。这些是导航线索，仍需同时验证标题和页面内容。不要把浏览器可访问性等同于已登录或有写权限。

1. 列出页面，选匹配站点与用途的页面；存在多个同路由页面时核对筛选、弹窗和目标上下文，不能任取第一个。
2. 没有目标页面时按工具能力打开已知地址；有登录页且用户已授权复用备用入口时，先在授权记录中定位准确地址，剔除自然语言标点，隐藏凭证参数，访问后等待并检查登录状态；不能仅凭导航成功判登录成功。仍未恢复时请用户登录，收到回复后重新取快照。备用入口参数不得写入Skill或业务产物。
3. 每次调用显式使用本次发现的 pageId。点击导致新标签/窗口时，重新列页面并核对标题、URL、目标模型上下文。
4. 刷新、查询完成、切换选项卡、关闭弹窗后重新获取快照；旧 UID 不得继续复用。
5. 中断恢复先读取 B08 checkpoint，再用平台当前状态核对；已保存先检索，已触发运行先查最新记录，不按历史步骤盲目重放。

## 定位优先级

查看海豚时从正确模型→关联ETL→跳转工作流进入，核对目标并复用会话。侧栏独立入口或猜测直链出现登录页时先纠正导航；正确入口仍确实需要登录才请用户处理。

| 顺序 | 方法 | 条件 |
|---|---|---|
| 1 | 最新快照中的名称、角色、标签与 UID | 在当前活动弹窗/目标行内唯一命中 |
| 2 | 读取 DOM 属性、相邻标签、提示文本 | 用于快照未暴露的自定义图标与只读输入框 |
| 3 | 基于刚观察到的 DOM 执行精确定位/点击 | 必须检查候选唯一、可见、所属容器；记录点击后状态 |
| 4 | 当前截图辅助判断 | 坐标仅限此刻截图且布局未变；一次操作后重新观察，禁止跨窗口复用坐标 |

每一步遵守“观察 → 判断唯一对象 → 操作一次 → 等待后置状态 → 回读验证”。找不到或命中多项时，不执行变更。

行匹配用技术表名/指标名所在单元格的完整值，加数据域、连接、层级交叉核对；不能仅用整行 includes 模糊匹配。例如“广告投放”不能误命中“广告投放报告”。允许子元素拼接后的单元格文本做 trim；同名模型须进一步核对技术表或当前观察到的模型标识。

## 自定义图标与浮层

- 模型“更多信息”曾有 `<iconpark-icon>`；快照可能完全看不到它们。读取目标行中实际可见图标的属性和提示，确认质量指标含义后操作。
- 曾观察到模型质量入口图标名 `camera-four`，质量列表“更多”为 `hamburger-button-fai3dgln`、执行为 `right-one`、新增为 `newlybuild`。这些只作线索，不能脱离现场菜单/提示/位置验证使用。
- 用户说的“第四个图标”指第四个可见图标；隐藏权限图标也可能存在于 DOM，不能直接 `children[3]`。图标布局变化时重新识别或询问。
- 点击“更多”后确认出现“配置监控 / 编辑指标 / 删除指标”菜单。仅悬停不一定展开。
- 下拉选项可能挂在 body 下且虚拟滚动；先确认当前打开的是哪个控件，再按完整文字定位实际可见选项。getClientRects 非空不能证明选项在滚动视口内，必要时滚动后重新快照。
- 曾发生工具点击滚动外选项误选其他连接。每次选择后回读标签，必须是完整值“跨境电商”，不是“旧-跨境电商”“临时-跨境电商”或“业务-OMS系统”。
- 同名“确定”按钮必须限定当前活动弹窗；不得点击背景弹窗或全页第一个匹配。

## 输入与 SQL 完整性

优先用工具的填写操作触发组件事件；确需脚本输入时按实际组件结构设置并触发所需 input/change，再回读。不要篡改 Vue 内部状态代替正常交互。

只读的“指标说明”“数据模型”“自定义内容”通常需要点击打开子弹窗，不能强行解除 readonly。SQL 从本地文件完整读取、填到“策略内容”的多行编辑器；不通过 shell 字符串拼接 SQL。

Chrome DevTools evaluate_script.args 在此工具中用于元素 UID；不得把 SQL 文本作为 UID 参数。传递字面数据时按工具真实接口处理，可在 JavaScript 函数文本中嵌入 JSON.stringify(sql) 形成字符串字面量；这不是 shell 转义，不能将其照搬到命令行。

保存后读取重开的 SQL 多行编辑器 value 或详情全文 textContent。列表单行预览可能压平换行，不能据此认定 SQL 已损坏。只允许 CRLF/LF 标准化后比较；不得任意去注释、截断、trim 或折叠空白来掩盖不一致。大响应截断时分段提取或本地保存全文；不能把可见前缀当作全文已验证。

## 等待和求助

查询/保存后先看加载状态、弹窗状态和目标行，不把刚出现的“暂无数据”当成最终不存在。短间隔重新取证，一般每 5～10 秒一次；每 60 秒至少更新用户进度。单次等待不超过 60 秒。

同一失败动作最多做一次基于新证据的恢复（如重新快照、滚动、清除错误筛选），不能原样循环点击。约 2 分钟仍无进展，或碰到未知控件/权限/同名冲突时，立即提具体问题。例如：“当前在配置监控的模型选择框，两个广告投放分别位于广告域和运营中心，技术表信息未显示，应从哪里查看技术表名？”

保存超时先查询是否已创建，运行超时先查监控历史/新时间，未证明前次未提交前禁止重试提交。已知长任务可继续有上限地等待，并询问用户正常耗时。留下当前 URL、目标、最后成功步骤、已观察状态和待解问题；不要只回复“失败”。
