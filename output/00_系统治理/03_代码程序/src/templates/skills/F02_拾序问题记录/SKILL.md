# 拾序问题记录

## 这项技能解决什么问题

- 把用户原文整理为拾序问题，支持逐条或批量录入。
- 由AI定义开放分类，并在保存后核对真实记录。
- 区分人类发起者、实际录入的AI身份、工具及本次模型，保存不可变的创建快照。

## 先读哪些本地知识

- 每次执行先读 `references/录入与分类规则.md`。
- 新增问题前读 `references/创建身份与模型规则.md`，确认来源依据。
- 调用工具前读 `references/MCP调用流程.md`，确认应用和Python环境。
- 按 B08 记录进度，工作区文件按 B02 备份，收尾按 B03 记录增量。

## 固定动作

1. 保留问题原意，提取标题和已提供背景，先定义分类。
2. 检查健康与相似问题；已有分类只是参考，不限制新增分类。
3. 优先调用已连接的拾序MCP；未注册时用 `scripts/shixu_mcp.py` 连接stdio。
4. 新建时先list_identities复用已确认的身份；确需新增则单独持久化create_identity请求并回读。每条问题显式传creation及本次modelInfo，不猜测人员或模型。
5. 每次写入前读取版本并持久化完整请求；使用create_issue或update_issue，未知结果沿用原请求重试。更新不改创建来源。
6. 保存后get_issue回读，核对编号、内容、分类、状态及六项创建快照；批量逐条处理、逐条记录结果。
7. 只向用户报告已核对的结果；失败项保留可恢复请求和下一步。

## 什么时候再读本 skill 的 references

- 分类不明确、用户表达情绪化、疑似重复或输入多条问题时，读录入与分类规则。
- 服务定位、请求字段、重试、冲突、脚本参数和实际调用时，读MCP调用流程。
- 人员代录、同名身份、AI切换模型、模型未知或旧请求重放时，读创建身份与模型规则。

## 边界

- 不编造背景、影响或解决依据；新增默认待梳理，缺少紧迫性依据时优先级中。
- 仅在用户要求记录或修改时写入；普通讨论不自动变成拾序问题。
- 不直接写数据库，不删除问题、不改变业务状态、不自行启动或重配服务。
- 不声称应用已实现自动AI分类；分类由调用本技能的AI判断。
- actor仅为审计标签，不能代替creation；不把示例姓名或模型当作当前事实，不自动修改已有身份档案。
