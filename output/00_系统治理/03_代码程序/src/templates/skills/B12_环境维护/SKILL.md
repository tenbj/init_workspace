# B12_环境维护

## 这项技能解决什么问题

- 将账号密码、API key、token、secret及私钥统一维护在根目录 `.envs/`。
- 给主AI、agent、subagent返回连接ID对应的精确文件路由和所需变量名，不返回秘密值。

## 先读哪些本地知识

- 按 `.system/standards/环境管理标准.md` 判断数据归属；已经掌握本轮标准时不重复加载。
- 只查路由时读 `references/精确路由.md`；新增、更新或恢复时读 `references/维护流程.md`。

## 固定动作

1. 区分“获取路由”和“维护凭据”，锁定服务、环境、权限身份与所需变量/密钥名。已有明确连接ID不扫描其他环境；无法唯一定位时只澄清缺失项。
2. 获取路由：执行 `scripts/environment.py route <连接ID>`，按需要附加 `--variable` 或 `--secret-file`；只将返回的对应文件路径、变量名交给调用方。路由成功即结束，不再读取真实文件或测试连接。
3. 维护：元数据修改前执行 B02；真实值通过本机指定源文件导入 `.envs/<连接ID>.env`，私钥等文件导入 `.envs/keys/<连接ID>/`。更新已有值先生成受保护的专用备份；具体命令见维护分册。
4. 按维护范围检查变量或文件到位，输出脱敏结果；按 B03/B08 记录连接ID、操作与状态，不保存真实值。业务连接测试仅在任务需要且已授权时执行。

## 什么时候再读本 skill 的 references

- 路由选择、最小读取与agent交接：`references/精确路由.md`。
- 注册、写入、替换、加密恢复和平台差异：`references/维护流程.md`。
- 交付字段和验收范围：`references/输出契约.md`；结构入口：`references/结构融合索引.md`。

## 边界

- 不整目录读取.envs，不打印真实文件、密码、API key、私钥、secret或认证头；真实值不进入Skill、业务源码、output、memory和普通history。
- 不因调用方是主AI、agent或subagent而扩大读取范围；明确子项时不返回同连接的其他变量/密钥路由，不自动改用其他环境。
- 不将路由请求升级为读取凭据、轮换、删除、联网或权限扩张。保护不可用时保留原值并返回具体状态，不降级成明文历史备份。
