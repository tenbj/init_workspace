# 目录与分层规则

## 九章目录及职责

默认一个模型一份使用说明，对应一张表或一个视图。批量任务按模型分别出文档，必要时增总索引；不把整座数仓规范写进单表说明。

九章一级标题保持稳定；二级标题可按分层替换，不适用项说明原因，缺失项标待确认，冲突列出双方依据。模板见 `../assets/模型使用说明模板.md`。

| 章 | 必须解释的内容 |
|---|---|
| 1. 模型概述 | 标识、环境、分层职责、模型类型、物理实现、用途、不适用场景和有据可查的替代模型 |
| 2. 数据范围与粒度 | 覆盖业务/时间范围、一行的业务含义、业务键、技术键、重复定义、多粒度区分字段 |
| 3. 字段与业务口径 | 全部当前可见字段的名称/类型/释义/角色/来源依据；枚举、指标公式及单位、币种、NULL/0/空串/特殊值 |
| 4. 数据形成规则 | 上游依赖，以及影响使用的过滤、去重、状态判定、映射、分摊和计算；不逐段翻译所有CTE |
| 5. 时间与更新机制 | 时间字段与时区、周期与延迟、完整性、增量/覆盖/快照/删除、历史保留与回补重算 |
| 6. 查询与关联规范 | 必选与有据的默认条件、聚合去重规则、关联方向/完整键/基数/有效期、查询权限与性能约束 |
| 7. 典型使用示例 | 业务问题、参数、只读SQL、输出粒度、结果解释、验证状态、校验方法和错误用法 |
| 8. 数据质量与使用限制 | 已知异常缺失、检查与对账口径、覆盖范围、指标和结果解释边界 |
| 9. 依据、版本与待确认事项 | 代码/配置/数据证据索引、适用版本与变更、缺口与冲突及其对使用的影响 |

第 3 章回答“是什么”，第 4 章回答“怎样形成”，第 6 章回答“怎样使用”；同一逻辑只在主章节展开，其余引用。第 9 章不能删掉或用“详情见源码”代替证据索引。

字段多时可按维度/标识/时间/事实分表，仍覆盖全部已取得字段；无法取得结构时明确覆盖不完整。指标写清统计对象、条件、分子分母、去重对象、时间窗口和可加性；没有指标的模型无需凑指标。

## 分层决定重点

实际分层职责以项目资料为准；表名前缀只是线索。DMT 若无定义则写“主题层（暂按此理解，待确认）”，不能据此宣称职责已确认。

| 分层 | 第3～6章需要展开 | 第4章二级标题参考 |
|---|---|---|
| ODS | 源对象与映射、采集过滤、增量依据、重复事件、删除同步、源端对账；无业务指标可说明不适用 | 来源与采集对象；采集范围与过滤；映射与格式转换 |
| DIM | 实体/版本键、编码统一、属性层级、有效期与当前版本、历史关联、未知成员 | 属性来源；实体识别与编码；归并分类与层级 |
| DWD | 事件粒度、清洗去重、状态与有效范围、维度补充、事实含义 | 上游依赖；清洗去重与有效判定；事实生成与维度补充 |
| DWS | 汇总维度、时间窗口、范围、公式、去重计数与二次聚合限制 | 输入明细范围；汇总维度与窗口；指标计算与特殊处理 |
| DMT | 主题边界、多过程整合、统一维度、并存口径、模型选择与关联 | 主题输入；多模型整合；主题口径与派生 |
| ADS | 应用对象、固定筛选、默认口径、排名分母、参数、输出解释 | 应用输入；筛选与结果计算；展示字段与输出 |

不新增一章重复写分层差异。下层已有说明可引用，但关键使用限制必须在本模型正文可见。

## 模型类型补充必答项

| 类型 | 必须说清 |
|---|---|
| 事务明细 | 事件/行的含义、撤销与冲正、业务状态、重试与重复、事实金额和统计日期 |
| 周期快照 | 截止时点、快照周期、缺快照处理、期末值选取；库存/余额等沿时间是否可加 |
| 累积快照 | 一行生命周期、里程碑时间、持续更新和终止状态；当前记录与历史状态能否重建 |
| 历史维度 | 业务键与版本键、有效期端点、当前标记、事实时点关联、重叠/缺口/未知成员 |
| 汇总 | 完整分组维度、窗口边界、去重对象、去重计数能否再加；比率按分子分母重算的条件 |
| 关系映射 | 关系方向、一对多/多对多、唯一匹配条件、有效期、冲突优先级、避免重复计数 |

模型可能兼具多种类型，组合适用项，不强行只选一个。类型判断没有依据时标推断并说明依据。不要从数值类型推定 SUM 合法；金额可加也要确认币种、粒度、状态和时间口径一致。
