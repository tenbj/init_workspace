# 脚本使用说明

本文件只说明“怎么最快把脚本跑起来”。执行 F01 时先读这里，只有脚本报错或需要改能力时才读源码。

## 入口选择

| 场景 | 推荐入口 | 原因 |
|------|------|------|
| AI 默认下载在线表格 | `download_alidocs.py` | 无需 npm 依赖，支持 `--validate-only`、超时参数和显式 profile/download 目录 |
| 已确认 Node 可用 | `download-alidocs.mjs` | 与 Python 版本同一套导出思路，适合对比验证 |
| PowerShell 用户手动运行 | `download-alidocs.ps1` | 只是 Node 入口的薄包装，不是首选自动化入口 |
| 只校验已下载 `.xlsx` | `download_alidocs.py --validate-only` | 不打开浏览器，最快确认文件有效 |

## 路径规则

- 默认从工作区根目录 `F:\Projects\workspace` 执行命令。
- `--output`、`--download-dir`、`--profile-dir` 优先使用绝对路径，避免脚本相对路径绕到 skill 内部目录。
- 输出文件放到成果目录：`output/<当前子项目>/03_代码程序/downloads/`。
- Chrome profile 默认建议放到：`.temp/F01/alidocs-chrome-profile/`，用于跨任务复用登录态、减少扫码次数。
- 如果用户要求把登录态跟随某个子项目隔离，再把 `--profile-dir` 改到该子项目的 `03_代码程序/browser-profile/`。

## 最快下载命令

把下面 3 个变量替换成当前任务的真实路径后执行：

```powershell
$Doc = "标准库"
$Downloads = "F:\Projects\workspace\output\<当前子项目>\03_代码程序\downloads"
$Profile = "F:\Projects\workspace\.temp\F01\alidocs-chrome-profile"

python ".agents\skills\F01_钉钉文档下载\scripts\alidocs-downloader\scripts\download_alidocs.py" `
  --doc $Doc `
  --download-dir $Downloads `
  --output "$Doc.xlsx" `
  --profile-dir $Profile
```

执行含义：

- `--doc`：读取 `scripts/alidocs-downloader/config/docs.json` 中同名文档配置。
- `--download-dir`：Chrome 下载目录；相对 `--output` 也会落到这里。
- `--output`：文件名或绝对路径；推荐只给文件名并配合 `--download-dir`。
- `--profile-dir`：登录态目录；固定后下次通常免登录。

## 常用参数

| 参数 | Python | Node | PowerShell 包装 | 用法 |
|------|------|------|------|------|
| 选择文档 | `--doc 标准库` | `--doc 标准库` | `-Doc 标准库` | 文档标记，来自 `docs.json` |
| 指定配置 | `--config path` | `--config path` | `-Config path` | 一次性链接可用临时配置 |
| 输出文件 | `--output name.xlsx` | `--output name.xlsx` | `-Output name.xlsx` | 文件名或绝对路径 |
| 下载目录 | `--download-dir path` | `--download-dir path` | `-DownloadDir path` | Chrome 下载目录和相对输出基准 |
| 登录态目录 | `--profile-dir path` | `--profile-dir path` | `-ProfileDir path` | Chrome user-data-dir |
| 调试端口 | `--port 9222` | `--port 9222` | `-Port 9222` | 端口被占用时换端口和 profile |
| 不启动 Chrome | `--no-launch` | `--no-launch` | `-NoLaunch` | 仅在已手动启动同端口 CDP 时使用 |
| 只校验文件 | `--validate-only` | 无 | 无 | 只检查 `.xlsx` 结构和工作表 |

## 首次登录

1. 脚本启动 Chrome 后，若页面停在登录页，等待可见浏览器窗口。
2. 请用户手动扫码、授权或登录，不要让用户给密码。
3. 登录完成后回到命令行按 Enter。
4. 之后同一个 `--profile-dir` 会复用 cookies/session。

## 校验已下载文件

```powershell
python ".agents\skills\F01_钉钉文档下载\scripts\alidocs-downloader\scripts\download_alidocs.py" `
  --doc "标准库" `
  --download-dir "F:\Projects\workspace\output\<当前子项目>\03_代码程序\downloads" `
  --output "标准库.xlsx" `
  --validate-only
```

校验成功时脚本会输出 `Validated:` 和每个工作表的 `rows x cols`。

## 一次性新链接

如果用户给的是未登记链接，不要先改 `常用链接.md`。最快做法：

1. 复制 `scripts/alidocs-downloader/config/docs.json` 到 `.temp/F01/run-docs.json`。
2. 在临时配置里新增一个文档标记、`url`、`outputFile` 和可选 `expectedSheets`。
3. 用 `--config "F:\Projects\workspace\.temp\F01\run-docs.json"` 运行。
4. 只有用户明确要求长期复用时，再把链接追加到 `references/常用链接.md`。

## 失败时少走弯路

- `No Chrome CDP instance found`：去掉 `--no-launch`，或确认指定端口已有 Chrome CDP。
- 端口被占用或 profile 被锁：同时换 `--port` 和 `--profile-dir`。
- 页面未就绪：让用户在 Chrome 完成登录，再回命令行按 Enter。
- 找不到菜单：读 `下载工作流.md` 的菜单重试策略，不要反复固定坐标点击。
- 下载面板显示失败：脚本会优先使用导出事件里的临时 URL 保存文件；不要把临时 URL 写入长期文件。
