# 继承范围与维护说明

## 来源与取舍

- 内容源：创建时个人技能目录中的 report-table-v2（汇报表格制作 V2.0）。保留受众判断、文字提炼、按事项拆行和不确定性表达；单页取舍与共享格合并改按本地分册执行，不以来源规则覆盖阅读任务和用户要求。
- 视觉源：solution-design-excel/references/style-and-export.md 的 Excel Layout 与 Visual style。保留 B2 起表、蓝色 #3366CC、30 pt 标题、18–20 pt 表头、14–16 pt 正文及较大行高；边框按本地规范区分无框标题、白框表头和黑框正文。
- 除基础视觉外，多页时继承方案设计版的工作表层级：首表为 `0 概览`，采用编号明细，概览主要模块与明细对应，子表按实际下钻需要创建。页数服从阅读任务，不为凑单页混用字段，也不为制造层级增页。
- 不继承方案设计版强制各页结论、方案论证链条或产品路线规则；层级细则统一见 [输入与内容要求](输入与内容要求.md)。
- 继续使用 #C00000 表达正文重点，但不再沿用正文重点加粗。首两列加粗用于结构，标红原因写在最右备注；元信息、缩进、留白和冻结设置以本地视觉分册为准。
- 30/20/16 pt、68/52 pt 为原范围内的默认选值；正文行高起点是本技能实现约定，不声称来自原文件。
- 标题默认合并业务表宽并居中，正文仍默认不横向合并；页尾按信息必要性取舍。标题合并不包含左右留白列。
- 本技能携带完整所需规则，运行时无需读取来源技能；后续维护本地分册即可，避免来源更新造成隐式变化。

## 命名与目录

当前工作区及其父级未找到 A01 引用的 .system/standards/Skills管理标准.md，采用符合其命名校验的 R01（R 表示汇报）作为本地编号，不声称已完成跨工作区域编号注册。若后续接入统一管理标准，再核对域分配。

scripts/ 保存统一的数据校验、生成、原生格式补充、验收记录与回归测试；assets/ 保存主题参数和最小输入示例。引擎调用环境中的 spreadsheets 作者工具，依赖不复制到本技能。任务目录只保存独立内容数据、成品和运行记录，细节见[生成与验收流程](生成与验收流程.md)。

## 通用要求与规则归属

以下为从表格迭代中提炼的维护摘要，不是单个演示文件的模板。具体规则由对应分册维护，不复制测试材料、单元格坐标或某次试改的固定列宽。

| 确认内容 | 规则归属 |
| --- | --- |
| 先识别信息角色，再确定同级分类、层级、阅读依赖与证据边界 | 内容结构设计：六项能力、结构六检 |
| 来源形成独立可追溯的证据结构；重排同步目录、标题与引用 | 内容结构设计：来源依据、阅读顺序；输出契约 |
| 概览与一级页逐一对应；第二列主干决定下级页，属性列后移 | 输入与内容要求：列顺序、总分层级 |
| 独立中文编号；组内阿拉伯序号拆列；删除章节指引列 | 输入与内容要求：列顺序与编号 |
| 标题包含页签身份，副标题只补充新信息 | 输入与内容要求：页签与页内大标题 |
| 首两列居中加粗；其余正文只用红字强调并备注原因 | 重点与分组 |
| 大标题和全部表头分别核对居中；标题无框、表头白框 | 视觉与验收：默认参数、分类验收 |
| 正文整列对齐；左一格缩进、右约一字留白；所有页冻结前三行 | 视觉与验收：对齐、留白、冻结 |
| 无补充和不适用留空，未知保留明确状态 | 输入与内容要求：空白、未知与事实边界 |
| 最终文件原生属性与实际显示都检查，不以赋值成功代替验收 | 视觉与验收、输出契约 |
| 阅读任务决定页签；区分单 sheet、主阅读页和单张打印纸 | 输入与内容要求：工作表数量与总分层级 |
| 公共约束、待决事项和方案事实使用匹配的字段，保留费用与周期口径 | 方案对比与结构复核 |
| 默认不用横向合并，标题除外；正文逐行维护优先于合并装饰 | 重点与分组、视觉与验收 |
| 删除无新增信息的页尾标识，局部修改不扩大为重设计 | 输入与内容要求：信息必要性；输出契约 |
| 内容、主题、生成代码分开；通过统一入口生成并保存可追溯记录 | 报告数据规范、生成与验收流程；scripts/、assets/ |

版本的唯一展示来源为 agents/openai.yaml 的 interface.display_name。目录名和 frontmatter name 保持稳定，不将后续版本号散写到各规则文件中。

数据协议、引擎与主题各自的技术版本用于兼容和重现，分别记录在代码/主题及运行日志中，不作为 Skill 展示版本。技能规则变化更新展示版本；不兼容的数据协议变化另行提升 schemaVersion。
