# D04_架构图生成

## 这项技能解决什么问题

- 把"系统 / 框架 / 模块"的结构性理解，转成一张可在浏览器直接打开、清晰可读的架构图。
- 产出物是**自包含 HTML + 内联 SVG**：分层带、语义配色、卡片网格、箭头流向、图例与侧边说明卡，无外部依赖。
- 适用对象：框架总览图、机制协同图、系统分层图、数据流图等"实体 + 关系 + 分层"型可视化。

## 先读哪些本地知识

- 先读 `references/架构图绘制方法论.md`：本技能核心 IP——如何抽象层级、定流向、配语义色、卡片化、坐标网格法、外围说明卡。
- 需要现成起点时，复制 `assets/架构图模板.html` 作为空白骨架再填充。
- 想看一张完整成品长什么样，直接打开 `assets/示例-核心框架架构图.html`（技能内附的已填充样本，与模板一一对应）。
- 需要色板 / 列锚点 / 网格尺寸速查时，再读 `references/配色与坐标速查.md`。

## 固定动作

1. **抽取结构**：确认或梳理出"实体清单 + 实体间关系 + 分层主张"（自顶向下几层）。
2. **定分层与配色**：按方法论把系统切成 3–6 个水平带，每个带分配一种语义主色；带内实体同色系。
3. **画卡片网格**：每个实体画成圆角矩形卡片（标题 + 要点 + 落点），用固定列锚点与 `text-anchor="middle"` 对齐。
4. **连流向与图例**：用 `<marker>` 箭头表达依赖 / 指向；底部统一图例解释颜色语义；关键关系用侧边 HTML 说明卡补充。
5. **交付自包含 HTML**：内联 `<style>` + 内联 `<svg>`，单文件浏览器直接打开；顶部标注标题与生成时间。

## 什么时候再读本 skill 的 references

- 默认动作不够覆盖复杂情况（如需要时序图、泳道图、或导出 PNG / 可编辑 SVG）时，再读 `references/架构图绘制方法论.md`。
- 需要复用模板或微调色板 / 坐标时，再读 `references/配色与坐标速查.md`。

## 边界

- 不把稳定业务真相直接塞进 `SKILL.md`；方法论与模板下沉到 `references/` 与 `assets/`。
- 不生成 README、CHANGELOG 等噪音文件。
- SVG 不自动换行：长文本必须拆成多个 `<text>` 分行，不得依赖自动换行。
- 交付物应为单文件 HTML（含内联 SVG）；不引入外部 CDN 或字体依赖。
