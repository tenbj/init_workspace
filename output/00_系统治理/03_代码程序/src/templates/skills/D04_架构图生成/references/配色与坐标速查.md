# 配色与坐标速查

> 配合 `references/架构图绘制方法论.md` 与 `assets/架构图模板.html` 使用。本表来自"核心框架整体架构图"的实际取值，可直接复用或整体替换。

---

## 1. 语义色板（CSS 变量）

写入 HTML `<style>` 的 `:root`：

```css
:root{
  --ai:#7c3aed;     /* 多 AI 接入层 */
  --ssot:#4338ca;   /* SSOT 事实源 */
  --exec:#475569;   /* 执行层 rules/skills */
  --mech:#0d9488;   /* 治理机制 */
  --gate:#d97706;   /* 支撑门 */
  --store:#0284c7;  /* 数据存储区 */
  --seq:#e11d48;    /* 强制门序列 */
  --ink:#1e293b;    /* 主文字 */
  --muted:#64748b;  /* 次要文字 */
}
```

约束：每个水平带一种主色；带内卡片用同色系浅底 + 同色描边；箭头/图例引用同一组变量。

---

## 2. 画布与列锚点

- **画布**：`viewBox="0 0 1120 H"`，`svg{width:100%;height:auto}`（H 随带数增长，6 带约 1460）。
- **列锚点**（多列卡片左缘 x）：`40 / 249 / 458 / 667 / 876`，间距 **209**。
- **卡片中心 x**：`列锚点 + 卡片宽度/2`（宽度 196 → 中心 = 锚点 + 98）。
- **文字居中**：`<text x="中心x" text-anchor="middle">`。

## 4. 箭头 marker 定义（直接复用）

放在 `<svg><defs>` 内：

```xml
<marker id="ar" markerWidth="10" markerHeight="10" refX="8" refY="3" orient="auto" markerUnits="strokeWidth">
  <path d="M0,0 L8,3 L0,6 Z" fill="#64748b"/>
</marker>
<marker id="ard" markerWidth="10" markerHeight="10" refX="8" refY="3" orient="auto" markerUnits="strokeWidth">
  <path d="M0,0 L8,3 L0,6 Z" fill="#94a3b8"/>
</marker>
```

- 实线强依赖：`stroke="#64748b" marker-end="url(#ar)"`
- 虚线参考/输入：`stroke="#94a3b8" stroke-dasharray="6 4" marker-end="url(#ard)"`

---

## 5. 快速起手公式

1. 带数 n → 估算 `H ≈ 120 + n×180 + 图例/说明留白`。
2. 每带的实体数 m → 列锚点 `x_i = 40 + i×209`（i=0..m-1，m≤5 时铺满 1120 宽）。
3. 每带 y 基准自上而下递增（如 48 / 182 / 336 / 498 / 758 / 936）。
4. 卡片：`rect x=锚点 y=基准 width=196 height=H rx=9`，内部文字按 `中心x` 居中分行。
