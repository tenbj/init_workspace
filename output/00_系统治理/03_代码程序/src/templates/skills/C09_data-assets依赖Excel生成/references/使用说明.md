# 使用说明

> 本地 CLI：默认只扫描已有仓库，不克隆/同步；仅显式 `--force-sync` 执行来源中的强制同步步骤，需符合当前 C01 授权。

## 默认命令

从工作区根目录运行：

```powershell
python ".agents\skills\C09_data-assets依赖Excel生成\scripts\generate_data_assets_dependency_excel.py" `
  --output "output\07_数仓质量治理\01_问题答疑\03_data-assets上下游依赖数量.xlsx"
```

默认会：

1. 定位 `input/data-assets`
2. 禁用 `origin` push 地址
3. 拉取 `origin/master` 并强制对齐本地 `master`
4. 解析 tracked SQL/Python 文件
5. 写出 Excel 并打印 JSON 统计

## 常用参数

| 参数 | 说明 |
|------|------|
| `--repo-relative <path>` | 工作区内仓库相对路径，默认 `input/data-assets` |
| `--repo <path>` | 直接指定仓库绝对路径；优先级高于 `--repo-relative` |
| `--output <path>` | 输出 Excel 路径；未传时写入 `.temp/data-assets依赖清单.xlsx` |
| `--branch <name>` | 默认 `master` |
| `--remote <name>` | 默认 `origin` |
| `--no-sync` | 跳过同步，只扫描当前仓库状态 |
| `--include-untracked` | 扫描文件系统中的 `.sql` / `.py`，不局限于 `git ls-files` |
| `--clone-url <url>` | 目标仓库缺失或为空目录时用于 clone |
| `--json-summary <path>` | 将统计摘要另存为 JSON |

## 写入 output 前的项目规则

若输出到 `output/` 正式子项目：

1. 先完成话题归属
2. 修改 live 子项目文件前执行 `B02`
3. 生成后更新子项目 `目录.md` 和 `版本记录.md`
4. 收尾执行 `B03`
