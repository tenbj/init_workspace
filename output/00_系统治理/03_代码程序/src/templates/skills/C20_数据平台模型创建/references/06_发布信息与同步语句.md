# 发布信息与同步语句

## P1 发布信息

| 输入框 | 依据与规则 | SQP例 |
|---|---|---|
| 数据连接 | 本平台“跨境电商”即Doris正式数仓；其他连接需核实，不凭业务域文字自动选择 | 跨境电商 |
| 数据分层 | 实际模型设计、表名前缀及域路径一致 | DWD |
| 数据库 | 开发阶段确定的库，通常cbebg但不可硬编码 | cbebg |
| 数据表 | 完整规范技术表名，库名单填 | dwd_ads_sqp_brand_view_ilu_dd |
| 代码路径 | 已合并仓库相对路径，包含.sql，不用本机路径或create文件 | cbebg/ads/dwd/dwd_ads_sqp_brand_view_ilu_dd/dwd_ads_sqp_brand_view_ilu_dd.sql |
| 模型属性 | 当前DWD/DWS/DMT/DMA为维度建模；ODS数据同步/文件导入另待案例 | 维度建模 |
| 同步方式 | 当前架构离线同步 | 离线同步 |
| ETL类型 | SQL | SQL |
| 模板 | SQL-DORIS | SQL-DORIS |
| 更新方式 | 实际写入语义与表名更新标识、参数一致 | 增量合并 |

本工作流flu全量通常无日期范围参数，ilu增量有范围参数；不能把SQL任意参数都算增量证据。首次用大范围初始化ilu仍是同一增量模型，不能改全量覆盖。出现ich/fsn或模板、引擎差异要按实际设计核对，不能凭本例猜枚举。

联动顺序：先连接/分层，再数据库/表名，最后代码路径。改分层可能清空数据库、把表名重置成dwd_、重写代码路径；改表名也可能继续拼接路径。输入后失焦、等联动稳定，再完整读回所有十项。不要只看输入动作成功。通过后进入同步语句。

## P2 同步语句

点击侧栏“同步语句”，等待自动拉取及字段智能生成。确认SQL非空、属于目标模型，来自已合并的正确路径，未截断或报错；若发现明显版本不符按异常分支处理。用户要求最小动作，不在此额外改写/执行SQL或添加配置。

瞬时“智能生成中”是否被捕捉不重要，它与生成字段信息相关。实操也出现“同步语句获取中...”；不要为补抓字样重复触发或刷新。代码已拉到后进入字段信息，字段自动生成可能只填一部分，不能据此跳过导入与检查。
