# 操作前确定模型中文名

先读随包原件 [数仓_01_命名规范手册.xlsx](../assets/数仓_01_命名规范手册.xlsx)，再结合 C18 的英文表规范和实际业务。原件5张表的尺寸元数据错误，openpyxl只读模式需对工作表调用reset_dimensions()，不能按A1尺寸认定无内容；也可普通模式读取。不要改原件。

## 顺序与检查

1. 确定数据库、英文规范表名、分层、数据域、业务对象/内容、粒度和更新方式。英文表名与加工目录按 C18；仓库层级、分支及MR按 C19。
2. 查手册02页对应分层模板、03页规则、04页术语及可用词根标准。登记缺项说明已查范围；外部业务原文不等于内部已登记，也不等于必须擅自翻译。
3. 记录候选及依据单元格、源版本/hash、冲突、用户确认/登记状态。已有明确名称不重复询问；新例外须确认，正式名称应在操作前定下。
4. 查同库表/名称是否已有模型，避免重复；树的完整路径单独记录。中文名、提交标题、英文表名是三个值，不互相复制替代。

## 原文模板与冲突

| 层 | 02页中文模板原文位置 | 使用边界 |
|---|---|---|
| ODS | E5 `{源系统/数据源}_{源业务对象}_原始表` | 原始表；本技能未演示完整ODS创建 |
| DWD | E6 `{数据域}_{业务对象}明细` | 本案例已验证；不要写明细表 |
| DWS | E7 `{数据域}_{业务对象}汇总_按{统计维度}` | 与03页C1粒度不入名有冲突，新DWS命名需明确取舍，不能冒充本案已确认 |
| DMT | E8 `{集市主题}_{跨域主题}宽表` | 集市主题需按相关字典评审，不临时当数据域 |
| DMA | E9 `{应用主题}_{用途}` | 首段是应用主题，不机械套DWD域前缀 |
| DIM/REF | E10/E11 | 仅提供规范定位，完整操作不在当前范围 |

03页A4（E8）长度不超过30字；A3统一下划线；B1/B2按术语登记及词根中文名；B3禁止临时/版本/人名/日期串等；B4禁止数据表/信息表/明细表/汇总表等空洞后缀；B5站点、国家、币种用标准中文；C3一义一名；C4与英文层级、业务对齐。

手册03页A1/C1/C2规则栏（E5/E14/E15）明确周期、形态、粒度由平台元数据承载；同页标题、部分F列及05病例仍含旧周期括号。**SQP案例按明确规则栏，不追加周期/形态括号或粒度尾缀。** 不把此案例的冲突处理扩展成对所有分层模板的无条件改写；未被案例解决的冲突给出原文位置并确认。04页L2个别词的使用说明允许保留英文，不能只看等级标题机械翻译。

## SQP已确认特例

- 正式中文名：`广告_SQP_品牌视图明细`；英文：`cbebg.dwd_ads_sqp_brand_view_ilu_dd`。
- 前缀广告_来自数据域；业务对象保留SQP_品牌视图；DWD后缀为明细。来源业务的“视图”不是被手册禁止的词，不能因其落为实体表强行删除。
- 用户已提出SQP登记申请并明确保留；本手册未列SQP，**申请不是审批完成**。以后其他业务名不能借此自动获得豁免。
- 不使用MR标题`DWD-SQP品牌视图`作为平台中文名，不加cbebg、ilu_dd或每日增量。历史草稿“广告_品牌搜索词表现明细”已被替代。
- 已有上游的中文名用于血缘身份检索，按平台真实登记值读取；不借当前手册要求重命名他人已有上游。
