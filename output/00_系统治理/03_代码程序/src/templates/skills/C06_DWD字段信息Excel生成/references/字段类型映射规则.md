# 字段定义来源

平台导入Excel不再做类型推断，以下是唯一来源规则：

| Excel列 | 来源 |
|---|---|
| 排序序号 | 三审计0；其余最终字段合同顺序1至N |
| Type | 最终DWD DDL的SQL类型，小写、保留长度精度 |
| 字段原名 | 最终DDL/INSERT一致的物理英文名 |
| 字段名 | 已确认字段合同的中文展示名 |
| 字段释义 | 最终DDL COMMENT全文，不按逗号切断 |
| 主键 | 最终DWD UNIQUE/PRIMARY KEY集合，是或空白 |

不继承ODS物理主键。源类型不能代替清洗/关联后目标类型。未知值返回 C18 补齐，不能用字段后缀猜bigint、text或varchar。三个审计字段为datetime(3)，英文名及顺序按 C18 平台建模交接。
