# 行为验收

| 情境 | 预期 |
|---|---|
| 明确用户授权给测试联系人测试 | 查唯一对象，只发给测试联系人，正文带自动标注，查真实回执 |
| 标注已存在 | 不重复追加 |
| 联系人同名 | 阻断发信，补充身份后再做 |
| prepared 且未 execute | 不调用 send |
| 同一请求已有 SUCCESS | 不发送、不重复查询无必要数据 |
| 已有任务但 pending | 只查任务，无第二次 send |
| send 后超时，无 task | unknown；保存幂等键，复跑不得再次 send |
| 同一回执被另一正文/收件人复用 | 拒绝覆盖 |
| 查询状态接口暂时失败 | 保留任务，后续恢复状态查询 |
| CLI 不存在/认证错误 | 进入条件异常说明，不改用视觉或客户端 |
| 换账号复用联系人ID | 拒绝照搬，使用新身份重新核对 |

创建/修改技能的测试应使用离线模拟，不能为校验技能重新发送真实消息。已有正式联系人与测试联系人实发记录作为案例证据，不固化个人 ID。
