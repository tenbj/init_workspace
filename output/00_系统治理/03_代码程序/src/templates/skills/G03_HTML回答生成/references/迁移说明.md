## 适装评估

结论：推荐当前项目正式安装，并限制触发范围。

| 维度 | 判断 |
|---|---|
| 新增知识价值 | 提供可直接运行的确定性排版 CLI、图表组件、内嵌草稿和局部修改能力 |
| 能力重叠度 | 与 G01 都输出 HTML；G03 专注 Markdown 渲染，G01 承接自由布局和定制交互 |
| 环境耦合度 | 核心页面仅需 Node.js 20+；本机 v24.14.1 可用，无需 npm 安装 |
| 流程负担 | 主要是写草稿、执行渲染、核对结果；不引入插件或监听服务 |
| 触发范围 | 收窄为明确 HTML 需求或需要视觉表达的复杂关系；不启用 always-on |
| 上下文成本 | 中文薄入口；原始长说明和视频分支按需展开 |
