# C21_数据平台新增字段

## 本地接入

先遵循当前工作区规则；按 B12 精确路由所需连接，按 B04/B08/B03 管理产物与进度。来源案例、账号、路径、人员和历史授权均不自动继承。

## 这项技能解决什么问题

- 为数据平台的已有模型逐个新增字段，覆盖字段定义、表单填写、DDL预览、确认执行和保存回读。
- 不限ODS；支持明细、汇总、维度等模型的新增实体字段。不同来源的类型与口径按场景核对。
- 本Skill只完成字段新增；代码同步使用已有Skill，海豚代码更新由独立Skill负责。

## 先读哪些本地知识

- 每次必读 [操作流程](references/操作流程.md)、[字段定义与场景](references/字段定义与场景.md)、[输出契约](references/输出契约.md)。
- 浏览器登录恢复遵循[共用操作规则](../../rules/platform-modeling-rules.md#平台登录与环境恢复)：先查 `.envs` 恢复认证，保留未保存窗口，不把登录成功当作字段定义确认。
- 按 B08 恢复进度，按 B03 记录增量；修改本地live文件不自动备份，用户明确例外优先。Skill编号按标准解析。

## 固定动作

1. **强制第一步：全量字段定义确认。** 先只读核对模型与字段，向用户一次展示本轮全部模型、全部待增字段的完整定义及执行范围，等待明确确认；未确认不得打开新增表单、填写、预览或执行。清单内容与确认规则见操作流程第一节。
2. 记录已确认清单、用户回复及执行范围；关键定义或范围变化时先确认差异。已有明确确认持续适用于未变字段，不重复询问。ODS只是来源场景之一，不把示例类型当通用默认。
3. 将目标浏览器标签页置前，从模型列表点击目标模型 → 数据字段 → 字段管理 → 新增字段。
4. 逐个填写并回读；非主键字段Nullable选“是”。用户要求先填不提交时停在表单，不点击“确定新增”。
5. 已授权提交时点击“确定新增” → 核对当前字段的DDL → “确认执行”。这是同一字段提交的两个界面步骤，不额外要求用户再次批准。
6. 核实业务成功响应并回读字段列表；当前字段确认成功后处理下一字段。报告字段新增结果，分别保留代码、调度、加载和回填的未完成状态。

## 边界

- 仅要求封装或讲解Skill时不操作生产；带教时只执行用户指定步骤。已确认完整清单内的提交授权持续有效，不重复询问；笼统的“加字段”、代码已提交或已登录不代替字段定义确认。
- 不通过“配置模型 → 同步语句 → 确认更新”修改代码，不把Git、海豚更新或运行验证塞进本流程。
- 既有模型加字段不套用新模型创建的MR合并前置门；需要新建模型时转 C20。
- 不自动删除、重建、改类型、补数、运行调度或发消息。没有证据不得声称实体变更、代码更新、数据加载均完成。
- 不硬编码模型ID、页面UID、请求编号或登录凭证；不刷新、关闭仍有草稿的窗口。全量清单确认后，仅在定义/范围变更、关键项缺失或DDL越界时再询问，不因熟悉的二次执行弹窗重复停顿。
