# 结构融合索引

> 本文件只说明 11 段 Skill 结构在 `A01_创建技能` 中的落点，不替代 `SKILL.md` 的触发入口。

## 一、入口定位

- **Skill**：`A01_创建技能`
- **职责摘要**：当用户要新建、重写或薄化本地 Skill 时使用；生成基础骨架、薄入口、references 路由与校验结果。
- **入口文件**：`SKILL.md`
- **展示元数据**：`agents/openai.yaml`
- **详细知识分册**：`references/openai_yaml.md`<br>`references/主控技能创建增量规则.md`<br>`references/技能创建完整流程.md`<br>`references/薄技能设计模式.md`<br>`references/通用技能设计原则.md`<br>`references/输出契约.md`
- **确定性执行脚本**：`scripts/generate_openai_yaml.py`<br>`scripts/init_skill.py`<br>`scripts/quick_validate.py`
- **模板与物料**：无专用物料；需要模板或样例时再补 `assets/`

## 二、11 段结构落点

| 结构 | 当前落点 | 使用方式 |
|------|----------|----------|
| 1. Skill Metadata | `SKILL.md` YAML frontmatter；`agents/openai.yaml` | 稳定 `name` 和触发描述在入口；版本与展示文案只在 `openai.yaml`。 |
| 2. Role & Goal | `SKILL.md` 的标题和“这项技能解决什么问题” | 入口只写角色、目标和适用范围摘要。 |
| 3. Trigger Conditions | `SKILL.md` frontmatter `description`；必要时见触发/固定动作章节 | 高频触发放入口；复杂触发、反例或分流放入 references。 |
| 4. Input Schema | `SKILL.md` 固定动作中的输入确认步骤 | 参数、默认值、输入路径和格式样例优先下沉到 references 或脚本参数。 |
| 5. Knowledge Base | `references/openai_yaml.md`<br>`references/主控技能创建增量规则.md`<br>`references/技能创建完整流程.md`<br>`references/薄技能设计模式.md`<br>`references/通用技能设计原则.md` | 只在触发本 Skill 时展开读取；本索引只说明本 Skill 的能力结构。 |
| 6. Execution Workflow | `SKILL.md` 的“固定动作”；`scripts/generate_openai_yaml.py`<br>`scripts/init_skill.py`<br>`scripts/quick_validate.py` | 入口保留主流程骨架；可自动化步骤进入 `scripts/`。 |
| 7. Decision System | `references/主控技能创建增量规则.md` | 判断路径、优先级、约束、权衡和异常处理优先放 references，硬约束保留在入口边界。 |
| 8. Output Schema | `references/输出契约.md` | 输出目录、文件名、字段、交付物和日志说明放 references；模板进入 assets。 |
| 9. Quality Check | `references/输出契约.md`；自动校验见 scripts | 主流程触发质量检查，细则和脚本校验下沉。 |
| 10. Examples | 无专用物料；需要模板或样例时再补 `assets/` | 文字案例放 references；可复用文件、模板、截图和 Excel 放 assets。 |
| 11. Tools & Permissions | `SKILL.md` 固定动作与边界；脚本见 scripts | 工具调用、只读/写入边界和禁止项必须可追溯；密钥不进入 Skill 文档。 |

## 三、维护规则

1. `SKILL.md` 保持薄入口，不把本索引展开成 11 个一级章节。
2. 新增输入、决策、输出、质量或案例细则时，优先新建/更新 `references/` 分册。
3. 新增确定性执行能力时，优先进入 `scripts/`，并在本索引中补路径。
4. 新增模板、样例、Excel、图片或静态物料时，进入 `assets/`，并在本索引中补路径。
5. 修改本 Skill 前先按 `B02` 做 FOLDER 备份；批量改造后运行 `B01` 体检。
