1. C03 返回源表建表文件的确切路径；不要根据时间戳、库名前缀或通配符猜文件。
2. C05 消费该路径生成 SQL 初稿及配套开发说明。以返回路径继续处理，不假定脚本没有追加表名子目录。
3. C18 完成命名确认、字段合同、最终 DDL 和加工 SQL，解决初稿中的枚举、类型和时间戳问题；SQL 头部不再承载设计说明。
4. C06 消费最终三件套，使用 `--output` 指定正式六列平台字段 Excel，用 `--work-dir` 保存校验及预览。不得沿用旧 ODS 推断和 11 列导出参数。
5. 核对最终 SQL、DDL、合同、Excel 一致性及预览后交付。静态通过不代表生产执行或平台导入已经验证；任何步骤失败时保留真实回执并停止后续交付。

全部路径归入本模型所属标准子项目；跨 Skill 路径按当前注册表解析。
