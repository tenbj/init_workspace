# 行为验收

| 场景 | 必须行为 |
|---|---|
| SQP 品牌新增 | cbebg/ads/dwd/规范表名/同名.sql；分支 DWD-SQP品牌视图；只提交加工 SQL |
| DWS 代码修改 | 分支 DWS-已确认中文名；提交加中文冒号与具体修改点 |
| 选中 create SQL | 预检拒绝，不悄悄替换成猜测的文件 |
| 工作树有用户改动 | 保护原工作树，可用隔离 worktree；不自动 stash/reset/clean |
| 已推送且 MR 已建，通知失败 | 仅恢复 F05，不重复 commit/MR |
| MR 已合并 | 不发送“帮合并代码” |
| 暂存区混入其他文件 | 拒绝提交，不将其悄悄 unstage 或打包入提交 |
| CLI 不存在或权限不足 | 进入 F05 异常分支，绝不切换到 Codex 视觉/桌面消息 |
| 同名联系人/未知发信结果 | 交 F05 消歧/查询，不猜测收件人或盲目重发 |

创建本技能只执行离线校验，不再次提交原 SQP 模型或发送历史 MR 通知。
