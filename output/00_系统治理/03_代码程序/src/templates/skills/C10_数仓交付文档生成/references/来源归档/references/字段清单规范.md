# 字段清单规范

## 字段顺序

1. 以目标 INSERT 列表和最终 SELECT 输出顺序为准。
2. 系统审计字段保持序号 0；是否由 SQL 显式写入如实说明。
3. 业务字段从 1 连续编号，不跳号、不重复。
4. SQL 新增字段时插入真实位置，后续字段顺延，不能简单追加到末尾。

## 各列填写口径

| 列 | 要求 |
|---|---|
| 字段中文名 | 区分原始字段、代表字段和派生字段 |
| 字段技术名 | 与目标表和 SQL 完全一致 |
| 字段类型 | 以目标表结构为准，不凭表达式猜测 |
| 字段释义 | 描述业务对象和粒度 |
| 加工说明 | 写明分支、来源、关联、聚合、窗口、除法、空值和精度 |
| 备注 | 写上游表、别名或系统维护方式 |

## 多分支规则

- 同一字段来源不同，使用“分支A：…；分支B：…”描述。
- 常量字段写明允许值和分支；恒为 NULL 时明确说明。
- 原始明细标识与代表标识必须分列，代表字段不得替换当前行主键粒度。

## 主键字段

- 列出拼接维度、顺序、分隔符、日期格式、空值规则和哈希方法。
- 先验证源 SELECT 粒度，再决定主键；目标 Unique Key 无重复不代表写入前没有折叠。
- 共用目标表承载多口径时通常需要包含口径字段。

## 完成检查

- Excel 技术字段集合和顺序等于目标 SQL 输出。
- 每个字段均有中文名、类型、释义、加工说明和来源。
- 不存在旧逻辑描述；代码修复后相关字段说明同步更新。
