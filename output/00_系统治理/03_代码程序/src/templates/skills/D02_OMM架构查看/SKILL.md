# D02_OMM架构查看

## 这项技能解决什么问题

- 启动 oh-my-mermaid 本地 Web 查看器
- 帮用户查看已有 `.omm/` 架构图谱
- 用中文薄入口承接 `omm-view` 的原始流程

## 先读哪些本地知识

- 先确认项目中是否已有 `.omm/` 架构文档
- 需要回看原始说明时，再读 `references/原始技能说明.md`
- 需要了解这次迁入时的本地化取舍时，再读 `references/迁移说明.md`
- 需要确认安装价值与限制时，再读 `references/适装评估.md`

## 固定动作

1. 确认用户明确要求打开或查看架构图谱
2. 检查 `omm` CLI 是否可用；不可用时提示用户安装 `oh-my-mermaid`
3. 先运行 `omm list` 判断是否已有可查看内容
4. 有内容时运行 `omm view`，用户指定端口时透传 `--port`
5. 报告本地查看地址；默认按原始说明使用 `http://localhost:3000`

## 什么时候再读本 skill 的 references

- 需要完整原始用法、原始边界或原始示例时，再读 `references/原始技能说明.md`
- 需要确认本次迁移来源、原始描述和本地化动作时，再读 `references/迁移说明.md`
- 需要判断是否适合启用该 skill 时，再读 `references/适装评估.md`

## 边界

- 不在 `.omm/` 缺失时启动空查看器；提示先执行 D01
- 该 skill 只读查看，不修改 `.omm/` 内容
- 不把原始长说明重新塞回 `SKILL.md`
- 不跳过当前项目已有的本地边界与治理约束
