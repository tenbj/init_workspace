# 分区与工作流执行

## 分区前置

1. C03 回读 DDL，C02 读取分区、边界、状态、动态属性与可得权限。核对业务日期列、NULL/1925 特殊日期、分桶副本和历史是否可能被动态淘汰。
2. 动态分区已开启不代表旧年分区存在；SPPR create_history_partition=false，只有 p2025—p2027，缺 p2022—p2024。现有同名分区也要比实际边界，IF NOT EXISTS 不会修正错误范围。
3. 展示完整 DDL、原属性、修改后的属性和失败恢复语句。**即使代理有权限，也必须等用户确认具体命令后才修改。**没有权限由用户执行并通知；只读查权限，不试 ALTER，也不借 writer 身份探测。
4. 必要时暂关动态分区→添加历史分区→恢复原开关（原来 false 就恢复 false）→SHOW PARTITIONS 与 SHOW CREATE TABLE 双回读。中途失败记录完成项，先恢复原开关，再排查；不得因部分 ADD 成功而开始补数。
5. 本次成功原样 SQL 在 [prepare_history_partitions.sql](../assets/sppr_case/prepare_history_partitions.sql)，由用户执行，代理回读。它不含 DROP/TRUNCATE。换表执行前必须重新生成与确认，不把原脚本直接重放。

不能未经确认扩大动态保留窗口或改 AUTO PARTITION。自动分区改造是另一个任务，需要实际 Doris 版本、列可空性和迁移方案；MySQL 兼容 VERSION() 不代表 Doris 版本。

## 配置 His-Init

平台浏览器操作遵循 C22 与当前浏览器工具约束，不输出连接密码、登录 token。先定位目标模型关联的日常工作流以确认真实源；全名查找已有 `[His-Init]{Doris表名}` 和活动实例，避免复制/重跑重复。

有可复用同表工作流时先检查现有版本，已验收且当前无缺口不改。需要新建时，按本场景用户明确约定，从任一已验证 `[His-Init]{Doris表名}` 工作流复制；记录模板来源和版本。该复制授权只适用于本历史补数流程，不扩展为修改原日常工作流的权限。

- 名称：`[His-Init]{Doris表名}`；描述：`{Doris表名}`。
- 定义执行策略：**串行等待**（SERIAL_WAIT）。
- 保存时勾选上线工作流定义；保存即 ONLINE。
- **定时不上线**。不要套用一般流程的“恢复原定时”去开启 His-Init 定时。
- 检查 DAG、节点、连接、writer 目标、旧表名残留；仅替换该节点六参数，保留已验证 DataX 模板、资源和连接。
- 若模板包含其他节点，不擅自启动无关节点，先明确本次应执行节点范围。

六参数先写本地完整文件，然后整块粘贴。编辑器全选是否成功必须验证，避免 fill/type 实际追加到旧内容。每项粘贴后将剪贴板改成唯一临时标识，再从编辑器全选复制，与源文件逐字比较（只允许明确的 CRLF/LF 差异）；避免读到旧剪贴板而误判成功。名称与描述也必须先全选清空再填写，保存前读出完整值；保存后再次回读持久化定义，校验名称、描述、六值及其余模板是否未意外改变。无法提供可信整块输入和回读时，不假称已配置；继续使用可用合规工具或交付用户填写。

上述临时标识校验适用于剪贴板方式。剪贴板不可用时可复用已验证的普通表单录入：先清空，使用当前工具支持的完整字段值回读与源文件逐字比较，再核对保存后的持久化六参数。两条路径的验收目标相同，不强制依赖失效剪贴板，也不把截图局部文本或粘贴返回成功当成全文一致。

## 一段一运行一提交

1. 提交前读本段 CK 数量、Doris 删除命中和分区就绪状态；核对固定保护、完整字段投影及参数检查。记录预期。
2. 启动弹窗显式填写本段 StartTime/EndTime。运行时用户所说的“两边都不发”真实控件为 **通知策略：都不发**（NONE），它与定义的串行等待不同。
3. 普通运行，不擅选原生补数、空跑、测试；其他选项沿用本次已验证设置。一个点击只产生一个实例；返回不明先查询实例，不能再次点击碰运气。
4. 立即记录实例 ID、工作流/节点版本、起止时间、状态和实例 commandParam 启动参数。实例没有 StartParams 不能声称使用了用户想要的日期，需对照保存节点值和实际展开证据。
5. 参数优先级不明必须在有删除动作前解决；已发现实例有效范围超出计划时立即采取平台可用的停止措施、核对停止状态与已产生的数据影响。用户要求停止时也必须停止实际输入/任务，而非仅停止轮询。
6. 成功状态后做数据库验收，不为成功实例反复打开节点日志；失败读日志定位阶段、实际参数及 SQL，按报错恢复流程处理。
7. 每段结果更新执行记录/B08，每表验收完成立即回写 Excel。His-Init 按已约定保留 ONLINE，定时关闭；不因通用临时工作流清理规则擅自下线。
