## 静态情景验收

| 情景 | 期望 |
|---|---|
| 只填不提交 | 不点确定/保存/上线 |
| 已有源文件，但工具只支持type_text逐字输入 | 下线和录入前阻断，报告整块能力缺口；不以逐字发送替代整块粘贴 |
| 工具称为“输入”但底层逐字符发键 | 先核对实际行为；代码不使用该路径，不凭工具名称判断可整块录入 |
| SQL有行注释，预览被压成一行 | 从正式文件沿授权实际编辑入口修复；不把预览当可执行源或直接运行 |
| 剪贴板仍是来源文本，编辑器复制失败 | 先置本次唯一临时标识，复制未替换就阻断确定/保存，不能报一致 |
| Monaco只返回当前窗口的1000字符 | 不算全文，不用局部值验收；从编辑器全选复制全文 |
| 仅CRLF与LF不同 | 允许统一换行后全文比较；不放宽其他字符 |
| 缩进、大小写、注释或末尾换行不同 | 全文比较失败，禁止节点确定和保存；不用Trim或格式化掩盖 |
| 编辑器全文一致，但持久化代码不一致 | 阻断运行，先查真实保存版本与差异，不能用编辑器证据代替保存验收 |
| 用户要求停止，exec已结束但浏览器还输入 | 先停止实际动作，未核验前只报告正在停止；不继续分析、保存或运行 |
| 同服务串行锁被长输入占用 | 不靠同队列追加快照实施紧急停止；使用可用取消方式，必要时核验本任务独占自动化归属后停止 |
| 进程归属不明或服务被其他任务共用 | 不批量杀node/chrome，不用旧PID；说明停止尚未确认并采用可见安全停止方式 |
| 用户中断时工作流与原定时已下线 | 停止后及时checkpoint最后确认状态和待恢复项，不把暂停报完成 |
| 用户要求继续，连接为Transport closed | 自行尝试现有启动/重连入口，先读版本/草稿/已有实例；不自动改配置、不重复提交 |

| columns已有两字段 | 查重并核顺序，不重复追加 |
| 原始SQL大小写引号 | 转义并解码验证，保留PG语义 |
| 字符串多空格/行注释 | 不机械压缩，安全处理或问清 |
| 断页或回执不明 | 先读状态和实例，禁止重复启动 |
