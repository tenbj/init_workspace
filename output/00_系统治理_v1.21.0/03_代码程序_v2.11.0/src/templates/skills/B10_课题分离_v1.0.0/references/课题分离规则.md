# 课题分离规则

## 目标

课题分离只做一件事：把一段混沌表达中混在一起的信息拆清楚。

它借鉴 `atomic-decomposition` 的“先分离事实、感受、判断、假设、目标、约束”思路，但明确裁掉后续三类产出：

- 不生成可验证实验。
- 不生成执行计划或每日行动。
- 不生成小红书选题、内容结构或商业化设计。

## 适用输入

适合处理：

- 情绪化表达：例如“我很乱、很焦虑、觉得自己不行”。
- 多目标表达：例如“我想减肥、做账号、赚钱、恢复身体，但又很累”。
- 含混判断：例如“我不知道是身体问题、情绪问题还是执行力问题”。
- 用户明确要求“先拆清楚”“只分离问题”“不要给方案”。

不适合处理：

- 纯代码调试。
- 单纯润色、改写、翻译。
- 已经清晰的执行任务。
- 用户明确要求研究方案、实验计划、内容计划时；这些应转给相应 Skill。

## 信息类型定义

| 类型 | 定义 | 判断标准 |
|---|---|---|
| 事实 | 已发生、可描述、相对客观的信息 | 时间、地点、状态、已做过的事、已有数据 |
| 感受 | 主观体验和情绪 | 累、烦、焦虑、害怕、委屈、无力、痛苦 |
| 判断 | 用户对自己、他人或局面的结论 | 我不行、没救了、对方不在乎、这事没有未来 |
| 假设 | 对原因、机制或关系的猜测 | 可能因为睡眠、压力、方法、环境、人际关系 |
| 目标 | 想要的结果或方向 | 变瘦、稳定、赚钱、改善关系、找到方向 |
| 约束 | 限制条件和边界 | 时间、身体、金钱、精力、家庭、平台规则 |
| 行动意图 | 用户想做或正在考虑做的事 | 想开始、想放弃、想记录、想找人帮忙 |
| 风险信号 | 需要谨慎对待的健康、安全或高压信号 | 持续疼痛、严重失眠、自伤语言、极端行为倾向 |
| 待澄清项 | 当前信息不足，不能可靠归类或判断的部分 | 缺少时间、频率、程度、背景、优先级 |

## 课题层命名

课题层是“问题域”，不是行动方案。命名时只说明这个层在讨论什么，不写怎么做。

常见课题层：

- 身体与健康状态
- 睡眠与精力
- 情绪与自我评价
- 目标与优先级
- 资源与现实约束
- 关系与外部环境
- 内容/账号/商业意图
- 决策冲突
- 风险信号与专业支持

## 标准输出模板

```markdown
## 一句话翻译

{用中性语言复述用户表达，不加建议}

## 混在一起的层

1. {课题层 A}
2. {课题层 B}
3. {课题层 C}

## 信息分离表

| 类型 | 原句或信息 | 更清晰的表达 | 确定性 | 备注 |
|---|---|---|---|---|
| 事实 |  |  | 已知/推测/缺失 |  |

## 课题边界

| 课题层 | 包含的信息 | 不包含的信息 | 需要澄清 |
|---|---|---|---|
|  |  |  |  |

## 待澄清项

- {为了继续研究或制定方案，需要用户补充的信息}

## 暂不处理

- 暂不生成实验。
- 暂不生成行动计划。
- 暂不生成内容选题或商业化方案。
```

## 示例

原文：

> 我想减肥，也想把过程发小红书，以后靠这个赚钱。但我现在很累，睡不好，浑身疼，又觉得自己很没用。

分离后：

| 类型 | 原句或信息 | 更清晰的表达 | 确定性 | 备注 |
|---|---|---|---|---|
| 目标 | 想减肥 | 用户有体重或身体管理目标 | 已知 | 还缺少当前状态和目标范围 |
| 内容/商业意图 | 发小红书、以后赚钱 | 用户有内容表达和商业化期待 | 已知 | 不在本 Skill 中设计内容路线 |
| 感受 | 很累 | 用户主观精力低 | 已知 | 可先作为状态信息 |
| 风险信号 | 睡不好、浑身疼 | 可能存在健康或睡眠相关风险信号 | 推测 | 不诊断，只标记 |
| 判断 | 自己很没用 | 用户把状态上升为自我否定 | 已知 | 需要与事实分开 |

课题边界：

| 课题层 | 包含的信息 | 不包含的信息 | 需要澄清 |
|---|---|---|---|
| 身体与健康状态 | 累、睡不好、浑身疼 | 减肥方法、运动安排 | 症状持续多久、严重程度 |
| 目标与优先级 | 减肥、赚钱、发小红书 | 具体执行计划 | 哪个目标最优先 |
| 情绪与自我评价 | 自我否定 | 事实判断 | 这种判断出现的频率和触发场景 |

## 质量自检

- 是否把事实、感受、判断、假设分开了？
- 是否把用户的判断还原为“判断”，而不是当事实复述？
- 是否明确标出已知、推测和缺失？
- 是否只命名课题层，没有设计实验或计划？
- 是否没有输出小红书选题、内容模板或商业化建议？
- 是否对风险信号保持谨慎，只标记、不诊断？
