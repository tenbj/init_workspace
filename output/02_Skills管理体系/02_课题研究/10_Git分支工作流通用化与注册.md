## 通用化内容

| 原有约定 | 通用后的行为 |
|---|---|
| 固定根目录不是仓库、应用在特定子目录 | 从目标路径用Git定位真实仓库，支持根仓库、嵌套仓库、worktree和新文件路径 |
| `.agents`等目录默认不在Git | 按真实仓库边界判断，不根据目录名推断 |
| 固定npm脚本和锁文件 | 从仓库规则、CI、构建与依赖配置选择实际可用检查 |
| 固定验收者 | 当前用户或其指定验收者 |
| 默认origin/master | 从用户指定、upstream与远端默认分支信息识别；有歧义才询问 |
| 实现后必推送 | 按已有授权区分实现、提交、推送；“提交一版”只做本地提交 |
| OK/没问题等自动合并 | 记录验收状态；仅明确授权或用户已接受的明确流程才合并 |
| 强制merge commit与删除远端分支 | 遵守仓库PR/MR、保护与合并策略，清理分支单独按授权 |
| 固定应用标签/版本规则 | 沿用目标仓库约定，普通实现不自动发版 |

保留受保护基线上的分支优先原则，保护用户脏改动和暂存边界，不自动reset/clean/stash/强推。不运行B01作为前置门；无Git时继续可做的文件工作，不自动初始化Git。
