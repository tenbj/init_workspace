# 字段类型映射规则

## SQL 类型 → 字段类型（Excel 中文列）

| SQL 类型 | 字段类型 |
|---|---|
| `datetime`, `datetime(3)`, `timestamp` | 日期 |
| `date` | 日期 |
| `bigint`, `int`, `tinyint`, `smallint`, `mediumint` | 数值 |
| `decimal(...)`, `float`, `double` | 数值 |
| `text`, `varchar(...)`, `string`, `char(...)` | 文本 |
| 其他未知类型 | 文本 |

## SELECT 表达式 → 类型推断（无 ODS/DIM 对应时）

| SELECT 表达式特征 | 推断类型 | 备注 |
|---|---|---|
| `NOW()` | datetime(3) / 日期 | 系统时间 |
| `from_unixtime(...)` | datetime(3) / 日期 | unix 戳转换，在字段备注中说明来源 |
| `Date(...)` / `date(...)` | date / 日期 | |
| `NULL as field` | varchar(255) / 文本 | 新增占位字段，备注标注"待补充" |
| `cast(... as bigint)` | bigint / 数值 | |

## 系统字段规则

以下字段固定归为系统字段，排序序号 = 0，置于 Excel 顶部：

- `first_inserted_dt`
- `etl_dt`
- `last_updated_dt`

## 主键规则

- ODS CREATE TABLE 中 `UNIQUE KEY(field)` 对应的字段，物理主键 = 是
- 其余字段物理主键 = 否，业务主键 = 否

## COMMENT 解析规则

ODS/DIM COMMENT 格式：`"中文说明,示例值"`

- 按**第一个逗号**分割
- 前段 → 字段名、字段释义
- 后段 → 字段备注（示例值）
- 无逗号时整段作为字段名，备注为空
