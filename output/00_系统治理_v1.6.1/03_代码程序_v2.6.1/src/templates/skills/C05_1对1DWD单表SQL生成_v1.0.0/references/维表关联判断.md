# 维表关联判断

## 触发信号（按优先级）

扫描 ODS 字段列表，按以下顺序命中即用，不再继续检查同类维表：

### dim_shop

| 优先级 | ODS 字段 | 命中档案 | 关联方式 |
|------|---------|--------|---------|
| SHOP-1 | `sid` 或 `lx_shop_id` | DIM-SHOP-002 | `src.sid = dim_shop.lx_shop_id` |
| SHOP-2 | `shopid` 或 `saas_shop_id` | DIM-SHOP-001 | `src.shopid = dim_shop.saas_shop_id` |
| SHOP-3 | `shopname`/`acc_name` + `platform` + `sitename`/`country` 组合 | DIM-SHOP-003 | 三字段联合关联 |
| SHOP-4 | `seller_id`/`sellerid` + 国家码字段 | DIM-SHOP-004 | sellerid + GB→UK 归一 |

### dim_msku

| 优先级 | ODS 字段 | 命中档案 |
|------|---------|--------|
| MSKU-1 | 有 `asin` 且已能拿到 `shop_id` | DIM-MSKU-001 |
| MSKU-2 | 有 `asin` + 账号/站点组合，无 `shop_id` | DIM-MSKU-002 |

## JOIN SQL 片段

### DIM-SHOP-001

```sql
left join (
    select saas_shop_id, shop_id
    from glcd.dim_shop_ich_dd
    where is_valid = 1
) dim_shop
    on src.<shopid_field> = dim_shop.saas_shop_id
```

补出字段：`dim_shop.shop_id`

### DIM-SHOP-002

```sql
left join (
    select lx_shop_id, shop_id
    from glcd.dim_shop_ich_dd
    where is_valid = 1
) dim_shop
    on src.<sid_field> = dim_shop.lx_shop_id
```

补出字段：`dim_shop.shop_id`

### DIM-SHOP-003

```sql
left join glcd.dim_shop_ich_dd dim_shop
    on src.<acc_name_field> = dim_shop.acc_name
   and src.<platform_field> = dim_shop.platform_name
   and src.<country_field>  = dim_shop.country
   and dim_shop.is_valid = 1
```

补出字段：`dim_shop.shop_id`

### DIM-SHOP-004

```sql
left join (
    select lx_seller_id, country_code, shop_id
    from glcd.dim_shop_ich_dd
    where is_valid = 1
) dim_shop
    on src.<sellerid_field> = dim_shop.lx_seller_id
   and if(src.<location_field> = 'GB', 'UK', src.<location_field>) = dim_shop.country_code
```

补出字段：`dim_shop.shop_id`

### DIM-MSKU-001

```sql
left join (
    select msku_id, shop_id, child_asin, msku,
           row_number() over(
               partition by shop_id, child_asin
               order by start_dt desc, msku_sort desc
           ) rk
    from glcd.dim_msku_ich_dd
    where is_valid = 1 and usable_scene = 0
) dim_msku
    on src.<asin_field> = dim_msku.child_asin
   and dim_shop.shop_id = dim_msku.shop_id
   and dim_msku.rk = 1
```

补出字段：`dim_msku.msku_id`、`dim_msku.msku`

## 无触发信号时

触发信号均未命中 → 不关联维表，继续生成，在输出文件顶部写：

```
-- ⚠️ DIM_CHECK: 未检测到标准维表触发信号，如需维表关联请人工确认
```
