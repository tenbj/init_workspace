# 多库说明

## 可用库

| 库名 | 用途 |
|------|------|
| `cbebg` | 主业务域（默认），含 dwd / ods / ads 层 |
| `glcd` | 跨域维度，dim 层为主 |
| `test` | 临时验证库，由 `temp-data-storage` 技能写入 |

不确定有哪些库时，先调 `client.get_databases()` 获取完整列表。

## 跨库查询

SQL 中使用全限定名，禁止用 `USE database` 切库：

```sql
SELECT a.shop_id, b.shop_name
FROM cbebg.dwd_shop_base_flu_dd a
JOIN glcd.dim_shop_ich_dd b ON a.shop_id = b.shop_id
WHERE a.dt = '2026-04-17'
```

## 完整探查链

```python
dbs    = client.get_databases()                          # 1. 列出所有库
tables = client.get_tables("cbebg")                     # 2. 列出库下所有表
fields = client.describe_table("dwd_shop_base_flu_dd")  # 3. 查看表结构
result = client.query("SELECT ...")                      # 4. 执行查询
print(client.format_result(result))                     # 5. 输出结果（必须 print）
```
