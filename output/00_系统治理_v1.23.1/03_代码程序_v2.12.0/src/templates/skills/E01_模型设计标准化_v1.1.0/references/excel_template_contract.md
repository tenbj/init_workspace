# Excel 模板契约

## 工作簿识别

模型设计工作簿至少应包含：

- `1.1 模型设计目录`
- `1.2 模型依赖说明（数据流）`
- 一个或多个实体设计 sheet

标准库工作簿至少应包含：

- `规则标准库`
- `映射标准库`

## 实体设计 sheet 识别

脚本通过表头行识别实体设计 sheet。表头行必须同时包含：

- `字段名`
- `字段描述`

常用列：

| 标准列 | 说明 |
|---|---|
| `字段分类` | 字段一级分类 |
| `二级分类` | 字段二级分类 |
| `字段序号` | 字段序号 |
| `字段名` | 当前字段名 |
| `字段数据类型` | 数据类型 |
| `字段描述` | 中文字段描述 |
| `参考字段` | 来源或参考字段 |
| `参考库表` | 来源或参考表 |
| `是否保留` | 字段控制标识；值为“否”时该字段不进入 AI 评审，跳过原因写入 `skipped_fields.jsonl` |
| `是否删除` | 字段控制标识；值为“是”时该字段不进入 AI 评审，跳过原因写入 `skipped_fields.jsonl` |
| `是否为枚举字段` | 枚举权威标识；有值时以表格记录为准，AI 不得自行反向猜测或覆盖 |
| `是否主键字段` | 主键标识 |
| `是否业务主键` | 业务主键标识 |
| `备注` | 补充说明 |

## 解析边界

- 隐藏 sheet 默认不作为待处理实体 sheet，但会出现在工作簿清单中。
- 带有实体表头的可见 sheet 会进入 `entity_fields.jsonl`。
- 模板 sheet、附录 sheet、评审清单、内容概览不进入字段评审。
- 若模板缺列，脚本写入 `template_check.json`，不自行修复。

## Excel 维度问题

部分 workbook 的 sheet dimension 可能错误，导致 `openpyxl` 只读到 `A1`。解析脚本使用 `.xlsx` XML 直接解析单元格，避免维度误判。
