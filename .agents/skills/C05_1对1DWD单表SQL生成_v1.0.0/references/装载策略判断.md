# 装载策略判断

## 判断规则

读 ODS SQL 的 WHERE 子句，检查是否含参数占位符：

| ODS SQL 特征 | 策略 | DWD 表名后缀 | INSERT 方式 |
|------------|------|------------|-----------|
| WHERE 含 `${StartTime}` / `${EndTime}` / `${bizdate}` | 增量 ilu | `_ilu_dd` | DELETE + INSERT INTO |
| 无参数占位符，或无 WHERE | 全量 flu | `_flu_dd` | INSERT OVERWRITE |

## 时间窗字段提取

增量表的时间字段从 ODS WHERE 子句中提取：

```
CAST(<time_field> as Date) >= '${StartTime}'
```

`<time_field>` 即为时间窗字段，DELETE 和 INSERT 均使用同一字段。

## SQL 骨架

### 增量（ilu）

```sql
delete from cbebg.<dwd_table>
where CAST(<time_field> as Date) >= '${StartTime}'
  and CAST(<time_field> as Date) <= '${EndTime}';

insert into cbebg.<dwd_table>
(
    <target_fields>
)
select
    <select_exprs>,
    NOW() as first_inserted_dt,
    NOW() as etl_dt,
    NOW() as last_updated_dt
from cbebg.<ods_table> src
<dim_join>
where CAST(src.<time_field> as Date) >= '${StartTime}'
  and CAST(src.<time_field> as Date) <= '${EndTime}';
```

### 全量（flu）

```sql
insert overwrite table cbebg.<dwd_table>
(
    <target_fields>
)
select
    <select_exprs>,
    NOW() as first_inserted_dt,
    NOW() as etl_dt,
    NOW() as last_updated_dt
from cbebg.<ods_table> src
<dim_join>;
```

## 注意

- 全量的 `INSERT OVERWRITE` 必须显式写目标字段清单
- 增量的 DELETE 和 INSERT 使用同一时间过滤字段
- `ich`（拉链表）和 `fsn`（全量历史切片）不在生成范围，遇到跳过
