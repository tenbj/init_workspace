# 输入与输出契约

必需输入：dws 可执行路径或 PATH、已确认 profile、recipient_name、content_file、request_id、receipt。独立调用没有默认收件人；已核对同名人的 openDingTalkId 可用 recipient_id 指定，但仍必须出现在当前账号此次查询结果中。

```text
python .agents/skills/F05_钉钉CLI消息发送/scripts/send_message.py --dws <dws路径> --profile <实际profile> --recipient-name <姓名> --content-file <正文UTF8文件> --request-id <稳定业务ID> --receipt <任务目录>/通知回执.json
```

默认只查询/预检并保存 prepared，不发送；用户或明确调用的上游技能已授权时，同一命令加 `--execute`。再次执行同一回执：成功直接返回；已取得任务只查状态；未知且无任务不重发。不能新建业务 ID 绕过防重。

正文文件可由调用方按 `assets/消息正文模板.txt` 生成；模板占位符必须替换。脚本使用参数数组，不通过 shell 拼消息。自动补齐 `（codex自动发送）`。

最小回执：profile、recipient_name/已核实ID、request_id、正文与摘要、幂等键、prepared/send_started/pending/unknown/failed/success、openTaskId、sendStatus、openMessageId、openConversationId、时间、最小错误类型。仅保存本次对象及消息，不保存令牌、完整通讯录或无关历史聊天。

调用方指定输出到所属子项目任务目录。回执和旁路锁用于恢复，不当作可随意清理的临时文件。活跃锁不删除；进程崩溃留下锁时先确认没有其他发送进程，再人工处理并读取已有回执，不能顺手重发。

脚本退出码 0 表示预检完成或真正 SUCCESS，需同时查看 status；2 表示未完成/失败/身份或防重阻断，不能仅凭退出码推断送达。网络异常转环境分册，不触发视觉回退。
