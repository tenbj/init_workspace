# 独立运行与迁移规则

## 独立性

H01 是已注册的自包含 Harness Skill：

- 不调用、不路由、不依赖任何外部系列 Skill。
- 所需流程、模板、脚本、合同和验证都在本能力包内。
- 外部方法可以作为灵感，但不得成为运行前置条件。

## 输入不足

1. 不影响产品范围的缺口：采用保守假设，并在 PRD 与输入对象中记录。
2. 会改变用户、范围、核心流程或数据责任的缺口：暂停生成并请求确认。
3. 不得用“先出一个 HTML 再说”绕开输入合同。

## 时间压力

可以降低视觉精细度，不能删除协议层：

- Human Layer：保持核心流程可体验。
- Machine Layer：保持所有文件和 ID 追踪关系。
- Evaluation Layer：必须运行验证器。

## 后续编号迁移

HH 是临时系列。本项目已将 HH02 → H01、HH03 → H02；以下是编号迁移时必须维持的兼容规则：

1. 只更换稳定 Skill ID、注册项、命令入口和展示名。
2. ASOC 版本、输入输出 Schema ID、文件合同和验证语义保持兼容。
3. 如发生不兼容协议变更，升级 ASOC 主版本，不用编号变化掩盖破坏性变更。
