# 原型产物规格

## 文件合同

| 文件 | 最低内容 |
|---|---|
| `manifest.json` | ASOC 版本、Intent、全部产物路径和分层 |
| `prd.md` | REQ ID、用户场景、范围、验收标准、假设 |
| `prototype.html` | 自包含、可操作、交互元素带 `data-event-id` |
| `ui.schema.json` | 页面、组件、组件状态、事件引用 |
| `interaction.json` | 事件、组件、触发器、前后状态、动作 |
| `user-flow.md` | `START`、决策/异常路径、`END` |
| `api.yaml` | OpenAPI、请求/响应、至少一种错误响应 |
| `database.sql` | 支撑状态与关系的数据模型，或不适用标记 |
| `evaluation/report.json` | 校验时间、结论、错误列表 |

## 追踪规则

- `REQ-*` 从 PRD 追踪到页面、交互或验收规则。
- UI 组件 `id` 在同一页面唯一。
- UI 的每个 `events[]` 必须对应 `interaction.json` 中的事件 `id`。
- HTML 的每个交互控件必须通过 `data-event-id` 对应同一个事件。
- 交互中的 `component_id` 必须存在于 UI Schema。
- 交互的 `from_state`、`to_state` 必须属于页面状态。
- 交互调用的接口路径必须能在 `api.yaml` 中找到。
- 数据库必须能表达接口依赖的关键实体与状态。

## HTML 原型完成标准

- 不是静态截图：主要用户路径可以点击完成。
- 覆盖默认、加载、空、错误、成功等适用状态。
- 不依赖外部构建工具即可打开。
- 所有按钮都定义 `data-event-id`，并在脚本中绑定行为。
- 视觉细节服务于信息层级和任务完成，不代替机器协议。

## 响应式增量合同

新能力包默认声明 `responsive-web-v1`，UI包含 `responsive`，manifest登记 `evaluation/responsive-report.json`。按 `移动端兼容设计与验收.md` 完成布局与行为实测，报告绑定HTML和配置哈希。ASOC1.0基础字段保持兼容；旧包基础结构验证不受影响，当前H01设计工作流使用 `--require-responsive` 完成新验收。
