# H01 原型能力包检查清单

## 合同

- [ ] Intent、输入、输出、流程和失败处理均已定义
- [ ] 八个核心产物齐全，验证报告存在且 `valid=true`
- [ ] 不适用项保留文件并写明理由

## Human Layer

- [ ] PRD 有 REQ ID、用户价值、范围、假设和验收标准
- [ ] HTML 可直接打开，核心路径可点击完成
- [ ] User Flow 包含开始、成功、异常和结束

## Machine Layer

- [ ] 页面、组件、状态、事件均有稳定 ID
- [ ] 所有按钮均有 `data-event-id`
- [ ] UI、Interaction、HTML 的事件 ID 一致
- [ ] API 有请求、成功响应和错误响应
- [ ] 数据模型支持关键实体、关系与状态

## Evaluation Layer

- [ ] 自动验证器返回零错误
- [ ] 人工检查未发现不可达路径或无响应控件
- [ ] 产物不依赖其他系列 Skill 即可解释和执行

## 手机与桌面兼容

- [ ] responsive合同声明布局、视口及真实REQ关联核心流程
- [ ] 360/390/430px及桌面对照实际浏览器验收通过，无页面横向溢出
- [ ] 关键操作触达区、输入字号、可见弹窗和固定栏遮挡检查通过
- [ ] 人工复核首屏主要任务、长内容、父子返回、错误/空态和底部最后一项
- [ ] 报告绑定当前HTML与场景哈希；明确真机/软键盘覆盖或未验收范围

## 通用交互要求（按功能适用性验收）

- [ ] 并列子功能使用Tab，每次只显示当前组；连续必填字段不被强拆
- [ ] 账号按钮展开菜单不直接跳转；菜单包含退出登录，支持外部关闭、Esc及键盘访问
- [ ] 主导航聚焦业务，账号设置/个人接入管理不在侧栏重复出现
- [ ] 辅助管理默认弹窗，复杂页面例外有设计说明；弹窗内部保留Tab
- [ ] 关闭后原页面、筛选、选择、滚动及焦点恢复；未保存修改有保存/放弃/继续编辑处理
- [ ] 桌面居中、手机适配弹层；长内容、关闭与主要按钮可达，Tab支持键盘和触摸
- [ ] 标题说明和按钮无无意义重复；成功刷新相关内容，失败保留输入并可重试
- [ ] 适用行为已进入PRD/UI/Interaction及浏览器验收证据；不适用项说明理由，未验证项不标通过
