# H01 原型能力包检查清单

## 合同

- [ ] Intent、输入、输出、流程和失败处理均已定义
- [ ] 八个核心产物齐全，验证报告存在且 `valid=true`
- [ ] 不适用项保留文件并写明理由

## Human Layer

- [ ] PRD 有 REQ ID、用户价值、范围、假设和验收标准
- [ ] HTML 可直接打开，核心路径可点击完成
- [ ] User Flow 包含开始、成功、异常和结束

## Machine Layer

- [ ] 页面、组件、状态、事件均有稳定 ID
- [ ] 所有按钮均有 `data-event-id`
- [ ] UI、Interaction、HTML 的事件 ID 一致
- [ ] API 有请求、成功响应和错误响应
- [ ] 数据模型支持关键实体、关系与状态

## Evaluation Layer

- [ ] 自动验证器返回零错误
- [ ] 人工检查未发现不可达路径或无响应控件
- [ ] 产物不依赖其他系列 Skill 即可解释和执行
