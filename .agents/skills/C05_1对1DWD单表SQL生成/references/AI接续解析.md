# AI 接续解析

脚本只负责辅助生成。遇到脚本异常、嵌套投影、通配符未展开或字段提取不完整，保留原始错误，直接由 AI 读取源 SQL、明确最终输出字段并完成生成，无需用户再次授权同一任务。

## 字段依据

1. 有实际 ODS 建表语句时，以其列名和类型为引用依据；需要获取时调用 `C03`。字段值、粒度及关联验证调用只读 `C02`。
2. 源 SQL 用于追踪最终投影、表达式和别名。递归展开 `SELECT alias.* FROM (...) alias`，识别 CTE、别名和嵌套查询；区分源字段与上游计算表达式。
3. 源代码与实际表不一致时，引用实际表字段，在说明中列出差异；不得把上游源系统表别名或表达式直接拼成 `src.<表达式>`。
4. 尚无实际结构时，可依据完整且可验证的输出投影生成，清楚记录类型缺口；无法确定的字段不得编造，也不得声称字段覆盖通过。

## 一对一的判断层级

一对一是当前落地 ODS 到 DWD 的粒度关系。上游抽取 SQL 中的 JOIN、GROUP BY、DISTINCT 或窗口函数不能直接作为拒绝依据；已经落地的计算结果应从 ODS 列读取，不重跑上游逻辑。

如果本次 DWD 转换自身需要聚合、去重或展开，说明其粒度影响，不把这种加工伪装成一对一清洗。维表关联必须检查匹配基数；无法保证每条 ODS 最多匹配一条时，先交付不扩行的一对一版本，把关联条件列入待处理。

## 生成与验证

- 遵循既有命名、装载与审计字段规则；不确定项用就地 `TODO_CONFIRM` 和同目录说明记录。
- 已确认源字段存储描述值时，直接映射 `*_desc`；缺少映射的编码才补 NULL 描述占位。
- 逐列建立“实际 ODS 列 → 最终 DWD 字段”的对应，核对覆盖、顺序、唯一命名及时间类型。
- 可访问数仓时，对最终 SELECT 做只读 EXPLAIN 和行数/唯一性核验。目标表尚未存在时验证 SELECT，明确未验证目标表 INSERT 兼容性，不执行建表或装载。
- 输出最终 SQL 和说明，记录脚本失败原因、AI 接续依据、实际完成的验证及剩余缺口。
