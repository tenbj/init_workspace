# 运行截图留证

每个实际配置指标运行后保存一张真实浏览器PNG。先按本Skill运行核验确认本次新记录，先收起左栏并关闭弹窗，使列表中的指标/模型身份、运行时间和正常或异常清晰可读；quality_value另从同次记录核对。不能用SQL文本、报告、生成图片或旧记录冒充本次截图。

记录技术表、模型编号、指标名/编号、运行时间、截图时间、结果、数值、无凭证页面URL、截图路径及文件哈希。不要覆盖历史图片。运行成功但截图失败时只回到同次记录补图，不重复触发任务。

批量编排时按C17输出契约保存独立运行证据和截图元数据，调用其attach登记，并检查HTML运行截图列和模型详情的缩略图与弹窗。单独使用C15时也须在交付HTML提供原图入口；截图文件随交付目录保存。

SQL保存回读完成、运行结果和截图留证独立记录。缺图不能回退平台已保存事实，也不能声称完整交付。用户要求仅一个案例或不补历史时遵循该范围；本次B0001—B0003历史不批量补图。


## 截图与展示优先规则（2026-09-29）

先收起平台左侧菜单，关闭运行记录弹窗，在指标列表完整显示目标名称、模型、最新监控时间和结果后截图。若已有“展开左侧菜单”按钮，说明已收起，不重复切换。列表一张图能识别目标和结果时，只交付这一张；不要默认再截运行记录弹窗或身份配套图。结果数值若列表不显示，可从同次运行记录核对并保存为结构化证据，注明quality_value_visible=false，不声称列表截图含数值。

HTML清单和详情只显示图片缩略图，不显示“查看截图”等文字链接或时间说明；时间仍保留在台账和无障碍标签。点击缩略图在当前页面弹窗放大，支持原尺寸缩放、关闭按钮、Esc与遮罩关闭、键盘焦点返回。不新开标签页。无截图显示短横线，具体原因保留在无障碍标签。

用户要求重拍同次结果时不得重复运行。旧图保留在证据文件和历史，台账旧项display=false，正常展示只保留新列表图。未来截图采集与HTML验收都按此规则执行。
