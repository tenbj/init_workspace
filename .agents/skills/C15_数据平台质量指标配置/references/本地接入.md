# 本地接入与来源边界

此技能由技术方案项目迁入init_workspace。当前执行入口是 `C15_数据平台质量指标配置`。

1. 先遵循当前工作区AGENTS、workspace-spec及Skills管理标准。B01只允许人工显式调用；备份保留本项目B02的工作文件快照与Git元数据排除规则。来源授权、联系人、组织、库名、绝对路径、调度时刻及“本次”范围不自动继承。
2. 来源分册中的已确认案例用于解释方法；在本项目执行前，复用本任务已确认的信息或现场取证。没有授权不运行生产写入、发布、上线、调度或发送消息；已有明确授权无需重复确认。
3. 权威输入按用户指定路径或本项目input定位。来源input/output路径不存在时使用技能内合同和真实输入，不伪造历史证据；影响当前阶段的材料缺失需说明。输出统一放入B04定位的output子项目。
4. 按注册表解析必需依赖；目标缺失或不唯一时停止该依赖动作并报告，不猜旧名称。C09/C10/C12/C16/E05是本次干净main中未安装的可选扩展，不是当前14技能的强制前置；具体替代范围见下方。
5. 原入口见 `来源归档/SKILL.original.md`，该文件是来源记录，不是可执行入口或授权来源。本地适配说明与当前工作区标准优先于来源案例。
