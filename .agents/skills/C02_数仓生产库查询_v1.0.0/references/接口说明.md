# 接口说明

## `DorisQueryClient(database, row_limit)`

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `database` | `"cbebg"` | 连接的默认库 |
| `row_limit` | `500` | 无 LIMIT 的 SELECT 自动截断行数 |

---

## 查询

### `query(sql, database=None) → Dict`

执行 SQL，返回结构化结果。

```python
result = client.query("SELECT shop_id, cnt FROM dwd_shop_base WHERE dt='2026-04-17'")
```

返回结构：

| 字段 | 类型 | 说明 |
|------|------|------|
| `data` | `List[Dict]` | 行数据 |
| `row_count` | `int` | 实际返回行数 |
| `auto_limited` | `bool` | 是否自动追加了 LIMIT |
| `sql_executed` | `str` | 实际执行的 SQL |
| `error` | `str \| None` | 失败时为错误字符串，成功为 None |

**始终先检查 `error`，再使用 `data`。**

---

## Schema 探查

### `get_databases() → List[str]`
列出所有可用库名。

### `get_tables(database=None) → List[str]`
列出指定库下所有表名。

### `describe_table(table, database=None) → List[Dict]`
获取表字段结构（Field / Type / Null / Key / Default / Extra）。

> **写 SQL 前先 describe**：对陌生表调用此方法确认字段名和类型，避免猜字段名。

---

## 开发辅助

### `explain(sql, database=None) → str`
获取 SQL 执行计划，用于 DWD 开发调优。

---

## 格式化输出

### `format_result(result) → str`
将 `query()` 结构化结果渲染为 Markdown，含元信息头（行数、是否截断、错误提示）。

### `format_to_markdown_table(data) → str`
仅渲染数据部分为 Markdown 表格，不含元信息头。

---

## 标准调用收口

```python
result = client.query("SELECT ...")
if result["error"]:
    print(result["error"])
else:
    print(client.format_result(result))
```
