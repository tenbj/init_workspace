# 输出契约

复用当前业务子项目和 B08 任务，不建重复话题；用 [更新记录模板](../assets/更新记录模板.md) 保存可恢复证据。

| 类别 | 记录 |
|---|---|
| 身份 | 模型/环境、项目/工作流/节点名称及ID；右上搜索框完整搜索词与准确匹配结果 |
| 来源 | 仓库、相对路径、ref和提交、读取时间 |
| 原状态 | 工作流/原定时、执行策略、范围、相关参数；保存后策略是否保持原值 |
| 差异 | 修改参数、语义变化、SQL/columns及转义检查 |
| 整块录入 | 实际整块复制/粘贴方式，来源文件/ref，字符/换行数或哈希；逐字输入不可作为替代 |
| 保存前回读 | 本次唯一临时标识已被编辑器复制替换、取得全文、仅CRLF/LF归一后的逐字比较结果；不保存敏感原始正文 |
| 保存 | 持久化版本、代码全文与来源比较、非授权参数未变、未提交停点；与编辑器回读分开记录 |
| 停止与恢复 | 用户停止时刻、执行层实际停止证据、浏览器/草稿、是否保存/启动实例、定义及原定时最后确认状态；恢复连接及真实状态检查结果 |
| 运行 | 实例ID、起止时间、实际范围、工作流整体终态；成功不为凑记录打开节点详情/日志，数据量通过只读查询核验；失败记录失败节点及脱敏原因。用户禁止试跑则明确未执行 |
| 收尾 | 最终工作流/定时、恢复回执或未恢复原因 |
| 遗留 | 历史补数、全量验证等未做事项 |
| 正式更新 | 参数契约、可重建日期、数据量和批次依据；每批启动参数、实例ID、终态、失败原因与重试调整；最终日期覆盖、数量和字段结果 |
| 执行前公布 | 对话中的完整分段计划、实际一次执行范围、总运行次数；不能用工作区文件代替对话公布 |
| 补数方式 | 区分参数区间运行与按调度日期拆分实例；补数记录依赖模式、串并行/并行度、执行顺序、时区、cron、调度日期、启动参数是否为空、预期实例数与既有空白日期处理 |
| 日期与负载 | 业务日期范围的查询依据、业务日期到调度日期的映射、完整范围/本批范围；单任务及同时运行任务合计量，避免用历史总量当并行负载 |
| 监控与通知 | 检查时刻、实例状态数、去重成功日期数/计划日期数、未完成/失败日期；提交并行度与实际运行状态分别记录，后台监控是否真实建立及完成后关闭情况 |
| 仅SQL与临时策略 | 用户授权、SQL起点和TASK_ONLY、被跳过节点；停队列后的成功日期与缺口重算；原始/临时/恢复策略和版本、实际并发、原定时恢复回读。STOP与旧失败单列，不计入成功覆盖 |
| 专用补数副本 | 仅海豚补数模式默认使用：来源/副本完整名称及ID映射、SQL和参数回读、依赖节点删除及剩余连线核验、定时关闭、执行策略、补数结果、完成后下线及原流程保持证据；复制不隔离生产表写入 |
| 参数范围运行 | 原工作流、起止启动参数、分批串行；不建副本、不删原依赖。先记录DAG判断、运行起点/方向、跳过依赖和后续节点逐项取舍理由；必要后续节点须执行，不固定TASK_ONLY或TASK_POST。来源范围行数、实际输出量、实例耗时分别记录，不把来源总量当作实际扫描量或排序量 |

阶段区分：草稿、已保存未上线、已上线未试跑、试跑中、失败待处理、试跑成功待恢复定时、正式更新待执行/执行中/待核验、已完成（或定时不适用）。授权包含历史更新时，不能把试跑成功及定时恢复当作最终完成；仅要求局部动作就交付该停点，不硬凑完成。

“正在停止/尚未确认停止”与“已确认停止”分开；取消等待不改变为已确认停止。平台模型目录状态、海豚定义、定时、实例终态、实体加载结果分别记录；平台待上线不能推断海豚未上线，实例SUCCESS也不能替代实体数据验收。

最终件是当前子项目过程/验收记录；中间件只保留必要脱敏差异与回读证据。不存完整原始日志、请求头。无生产写入脚本，scripts保留占位；自动化另按确认接口实现。

回复说明结果、实际范围与定时状态，B08覆盖当前状态；总业务目标仍有工作时不提前关闭任务。
