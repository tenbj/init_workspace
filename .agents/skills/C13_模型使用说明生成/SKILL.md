# 模型使用说明生成

## 这项技能解决什么问题

- 为一张数仓表或视图生成面向数据使用者的说明：一行代表什么、字段如何解释、怎样查询和关联、结果有哪些限制。
- 默认使用统一九章目录，按分层职责和模型类型补充规则，交付同源 Markdown 与离线单文件 HTML。

## 先读哪些本地知识

- 先读 `references/本地适配说明.md`，确认路径、依赖及来源授权的适用范围。

- 先读 `references/取证与验证.md`，确定目标与可访问证据；再读 `references/目录与分层规则.md` 选择适用内容。
- 写文档前读 `references/输出契约.md`，使用 `assets/模型使用说明模板.md`；用户指定范围和格式优先。

## 固定动作

1. 定位目标库表、环境、代码入口与读者，记录仓库版本和项目分层约定。仅在目标不唯一等关键缺口影响执行时提问，其余留待确认。
2. 从目标写入或视图逻辑逆向追踪实际依赖，核对 DDL、配置及现有口径资料；记录关键结论的来源和冲突，不要求用户重抄元数据。
3. 在已有授权和查询约束内，通过 C03 获取 Doris DDL、通过 C02 做有界只读验证。无法访问时继续生成源码版，并注明未验证；不自动同步或重置仓库。
4. 按九章模板编写正文，解释业务粒度、字段、加工、时间、聚合与关联规则。区分实现事实、数据验证、业务约定、推断；缺失、不适用、冲突分别表达。
5. 为关键使用场景编写带参数说明的只读 SQL，标明“仅生成 / 已执行 / 已对账”及实际验证范围。粒度或关联键不清楚时不宣称可用于正式统计。
6. 按 `references/生成与验收.md` 从 Markdown 生成 HTML，检查同源、九章目录、导航和使用限制；选择草稿、限定范围可用或正式状态。
7. 交付文档、证据与关键缺口。按 B04 定位子项目，修改按 B02，进度与记忆分别按 B08、B03 收尾。

## 什么时候再读本 skill 的 references

- 寻找输入、追踪依赖、处理冲突或安排验证：读 `references/取证与验证.md`。
- 确定九章内容及 ODS/DIM/DWD/DWS/DMT/ADS、快照/维度/映射差异：读 `references/目录与分层规则.md`。
- 确定路径、状态与失败交付：读 `references/输出契约.md`。
- 运行渲染器、检验离线与打印效果：读 `references/生成与验收.md`。
- 审查能力包结构：读 `references/结构融合索引.md`。

## 边界

- 生成使用说明，不改模型、生产数据、调度或权限，不自动部署或发送文档。
- 实现事实不等于业务默认口径；有限数据验证不等于全量历史保证；技术键唯一不等于业务粒度正确。
- 只有代码和查询入口也可启动首版；依据不足时明确留白，不能编造字段含义、币种、时区、更新周期、负责人或替代模型。
- 只解释影响使用的加工逻辑，不逐个翻译 CTE；本技能不替代模型命名评审、Excel 交付清单或报表操作说明。
- 不把连接密码、凭据或未经脱敏的业务明细写入文档和证据文件。
