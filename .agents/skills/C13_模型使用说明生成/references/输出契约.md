# 输出契约

## 最终件与工作目录

- 默认交付 `{NN}_{模型名}使用说明.md` 和同基名 `.html`。正文九章、可编辑 Markdown 为唯一正文源；HTML 由脚本生成，不另写一套正文。
- 按 B04 定位子项目，正式文档进入 `01_问题答疑` 或 `02_课题研究`，同步 `目录.md`；命名遵守当前工作区标准。
- 在 `03_代码程序/模型使用说明/<库名.模型名>/` 保存 `证据清单.md`、只读验证 SQL、脱敏结果摘要、采集 DDL 和 `生成校验.json`。批次需区分环境/版本，不能误覆盖另一模型。
- 第 9 章自带关键依据摘要，离线 HTML 单独打开即可读懂主要结论；引用详细 SQL/证据文件时一并提供。需内嵌的图片放 Markdown 同目录或下级目录，Markdown 交付连同图片目录携带。
- HTML 使用侧边目录、章节定位及高亮、窄屏菜单、可横向滚动的表格、打印样式。CSS/JS/本地图片内嵌，无 CDN；打印可另存 PDF，但本脚本不生成 DOCX/PDF。

## 文档状态

| 参数 | 展示 | 使用条件 |
|---|---|---|
| `draft` | 草稿 | 默认；关键粒度、关联、统计口径不清楚或未完成内容核对 |
| `limited` | 限定范围可用 | 已有证据支持部分用途，正文首页明确可用范围、不能使用的场景、验证范围和剩余缺口 |
| `final` | 使用说明 | 适用范围内的关键规则、示例与证据经过语义审查，无影响该范围的未解决事项；不适用项仍保留说明 |

状态由内容审查决定，不由脚本或查询成功自动授予。原始模板和虚构演示必须为草稿。有限范围可用不代表生产审批或上线授权。

第 9.3 节始终叫“待确认事项及其对使用的影响”；没有未决事项时写明当前适用范围内无已识别未决事项，不能因标题含“待确认”误拒绝正式文档，也不能为了变成正式文档删除真实缺口。

## 失败与交付

- 取不到数据库、调度配置或业务资料时仍可形成有据的草稿，记录缺失、失败和使用影响；无任何有效证据时只交付缺口清单。
- 渲染器拒绝覆盖现有输出（除非备份后显式 `--force`），输入永不修改；结构或模板检查失败时不覆盖旧 HTML。
- 生成校验 JSON 记录源 SHA-256、九章与目录、图片、占位符数量和渲染检查；不代表业务/SQL正确性。写输出过程中发生文件系统错误时检查实际文件，不能把部分落盘称为完整交付。
- 最终回复给文件链接、状态、已完成验证和关键限制；不能只给生成过程或渲染命令。

本技能的离线渲染器与视觉模板派生自 F03，作为独立本地副本随本技能维护；运行时不依赖 F03 的文件路径。保留侧栏、打印与同源校验，增加九章检查及限定范围状态。数据库访问按需依赖 C02/C03，依赖稳定编号按工作区 SSOT 解析，不硬编码版本化路径。
