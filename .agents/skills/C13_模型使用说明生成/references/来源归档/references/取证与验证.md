# 取证与验证

## 输入与启动条件

最小启动输入是可定位的目标表/视图，以及可读源码、DDL 或既有说明之一；代码仓库与只读查询能力是推荐组合。若只有表名且任何证据均不可访问，交付输入缺口清单，不生成假装完整的说明。

| 输入 | AI 自行提取的内容 | 缺失时处理 |
|---|---|---|
| 目标与项目约定 | 库表、环境、读者、分层定义、模型类型、命名约定 | 多个同名目标无法区分时询问；其他标待确认 |
| 现行仓库 | DDL、ETL、DataX、函数、参数、必要上下游、提交号和本地改动 | 记录实际可读版本，不声称就是生产版本 |
| 数据库读取入口 | 现行结构、视图定义、键与受限验证 | 不可连接则记失败，保留源码说明，不虚构数据结果 |
| 调度和运行资料 | 周期、时区、参数、依赖、运行结果、回补和删除 | SQL 时间边界可解释；实际周期和参数不能猜测 |
| 业务与消费资料 | README、需求、口径、报表 SQL、已验证问答 | 消费代码是一个使用案例，不能自动上升为全局默认 |
| 查询约束 | 允许库表、时间范围、超时、成本、敏感字段处理 | 优先复用已有约束；无可限定范围时只提验证方案 |

不把人工字段字典设为启动前置；可从代码和数据库取得的内容由 AI 提取。用户提供一个目标后，在现有授权内查找入口，不重复索取已知信息。

## 依赖读取边界

1. 从目标落表或视图开始，逆向追踪实际 FROM/JOIN/CTE、分支、函数和配置；记下文件路径、行号/代码片段、提交号、读取日期。
2. 对关键字段追到足以解释来源、过滤、去重、计算、映射和时间语义的位置。遇到不可读外部源即记录边界；不用全仓扫描替代必要依赖分析。
3. 区分仓库实现、生产对象定义、调度实际运行和业务约定。发现差异分别列出证据、影响章节和待解决问题，不静默选一份覆盖另一份。
4. 已有本地代码可直接只读检索。代码更新另按用户授权处理；本技能不自动调用会覆盖本地漂移的同步动作。

## 关键结论证据表

在工作目录保存 `证据清单.md`，正文用 E01 等标识引用，并在第 9 章提供精简可读索引。

| 结论ID | 章节与结论 | 依据类型 | 来源位置/版本 | 验证范围与结果 | 状态及使用影响 |
|---|---|---|---|---|---|
| E01 | 一行代表的业务事实 | 实现事实 / 数据验证 / 业务约定 / 推断 | 文件行号、对象DDL、配置或资料段落 | 环境、日期区间、筛选、执行时间、SQL文件与结果；未验证明确写出 | 有依据 / 待确认 / 存在冲突；受影响用法 |

“依据类型”和“状态”是两个独立维度。不用笼统的“已确认”替代证据性质。业务约定应注明明确资料出处或用户确认，不自行编造审批人。

## 只读验证

- Doris DDL 获取通过 C03 的现有脚本，指定本次证据目录。执行前读取其入口与异常说明；子调用只取结构，不手写连接兜底。数据验证是上层独立步骤，通过 C02 执行，只在该步骤构造只读 SQL。子技能不可用时报告该步骤缺口，不修改子技能。
- 使用已有授权的环境、对象和约束；不在创建本技能或展示模板时自动连接生产库。示例 SQL 不会因渲染文档而执行。
- 先从元数据与源码提出假设，再做必要的小范围验证：粒度候选组合重复、关联基数/漏匹配/扩行、空值与特殊值、枚举、指标抽样与上下游对账。
- 查询使用明确时间或分区范围和必要列，遵守可用超时与成本限制。`LIMIT` 只限制返回行数，不能作为聚合全表扫描的成本保护。
- 多字段键用 `GROUP BY` 与重复组计数验证；不要靠拼接字符串去重，避免分隔符碰撞与 NULL 丢失。空值单独统计。记录原始重复和选最新/去重后的结果，不能混为一谈。
- Doris 技术键的合并行为可能隐藏入库前重复；目标表当前键唯一不能证明业务粒度正确或未发生错误覆盖。只说明可由实际结构与验证支持的结论。
- 关联要核对完整联合键、版本/有效期、方向与预期基数；验证匹配率及关联前后行数/金额。仅字段同名不能推出可靠关联。
- 一天存在数据不代表所有站点、分区或任务分支到齐。没有预期覆盖范围和运行证据时，完整性仍为待确认。
- 查询失败保留经过脱敏的错误与未完成项；不重复进行相同昂贵查询，不升级权限或改生产配置。

## 示例状态

| 状态 | 必须记录 |
|---|---|
| 仅生成 | 未运行，方言、输入参数、预期粒度、适用条件和校验方法 |
| 已执行 | 实际环境、时间、参数、范围、执行结果；只证明在该范围执行成功 |
| 已对账 | 上述信息，加对账对象、同口径规则、差异及接受标准的依据 |

未执行的 SQL 不标“验证通过”。业务参数占位符要解释并替换后才能执行；默认日期、站点、状态筛选没有依据时不能假装是已确认默认值。

## 反例

- “近30天估算销售额 / 30”可以写为折算日均估算值；不能写成真实当日交易销售额。
- 某时间范围未查出重复，只能写本次范围内未发现重复，不能保证过去和未来全程唯一。
- `${StartTime}`、`${EndTime}` 的比较符可以说明开闭区间；实际调度传参、周期、时区需另外取证。
- 单个报表过滤取消单，只能证明该报表的实现用法；推广为所有分析的默认范围需业务约定。
