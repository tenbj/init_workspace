# 命令与状态

先B02备份已有输出子项目。以下从工作区根目录运行，目录为其03_代码程序下治理目录。

```text
python .agents/skills/C17_数仓质量治理编排/scripts/govern.py --output-dir <目录> init
python .agents/skills/C17_数仓质量治理编排/scripts/govern.py --output-dir <目录> batch --input <目录>/清单来源/B0004.json
python .agents/skills/C17_数仓质量治理编排/scripts/govern.py --output-dir <目录> schedule --input <周期JSON>
python .agents/skills/C17_数仓质量治理编排/scripts/govern.py --output-dir <目录> attach --input <截图元数据JSON>
python .agents/skills/C17_数仓质量治理编排/scripts/govern.py --output-dir <目录> render
python .agents/skills/C17_数仓质量治理编排/scripts/govern.py --output-dir <目录> verify --batch B0004 --model M0033
python .agents/skills/C17_数仓质量治理编排/scripts/ledger.py --output-dir <目录> --change <变更JSON>
```

批次输入含id、name、models数组，每项connection/database/table，明确跳过时skip=true、note。编号从台账最大值加1。重复技术身份合并来源，不覆盖成果。

周期输入cycle=daily、times为全部HH:MM、source_enabled布尔、observed_at时区时间、raw原值；命令只打印推算结果，由调用方落盘并写schedule，再去平台配置回读。不能将计算成功记为平台配置完成。

台账唯一当前态，patch字段expected_revision/kind/message及models/batches/questions/config。字典递归合并，数组整列替换，追加证据时保留旧数组。stages固定C14/C15/C11，uniqueness为独立扩展；notification、schedule、screenshots分别记录。

assets/看板模板.html与scripts/ledger.py为唯一实现源。既有输出manage.py是兼容入口；输出中的模板副本不参与渲染。init拒绝覆盖台账，batch不调用平台，attach只登记已捕获的真实图片，不代替浏览器截图。

verify检查指定批次/模型的留证，不替代原子Skill核验。历史不补范围由config.screenshot_policy.no_backfill_batch_ids记录，不能扩展到未来批次。
