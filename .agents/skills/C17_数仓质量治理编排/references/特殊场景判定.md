# 特殊场景判定

依据2026-10-10逐例带教。以下为本工作区C17治理规则及本批案例边界；用户后续明确指定范围时按新指令执行。身份、类型、状态须现场核实，历史表名、节点ID和截图不能替代当前定位。

## 适配与范围

| 场景 | 判定与动作 | 证据与边界 |
|---|---|---|
| ODS关联工作流原本下线 | 标注“下线ODS，不适配”，跳过本批，不为补监控自行上线 | 依据工作流实际状态，不是模型“待上线”标签；不包括为本次编辑临时下线的流程 |
| 文件导入ODS | 注明“文件导入，不适配”，跳过当前DATAX同步行数治理分支 | 核实实际导入方式及关联ETL；不自动增加文件批次统计改造任务 |
| API采集型ODS | 注明“API采集，不适配”，跳过当前DATAX分支 | 依据实际SQL/SPARK/API节点，平台标签写DATAX不能替代节点证据；不自行改造采集程序 |
| 已有统计节点和同模型监控，用户确认无需处理 | 记“已有沿用”，结束本例；不补通知、不迁移节点、不重跑 | 保留真实节点类型；不写成本次运行通过。仅一项已有时分别记录并按原授权补缺项 |
| 已归档模型/清单错误 | 全状态检索后记录已归档；当前模型已获“不适配、跳过”指令就执行，不再追补源码 | 本批已确认子体合并模型跳过；不扩大成所有层级/所有归档模型永久禁配，其他新范围按用户要求判断 |
| DIM/CTRL暂不处理 | 只对用户本批清单设置skip及原因 | 不代表两层永久不支持DQC |
| “先记录、最后处理/最后自己补” | 保留in_scope=true及具体待补齐项，加入可恢复待办；先继续无依赖模型，前面完成后自主补齐 | 不等于用户跳过、不标完成、不重新询问已授权处理动作 |
| 后来恢复已跳过模型 | 保留先前跳过事件，更新该批来源skip=false及轮次，重新核对现场并完成 | 不删除旧证据，不继续拿旧skip阻挡；同模型不重复登记 |

“不适配”是当前分支/本批范围判定，不代表没有任何质量需求。已有本地核验保留，未配置/未运行分别记录。来源skip、in_scope、当前动作、待答问题、批次报告与HTML应同步，避免已决策仍待确认。

## 身份、来源与执行问题

- 同技术表多引擎：按C15身份门选Doris，不能因CK已上线而选CK；搜索覆盖已归档，搜不到先排除筛选问题。模型待上线、工作流下线、定时停用分别记录。
- 旧表/仓库代码/部署不一致：按[最新源码准备](最新源码准备.md)的海豚真实SQL优先分支执行；仓库维护问题单列，真实SQL核实后继续探查和配置。登记旧表与实际写入表分开记录，不用旧表历史数据替代新表证据。
- 找错模型或入口：按C15纠错恢复继续原授权闭环，不能只记录错误。模型→关联ETL→跳转工作流复用正确会话；误开独立登录页不直接认定用户未登录。
- 候选不唯一、超时、内存保护：按C11继续完整业务字段探查及分批覆盖，不交给用户解决计算量；已确认一致性可独立配置。
- 全字段GROUP BY可以用于证明完整业务重复，但属于探查SQL，不直接作为正式业务唯一性配置；正式模板以C11/C14为准。

## 完成口径、记录与交互

- 用户只验收“配上”时，正确模型SQL保存回读完成即配置完成；正常/异常如实保留。异常不作为配置缺口，不默认修数据、不改阈值；已授权通知、周期、运行、截图仍分别完成。探查不足仍是执行待办。
- 非ODS按模型最后配置时间加5分钟；月度/每周保留日期约束并核对跨日。源定时停用不等于不适配，也不授权启用源任务。ODS周期按专用对标，不套非ODS算法。
- 默认治理状态写本地`模型台账.json`、`执行日志.jsonl`并生成`治理进度看板.html`；实际DQC写数据平台。`127.0.0.1:8765`是独立服务，未建立自动同步，不能替代本地台账或隐式向服务写入。用户明确要求同步时另按该范围处理。
- 新建/沿用按批次分别标注统计节点、一致性、唯一性指标，显示真实节点类型、本轮是否修改/运行；依据修改前定义和查重证据，不凭结果状态推断。字段契约见[输出契约](输出契约.md)。
- 用户要求“一例一例”时，每次聚焦一类与代表模型，交代已完成、具体缺口及待判事项；已确认同类规则直接复用，延期事项最后自主补。
- 锁屏据当前工具回答：脚本与DOM/CDP操作通常不依赖桌面解锁，但不承诺所有环境可用；保持电脑不睡眠、网络及浏览器进程存活。登录、验证码或桌面交互确有需要时再说明用户动作，不把锁屏与睡眠/断网混为一谈。
- 每模型结束只关闭AI创建且无未保存内容的多余页，保留用户窗口；截图后恢复本任务窗口最大化并核实，再关闭该模型质量tab。独立C15同样遵循其截图规则。

逐例审计记录保存在数仓质量子项目；这里不固化临时模型ID、运行数字或未证实结论。
