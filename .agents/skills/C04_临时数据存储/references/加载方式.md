# 加载方式

## 前置条件

| 条件 | 说明 |
|------|------|
| Python 3.8+ | 硬性要求 |
| `pymysql` | `pip install pymysql`，缺失时脚本会给出提示 |

## 连接与环境变量

固定使用 `.envs/catalog.json` 中的 `doris.test.writer`，配置文件为 `.envs/doris.test.writer.env`。客户端通过 `.envs/env_manager.py` 加载；先用 `python .envs/env_manager.py check doris.test.writer` 校验本地配置。此检查不连接数据库，也不写数据。

| 变量 | 说明 |
|------|------|
| `DORIS_HOST` | 测试连接地址 |
| `DORIS_PORT` | 测试连接端口，必填 |
| `DORIS_USER` | 测试写入账号 |
| `DORIS_PASSWORD` | 测试写入账号密码 |
| `DORIS_DATABASE` | 必须为 `test` |

不再使用 `DORIS_STORAGE_*`，不扫描旧文件，不回退生产只读连接。当前进程存在不同值的同名 `DORIS_*` 时停止；生产查询和测试写入放在独立进程。登记名不证明物理集群隔离，实际写入权限以账号授权为准，写入仍须遵守当前任务范围。

## 加载代码

```python
import importlib.util, pathlib

_skill_script = pathlib.Path(".agents/skills/C04_临时数据存储/scripts/doris_storage_client.py")
spec = importlib.util.spec_from_file_location("doris_storage_client", _skill_script)
mod  = importlib.util.module_from_spec(spec)
spec.loader.exec_module(mod)

storage = mod.DorisStorageClient()
```

> 凭证只允许通过环境变量注入，禁止写入脚本、仓库、临时文件或对话记录。
