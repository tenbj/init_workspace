# 结构融合索引

> 本文件只说明 11 段 Skill 结构在 `J01_HyperFrames视频制作` 中的落点，不替代 `SKILL.md` 的触发入口。

## 一、入口定位

- **Skill**：`J01_HyperFrames视频制作`
- **职责摘要**：当用户需要用 HyperFrames 制作、编辑、复刻网页动效视频、产品演示片或动态字幕时使用；按需桥接上游完整技能包完成工程创建、质检预览与 MP4 渲染。
- **入口文件**：`SKILL.md`
- **展示元数据**：`agents/openai.yaml`
- **详细知识分册**：
  - `references/子技能路由表.md`
  - `references/工作区适配与避坑守则.md`
  - `references/输出契约.md`
  - `references/结构融合索引.md`
- **确定性执行脚本**：按方案 A 薄桥接，直接复用上游 `<UPSTREAM_SKILLS>/hyperframes/scripts/plugin-cli.mjs` 及上游 `media-use/` 内脚本；本目录 `scripts/` 暂留 `.gitkeep` 占位。
- **模板与物料**：直接复用上游 `registry/` 450+ 组件库；本目录 `assets/` 暂留 `.gitkeep` 占位。

## 二、11 段结构落点

| 结构 | 当前落点 | 使用方式 |
|------|----------|----------|
| 1. Skill Metadata | `SKILL.md` YAML frontmatter；`agents/openai.yaml` | 稳定 `name` 与触发描述在入口；三段式版本只在 `display_name`。 |
| 2. Role & Goal | `SKILL.md` 的标题与“这项技能解决什么问题” | 明确方案 A 薄桥接定位与适用视频类型。 |
| 3. Trigger Conditions | `SKILL.md` frontmatter `description` 与“边界” | 明确命中视频任务与排除静态网页/架构图/原型等反例。 |
| 4. Input Schema | `references/子技能路由表.md` 与 `references/工作区适配与避坑守则.md` | 说明主题简报、素材来源、环境前提与上游路径解析顺序。 |
| 5. Knowledge Base | `references/子技能路由表.md` → 上游 `<UPSTREAM_SKILLS>/*/SKILL.md` | 按需只读 1~2 个上游子 Skill，不把 3.79 MB 文档搬进核心骨架。 |
| 6. Execution Workflow | `SKILL.md`“固定动作”；上游 `plugin-cli.mjs` | 归属建项 → 定位上游 → 编剧写 HTML → `lint/check/snapshot/preview` → `render`。 |
| 7. Decision System | `references/工作区适配与避坑守则.md` | L0/L1/L2 费用阶梯、Windows/中文避坑决策、遥测开关边界。 |
| 8. Output Schema | `references/输出契约.md` | 最终件 MP4/工程目录、中间件、验收清单与汇报要求。 |
| 9. Quality Check | `references/输出契约.md`；上游 `lint`/`check`/`snapshot` | 必须通过检查与看图验收才进入交付渲染。 |
| 10. Examples | `references/子技能路由表.md` 与上游 `examples/` / `registry/` | 复用上游官方样例与 450+ 动效组件，不在本地重复抄写。 |
| 11. Tools & Permissions | `SKILL.md`“边界”与 `references/工作区适配与避坑守则.md` | 约束只写 `output/<子项目>/03_代码程序/`、付费前置授权、凭据走 `B12`。 |

## 三、维护规则

1. `SKILL.md` 始终保持 100 行以内薄入口，不得向入口堆砌上游长文档。
2. 上游更新能力时，仅需在源码仓执行 `git pull` 或运行 `npx hyperframes skills update`，仅当上游目录布局变化时再更新 `references/子技能路由表.md`。
3. 后续如沉淀工作区专属品牌模板（`frame.md`）或自动化封装脚本，可按需放入 `assets/` 或 `scripts/` 并同步更新本索引。
