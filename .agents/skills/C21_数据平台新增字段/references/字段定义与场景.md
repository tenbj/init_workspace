# 字段定义与场景

## 最小输入

| 项目 | 必要内容 |
|---|---|
| 模型身份 | 业务域、中文名、完整库表名、连接、环境；分层只作上下文 |
| 字段定义 | 原名、中文名、释义/来源口径、目标数据库完整类型（含长度/精度/小数位）、Nullable、默认值、物理/业务主键 |
| 展示设置 | 排序、可选分组与备注；现场默认值也要回读 |
| 执行范围 | 仅填写、提交指定列、逐列提交全部；最后要停在哪里 |
| 来源依据 | 源列定义/开发交付/业务明确指令；记录证据时间 |
| 全量确认记录 | 本轮全部模型字段清单、版本/时间、用户明确回复、确认范围；变更项另记 |

用户明确决定优先于类型建议，业务释义不从字段名猜。先只读形成完整清单，按操作流程第一步一次性请用户确认；未知关键项不静默补默认。确认前不进入新增表单，确认后不逐项重复询问。

## 类型与NULL

- 源类型、目标类型、业务取值是三个不同概念；值只有0/1不能证明源类型是INT。
- 根据来源定义、真实值、模型设计及目标引擎选型；用户确认偏离源类型时记录决定与转换验证待办，不静默改回。
- 本平台带教规则：非主键字段Nullable选“是”。这是本流程的配置惯例，不是“所有数据库非主键必须允许NULL”的理论结论。
- 主键必须根据已有模型设计与引擎能力核对物理键和业务键；两者不能互相推断。没有明确依据不勾选主键，关键冲突问清。
- 默认值、Nullable、历史回填相互独立。源默认值不自动等于目标默认值，不推断新增列后历史数据已获得业务值。
- 本流程增加新字段；修改已有字段类型、删除或重命名另立任务，不冒充新增。

## 场景分支

| 场景 | 新增前的核对重点 | 本Skill完成边界 |
|---|---|---|
| ODS源字段同步 | 源库完整类型（含长度/精度）、NULL、默认值、注释、实际值；目标映射决定 | 平台逐字段新增，记录源到目标映射；不修改抽取SQL或DataX配置 |
| DWD明细模型 | 开发交付的列名/类型/口径，派生表达式的输出类型与NULL可能性 | 依确定设计新增；表达式开发与发布由独立能力负责 |
| DWS/DMT/DMA汇总或应用模型 | 指标单位、精度、小数位、计算口径、模型粒度是否受影响 | 仅增加既有模型字段；不能把新指标直接假设成INT或STRING |
| DIM/其他实体模型 | 属性含义、键角色、可空性、历史属性策略 | 沿相同字段表单操作；键/历史策略调整不在本Skill内 |
| 视图、文件模型或其他引擎 | 现场是否支持相同新增入口，是否存在可ALTER的物理表 | 不照搬Doris ADD COLUMN；不支持时说明差异并交接 |

ODS/Doris已实际走通。其他分层共享字段信息和操作原则，但未逐场景实测；只在现场支持同一路径时复用，不声称所有模型/引擎均验证。

## 独立职责

1. 本Skill负责平台字段新增与结果核对。
2. 代码同步/发布调用已有对应Skill（GitLab发布可由 C19 承接），本Skill不重复实现仓库同步、分支、MR和通知流程。
3. 海豚节点代码更新应由独立Skill承接，不在本Skill内给出未经带教的更新步骤。
4. 不使用“配置模型 → 同步语句 → 确认更新”代替海豚代码更新。
5. 字段添加成功不意味着同步链路、调度或历史数据就绪；各阶段分开报告。用户只要求字段新增时，到字段新增核验为止。
