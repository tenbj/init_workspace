# G02_单画布ER图生成

## 这项技能解决什么问题

- 生成或审查单文件、离线、单画布 ER 图 HTML。
- 固化实体简称、鸡脚基数、在线连接键、正交布线、可编辑交互和双态几何验收，避免“关系正确但图难读”。

## 先读哪些本地知识

- 必须完整读取 `references/单画布ER图呈现与验收标准.md`。
- 需要通用 HTML 产物能力时，再读取并遵循 `G01`。

## 固定动作

1. 汇总表、字段、主外键、可空性、唯一约束和业务含义；确认实体数、关系数及唯一简称。
2. 先确定无重叠实体布局、专用端口和正交通道，再绘制关系；每个实体只出现一次，并尽量做到无交叉。
3. 使用鸡脚符号表达基数，并把 `父简称.字段 = 子简称.字段` 放在所属线段上；线的两端必须垂直进出实体框。
4. 默认显示 PK、FK 和核心字段；点击实体展示全字段；一键隐藏字段时缩小实体并重算全部端点、路径和标签。
5. 实体、端点、关系线和连接键需要支持拖拽移动；连接键拖动后仍吸附在所属水平/垂直线段上，端点拖动后仍吸附在实体边界并垂直出入。
6. 鼠标悬浮或选中实体/关系/连接键时高亮相关实体、线和标签；实体右键菜单支持“隐藏实体”，顶部提供“全部显示”恢复当前会话隐藏项。
7. 若同时需要概念模型，把它放在物理模型之前；概念模型只显示表名，但每个模型仍保持完整单画布。
8. 对字段展开态、隐藏态和关键交互状态分别在真实浏览器执行几何验收；运行 `python scripts/validate_erd.py <HTML> --entities N --relations N`。
9. 按 B02 备份、B08 记录进度、B03 写入记忆；没有新鲜验收证据时不得宣称完成。

## 什么时候再读本 skill 的 references

- 每次生成、修改或审查 ER 图时都读完整标准；其中包含具体反例、运行时验收契约与交付清单。

## 边界

- 不用箭头代替鸡脚，不把一张关系图拆成多个孤立小图，不为减少交叉而复制实体。
- 连接键不得脱离所属线、盖住整段线或遮挡其他关系；线不得穿实体、贴框、交叉、斜连或共轨重叠，端点不得以平行贴边方式接入实体。
- 字段隐藏不得只把文字设为不可见；实体必须真实收缩，并保持简称、表名、中文含义与字段数摘要。
- “实体隐藏”只隐藏当前页面会话里的实体及其相关关系，不写入 `localStorage`、`sessionStorage` 或 `IndexedDB`。
- 本 Skill 只规定 ER 图呈现与验收；数据库业务事实仍以用户输入和项目数据模型为准。
