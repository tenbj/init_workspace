# 单画布 ER 图呈现与验收标准

## 1. 适用范围与交付形态

- 适用于数据库模型讲解、物理 ER 图、概念 ER 图及其单文件 HTML 交付物。
- 交付物默认是一个可离线打开的 HTML：CSS、JavaScript、SVG、图标和模型数据全部内嵌，不依赖 CDN、远程字体、图片或接口。
- “一张图”表示一个模型使用一块连续画布：每个实体只出现一次，全部关系在同一坐标系中呈现。不得拆成多个关系卡片，也不得靠复制实体减少交叉。
- 优先使用 SVG 表达实体、正交路径、鸡脚、标签和交互；实体量较大时提供搜索、拖拽、缩放、适配全图和复位。
- 需要交互式编辑时，实体框、关系端点、关系线和连接键标签都应支持移动；移动后仍保持正交线、在线标签和端点垂直出入框。
- 使用语义化 HTML 和可访问按钮；兼顾不同视口与打印。

## 2. 概念模型与物理模型

- 数据模型讲解同时需要概念模型和物理模型时，概念模型放在物理模型之前，后续章节编号顺延。
- 概念模型实体只显示表名和简称，不显示字段；重点讲清业务实体和一对多关系。
- 物理模型显示字段明细、主外键与连接键。
- 概念模型和物理模型可以是同一 HTML 的前后章节，但各自必须是一块完整单画布，不能把单个模型分割成多个小图。

## 3. 实体信息与唯一简称

- 每张表必须有唯一、稳定、短小的英文简称，例如 `CU`、`MP`、`DR`。
- 每张物理表只渲染一个实体。实体数必须等于输入表去重数，简称、DOM ID 和表名均不得重复。
- 展开态实体头部显示：简称、物理表名、中文含义；正文至少显示 PK、FK 和核心字段。
- 点击实体打开侧边详情，按原顺序展示全部字段、类型、可空性、键类型和说明。
- 实体框在默认布局、字段隐藏、拖拽后均不得相互重叠；若用户手动拖成重叠，应提供可恢复的复位或重新适配能力。
- 同名表使用完整限定名区分；复合键按一个约束整体表达。

## 4. 一多关系与鸡脚语义

- 所有关系必须使用 Crow's Foot 鸡脚符号，禁止箭头。
- 直线端的竖线表示“一/必有”，圆圈表示“可选/零”，鸡脚表示“多”。页面说明区应明确解释这些符号。
- 基数必须来自真实约束：普通非空 FK、可空 FK、唯一 FK 和自关联不得统一画成同一种关系。
- 多端的圆圈、竖线和鸡脚必须与主路径共轴，不能被“甩”到线条走向之外。
- 端点前必须保留足够长的直线接近段，建议不少于 26px，并大于鸡脚标记深度。

## 5. 连接键必须在线上

- 每条物理关系恰有一个连接键标签，格式固定为：
  `父实体简称.父字段 = 子实体简称.子字段`。
- 复合键完整列出字段对，可用 `AND` 连接，不得省略到无法识别。
- 标签几何中心必须落在自己的一条水平或垂直直线段上；移动、收展或重排后同步更新。
- 标签背景可以隔断自己下方的一小段线以保证可读性，但承载线段必须在标签两侧各露出至少 18px，不能让整段横线看起来断掉。
- 标签不得脱离自己的线，不得放在折点、鸡脚端点或多线交汇处。
- 标签不得覆盖实体、其他关系线、其他标签或鸡脚；任意两个标签边框至少留 4px。
- 多条关系靠近同一区域时必须错层、错位或改用不同通道；不能让 A 关系的标签盖住 B 关系的线。
- 连接键标签支持拖拽时，只能吸附在自身关系的一条水平或垂直承载段上，不得被拖到实体框内、空白区、折点或其他关系线上。
- 标签移动后必须同步更新标签所属关系的高亮、选中状态和验收属性；不得用固定绝对位置伪装“在线”。

## 6. 单画布布线规则

- 优先把父实体放在上方、子实体放在下方，让关系以上下方向进出；必要时使用左右端口和外围长通道。
- 所有关系使用水平/垂直正交线，禁止斜线。
- 每条线从实体边界的专用端口垂直离开，先走出安全距离再转弯；禁止沿实体边框贴行。
- 线的两端必须与实体框边垂直相交：上/下边只能接垂直线，左/右边只能接水平线；不得出现平行贴边、斜接、端点甩出框外或插入框内。
- 路径不得进入任何非端点实体的矩形，也不得被实体或标签遮挡。
- 无关关系不得交叉、相切成 T 形、共轨重叠或共享长通道；同源/同目标关系分配独立端口与通道。
- 低频或长距离关系优先走画布外围，主干关系保留更直接的通道。
- 自关联使用独立且足够宽的回环，不与其他入线、出线或标签重叠；必要时扩大实体间距或画布。
- 连线在实体层之后绘制，标签位于连线之上；层级不能代替几何避障。

## 7. 已验证的典型反例

- `CU→MP`：先从 CU 垂直离框再转弯，不能沿 CU 底边贴行。
- `CU→DR`：不得与 `CU→CP` 的连接键框重叠；DR 端需要足够长的直线接近段，让圆圈/鸡脚与路径共轴。
- `CU→MP`：连接键应放在较长的承载段上，标签两侧都能看见线，不能遮住整条横段。
- `MP` 自关联：使用独立回环，避开 `CU→MP`、`AU→MP` 等其他关系。
- `AU→DR` 与 `CU→DR`：路径和标签分别错层，任一连接键都不能覆盖另一条线。
- `AU→AL` 与 `AU→DR`：两个连接键垂直错开；字段隐藏、实体变矮后仍保持至少 4px 间距。

这些简称只是问题模式的实例。新模型应把规则推广到所有同源、多入线、自关联和密集标签区域。

## 8. 字段显隐交互

- 提供一个全局“隐藏字段/显示字段”按钮，不要求用户逐表操作。
- 提供一个全局“全部显示”按钮，用于恢复被右键隐藏的实体及其关系。
- 隐藏字段后，实体必须真实收缩，而不是只隐藏文字或留下原高度空框。
- 收缩态至少保留：简称、物理表名、中文含义和字段数量摘要。
- 展开态恢复原字段顺序和尺寸语义；缩放、平移状态不应无故丢失。
- 每次收展都重新计算实体高度、关系端点、鸡脚、路径和连接键位置。
- 字段显隐与实体隐藏只控制当前页面会话，不写入 `localStorage`、`sessionStorage` 或 `IndexedDB`。
- 实体右键菜单应支持“隐藏实体”；隐藏实体时同步隐藏所有相关关系和连接键，不能只把实体设为透明或留空占位。
- “全部显示”后必须恢复所有实体、关系、端点和连接键，并重新计算布局、路径和标签位置。
- 连续切换至少 20 次，实体数、关系数、标签数和布局结果应保持稳定。

## 9. 编辑、高亮与隐藏交互

- 鼠标悬浮实体时，高亮该实体及其相邻关系、连接键和另一端实体；离开后恢复默认样式。
- 鼠标悬浮关系线、端点或连接键时，高亮同一条关系及其两端实体；选中后保持高亮，直到选择其他对象或清空选择。
- 实体框支持拖拽移动；移动过程中和移动结束后，相关端点、正交路径、鸡脚和连接键必须实时重算。
- 关系端点支持拖拽移动；端点必须吸附在所属父/子实体边界上，并依据所吸附边自动保持垂直出入框。
- 关系线支持拖拽移动；拖动后仍必须由水平/垂直线段组成，不能产生斜线、穿框、贴框或标签离线。
- 连接键支持拖拽移动；拖动后必须吸附到自身关系的最近合格线段上，且标签中心仍位于该线段上。
- 实体右键菜单只能作用于当前实体；隐藏后实体数和关系数在页面显示上减少，但数据源实体/关系定义不得被删除。
- 顶部“全部显示”恢复隐藏项后，默认验收计数必须回到完整实体数和完整关系数。

## 10. 展开态与隐藏态的几何验收

两种状态必须分别在真实浏览器中点击按钮后检查，不能只用静态源码推断。

1. 实体：数量正确、简称唯一、每表一次；展开字段完整，隐藏后高度确实变小，再显示可恢复。
2. 关系：数量等于去重 FK 约束数；父子表、字段映射、可空性和唯一性对应的基数正确。
3. 端点：落在所属实体边界；线端与框边垂直；直线接近段足够；鸡脚、圆圈、竖线与路径共轴。
4. 避障：路径不进入非端点实体；无无关交叉、T 形接触、共轨重叠和贴框走线。
5. 标签：每条关系恰有一个；文本精确；中心位于自己的直线段；两侧各有至少 18px 可见线。
6. 间距：标签不覆盖实体、其他路径、鸡脚或标签；标签间至少 4px。
7. 视口：适配全图后所有实体、线、鸡脚和标签可见；50%、100%、200% 缩放下仍清楚。
8. 稳定性：隐藏/显示、复位、适配全图和窗口变化后无断线、漂移、重复事件或控制台异常。
9. 交互：拖动实体、端点、关系线和连接键后，仍满足实体不重叠、端点垂直、路径正交和连接键在线。
10. 隐藏：右键隐藏实体后，相关关系同步隐藏；点击“全部显示”后恢复完整实体、关系和标签计数。

若不能做到零交叉或零遮挡，必须列出未通过的具体关系并继续调整，不得用“尽量”“基本”代替通过。

## 11. 运行时验收契约

成品 HTML 的 `<html>` 根节点应在自检完成后写入以下属性，值为 `pass` 或可计数值：

```text
data-geometry-status="pass"
data-entity-uniqueness-status="pass"
data-relation-integrity-status="pass"
data-crowfoot-status="pass"
data-label-anchor-status="pass"
data-label-clearance-status="pass"
data-label-overlap-status="pass"
data-fields-visible-status="pass"
data-fields-hidden-status="pass"
data-crossings="0"
data-label-overlaps="0"
data-path-entity-intrusions="0"
data-tables="<实体数>"
data-relations="<关系数>"
```

`?qa=all` 应自动依次执行展开态与隐藏态检查，并最终恢复正常初始状态。校验脚本以真实浏览器渲染后的这些属性为完成门；属性缺失也算失败。

## 12. 交付清单

- 新建文件时不覆盖用户要求保留的旧版本。
- HTML 可断网打开且没有外部请求。
- 概念模型（若要求）在物理模型之前。
- 单画布、实体唯一、简称完整。
- 鸡脚语义与连接键文本正确。
- 默认布局实体不重叠，关系尽量无交叉；若无法零交叉，必须列明具体关系和原因。
- 端点与实体框垂直连接，移动后仍保持正交和在线标签。
- 实体、端点、关系线、连接键可拖动；悬浮/选中高亮明确。
- 实体右键隐藏与顶部“全部显示”可用，且只影响当前页面会话。
- 字段收展真实改变实体高度。
- 展开态和隐藏态全部几何检查通过。
- `scripts/validate_erd.py` 返回 0，并保存必要的浏览器截图或可复核证据。
