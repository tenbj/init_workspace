# 使用与维护

## 触发与分工

G03 适合将有明确结论的复杂解释、流程或比较快速渲染为单页 HTML。模型负责事实、内容与组件选择，随附 CLI 负责图表布局、CSS 和交互。用户指定纯文本时尊重指定格式。

G01 用于自由布局、数据探索、专用编辑器和定制交互；H01 用于产品原型。G03 不替代专业技能的取证、SQL 验证或业务口径分析。不要仅因回答含列表就触发。

## 默认生成

Node.js 20+；无需全局安装与 npm 依赖。以当前工作区根目录为命令工作目录：

```powershell
node .agents/skills/G03_HTML回答生成/scripts/render.mjs "output/<子项目>/03_代码程序/draft.md" "output/<子项目>/03_代码程序/answer.html"
```

替换占位路径，实际草稿按项目要求命名；01/02 分类内容文件使用 B04 分配的编号。封装固定传入 `--no-open`，用 `.temp/answer-me-with-html-runtime` 保存工具状态，并设置 `AM_NO_UPDATE_CHECK=1`。主题、语言、模板写入草稿 frontmatter；一般用 `lang: zh`、`template: sheet`，较长线性阅读改 `doc`。

每个面板解决一个子问题，通常 3–8 个；内容简单可以更少。优先使用已有组件，不手写布局 HTML/CSS/SVG。

| 信息形态 | 组件 |
|---|---|
| 连接、分支、架构 | flow |
| 多角色随时间发送消息 | sequence |
| 分类、层级、文件目录 | tree |
| 阶段、演进 | timeline |
| 多维比较 | Markdown 表格 |
| 结论或提示 | callout |
| 真实值与边界 | limits，仅有实证数值时使用 |

语法按需查询：`node .agents/skills/G03_HTML回答生成/scripts/am.mjs help sequence`；完整选型与语法见原始技能说明。草稿文件优于 PowerShell 文本管道，可避免中文被旧版 PowerShell 的管道编码替换为问号。

## 校验与局部修改

CLI 返回成功路径后核对文件存在、中文、面板、图表、内嵌原稿及外部资源。复杂页面或布局有变化时用浏览器检查桌面和窄屏；未经浏览器检查，不声称视觉验收已完成。STE 是文字提示，不证明内容正确；默认最多修改两轮。

已有页面只改一个面板时先执行 B02，使用上游 patch 命令。上游以 HTML 中 `#am-source` 为原稿，因此同时维护独立草稿，防止两份内容漂移。

```powershell
$env:AM_HOME = Join-Path (Get-Location) '.temp/answer-me-with-html-runtime'
$env:AM_NO_UPDATE_CHECK = '1'
$env:AM_NO_OPEN = '1'
node .agents/skills/G03_HTML回答生成/scripts/am.mjs patch "output/<子项目>/03_代码程序/answer.html" --panel A --from "output/<子项目>/03_代码程序/panel.md" --no-open
```

这些环境变量只用于当前命令进程，不写入用户系统配置。改完后确认其他面板、主题与原稿仍保留。页面里的 Reply 按钮用于复制反馈，不自动发送消息。未回答的默认选项不能视为用户批准。

## 设置、升级与清理

`references/settings.md` 仅保留上游原文；其中全局安装路径与升级方式不适用于本项目。优先通过草稿 frontmatter 指定单次设置。只有用户提出持久设置需求时才对本项目的 AM_HOME 使用 `config set`。

升级按 A02 抓取固定提交，按 A01 本地化，并执行 B02 备份、来源哈希校验、渲染验收和注册检查；不运行 npx 全局升级。不自动清理用户产物；确需清理时先列出精确范围，按已有授权和工作区删除规则处理，不因上游提示扩展任务。

## 视频分支

只有用户明确要求视频才读 `video.md`。默认 `--voice off` 生成字幕播放器，防止 `auto` 因现有凭据调用外部语音服务。在线语音需用户已授权服务及内容发送；本地语音需确认服务地址。始终显式 `-o` 写入 output。MP4/WebM 另需浏览器、Node.js 22+，MP4 还需 ffmpeg。视频导出未纳入本次安装验收。
