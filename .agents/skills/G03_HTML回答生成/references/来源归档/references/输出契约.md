# 输出契约

## 必交付

- UTF-8 扩展 Markdown 原稿和对应单文件 HTML，位于已定位的 output 子项目。
- HTML 的 CSS、JS、图表内嵌，默认无外部运行时依赖，保留 `#am-source` 以支持局部修改。
- 事实、推导和示例可区分；引用资料提供可追溯来源，不把展示效果当作事实核验。
- 更新目录、版本记录、B03 记忆和 B08 任务状态；答复给出结论与绝对本地路径链接。

## 验收

1. CLI 成功退出，目标文件存在且非空。
2. 原稿语言正确，面板和图表覆盖目标问题；文字与组件警告已解决或说明。
3. 离线资源检查通过；浏览器检查是否执行须如实记录。
4. 已有页面修改前完成备份，独立草稿与嵌入原稿同步。

## 失败处理

缺少 Node.js、草稿语法错误或渲染失败时不得声称生成成功。保留原稿和错误摘要；修正后再渲染。视频播放器、MP4/WebM 是独立交付类型，需要分别检查，不凭 HTML 成功宣称视频导出成功。
