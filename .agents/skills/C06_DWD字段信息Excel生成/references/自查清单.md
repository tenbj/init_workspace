# 自查清单

生成 xlsx 后逐项核对，全部通过才结束。

## 字段完整性

- [ ] Excel 中字段原名列（字段原名）数量 = DWD INSERT 字段数量
- [ ] Excel 中不存在 DWD INSERT 列表之外的字段
- [ ] 系统字段（first_inserted_dt / etl_dt / last_updated_dt）排序序号均为 0 且在最前

## 类型正确性

- [ ] ODS 直传字段的 Type 列与 ODS CREATE SQL 中类型一致
- [ ] DIM 关联字段的 Type 列与 DIM CREATE SQL 中类型一致
- [ ] 所有 `from_unixtime` 转换字段的 Type 为 `datetime(3)`，字段类型为 `日期`
- [ ] `NULL` 占位新增字段的 Type 为 `varchar(255)`，字段类型为 `文本`

## 主键标记

- [ ] ODS UNIQUE KEY 对应字段的物理主键 = 是
- [ ] 其余字段物理主键 = 否

## 备注完整性

- [ ] COMMENT 中有逗号分隔的字段，字段备注列不为空
- [ ] `NULL` 占位字段的字段备注已标注"新增字段，待补充"或"枚举中文映射，待补充CASE WHEN"

## 文件落点

- [ ] xlsx 保存路径为 `output/C05_1对1DWD单表SQL生成/<dwd_name>/<dwd_name>_字段信息.xlsx`
- [ ] ODS CREATE SQL 和 DIM CREATE SQL 均在同一输出目录下
