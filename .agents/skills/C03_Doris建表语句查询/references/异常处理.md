# 异常处理

## 常见错误

| 错误信息 | 原因 | 处理方式 |
|---|---|---|
| `找不到 doris_query_client.py` | 数仓生产库查询 skill 不存在或路径变更 | 确认 `.agents/skills/C02_数仓生产库查询/scripts/doris_query_client.py` 存在 |
| `查询失败：...` | Doris 连接失败或表不存在 | 检查表名是否正确；检查网络/VPN；检查 Clash 内网放行 |
| `返回结果为空` | 表存在但 SHOW CREATE TABLE 无返回 | 确认账号有该表的查看权限 |
| `库名.表名` 格式错误 | 输入了多个点号 | 只允许一个点，格式为 `库名.表名` |

## Clash 内网放行

若连接 Doris 失败，先运行 `Clash内网放行` skill 确保内网可达，再重试。
