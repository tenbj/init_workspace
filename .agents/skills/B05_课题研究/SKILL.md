# 课题研究

## 这项技能解决什么问题

用户在对话中提出一个需要深入探讨的问题或话题时，AI 不是随口回答，而是按照标准研究方法论（问题→第一性原理→根因分析→推导→结论→参考文献）进行结构化分析，所有产出落盘到子项目文档中。

当用户的问题包含“为什么、原因、根因、机制、异常、失败、偏差、问题诊断、怎么修正”等意图时，本 Skill 必须显式执行根因分析，而不是只给解释性推导。

## 先读哪些本地知识

- 已存在的研究方法论约束写在 `.agents/rules/direction-rules.md` 中（落盘规则、output 唯一路径）
- 需要完整研究方法论（如何找第一性原理、如何做根因分析、如何做推导、如何标注来源）时，再读 `references/研究方法论.md`
- 需要判断每条论断该标哪种来源标签时，再读 `references/标注规范.md`

## 固定动作

1. 确认话题是否已有子项目 → 没有则先调用 `B04` Skill 创建

2. **⚠️ 领域分流（强制门，不可跳过）**：
   - 判断话题是否属于 **健康 / 减肥 / 养生 / 中医调理**（含身体症状、体质、睡眠、情绪、饮食调理等）
   - **是** → 立即读 `references/健康养生研究方法论.md`，后续论证与结构部分**完全由该专项方法论替代**，通用步骤 7-9 不再执行；若问题含原因/机制/症状诊断意图，专项方法论中的根因分析章节必须执行
   - **否** → 继续执行下方第 3-11 步通用流程

3. 研究类文档落到该子项目的 `02_课题研究` 子文件夹；live 路径不写版本号
4. 为研究文档分配 `02_课题研究` 内的下一个顺序编号，文件命名为 `{NN}_{标题}.md`；具体脚本调用见 `B04` Skill
5. 新增/删除/升级研究文档时，在子项目 `版本记录.md` 中记录版本变化；执行细节见 `B04`/`B02` Skill
6. 把用户的问题写入文档的"问题"章节并正面回答
7. 用第一性原理逐条论证回答的每个主张：
   - 定位该领域的权威第一来源（经典原典 / 奠基性论文 / 学科公理），精确引用
   - 现代学术期刊标明作者、年份、期刊、DOI
   - 所有逻辑延伸标注为【合理推导】
8. 当问题含原因、机制、异常、失败、偏差或修正意图时，新增"根因分析"章节，并按以下链条逐项写清：
   - **现象**：只记录可观察事实或用户原话，不把解释写成现象
   - **直接原因**：说明最接近现象的触发因素或近因，并标明证据来源或【合理推导】
   - **深层机制**：把直接原因追溯到第一性原理、经典出处、权威研究或多层推导链
   - **根因判断**：选择最上游且可干预的主因；若证据不足，写"暂不能确定"，不得伪造确定性
   - **证据验证**：列出能证实或证伪根因判断的观察、数据、文献或实验
   - **修正建议**：给出对准根因的最小修正动作，并说明它对应哪条根因判断
9. 在第一性原理和根因分析的基础上做合理推导，得出实践结论
10. 汇总所有引用到文档末尾的"参考文献"章节
11. 同步更新子项目根目录的 `目录.md` 中 `02_课题研究` 分节；文件列链接格式见 `工作区骨架规格.md` 固定文件节

## 什么时候再读本 skill 的 references

- 不清楚"第一性原理"怎么找、怎么区分于普通推导时 → 再读 `references/研究方法论.md`
- 不清楚"根因分析"如何从现象追到可干预根因时 → 再读 `references/研究方法论.md`
- 不确定某条论断该标【经典出处】【权威研究】还是【合理推导】时 → 再读 `references/标注规范.md`
- 需要确定文档的结构和叙事顺序时 → 再读 `references/研究方法论.md`
- 话题属于**健康 / 减肥 / 养生 / 中医调理**时 → 已在固定动作第 2 步强制触发，此处仅作备忘；若未读专项方法论就执行了后续步骤，视为流程错误

## 边界

- 不做无来源的断言——每一层论证都要有出处或明标推导
- 不把"直接原因"冒充"根因"——根因必须追溯到深层机制，并且说明为什么它是当前最上游、最可干预的主因
- 不在对话框中给完整回答——所有实质性内容必须先落到 `02_课题研究` 下的文档
- 不把"第一性原理"和"合理推导"混为一谈——推导必须是基于第一性原理的逻辑延伸
- 不缺少参考文献章节——每份研究文档必须有完整的引用列表和访问路径
