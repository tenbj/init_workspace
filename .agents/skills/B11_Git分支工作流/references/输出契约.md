# 输出契约

按实际执行动作汇报，不补造状态。

## 有 Git 仓库

- 仓库绝对路径、当前工作分支、相关目标基线（已确认时）。
- 已完成的主要改动和可点击文件入口。
- 已运行的检查、结果；未运行或受阻的检查说明原因。
- 提交号仅在已提交时给出；尚未提交明确写“未提交”。
- 推送远端/分支仅在成功时给出；未经请求或失败时写真实状态。
- 验收者和可复核步骤；合并、发布、标签、分支清理分别说明实际完成情况。
- 用户未提交内容仍有保留时，说明其不在当前交付内。

## 没有 Git 仓库

说明目标路径、为何不需要分支、已完成文件和验证；不创建提交号，不以无 Git 为理由阻止可以完成的普通文件工作。

## 失败与部分完成

定位失败、Git 不可用、权限或远端问题、检查失败必须说明具体影响。可独立完成的工作继续处理；不把尚未完成的推送、验收、合并或发布写成已完成。
