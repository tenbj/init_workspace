# 精确路由

输入锁定连接ID，例如doris.prod.readonly；有明确所需项时同时指定变量或密钥名。相同服务不同环境或权限不互相替代。

```powershell
python .agents/skills/B12_环境维护/scripts/environment.py route doris.prod.readonly --variable DORIS_PASSWORD
python .agents/skills/B12_环境维护/scripts/environment.py route service.prod.client --secret-file CLIENT_KEY_FILE
```

路由命令只读非秘密catalog元数据并校验路径，不打开真实.env或密钥文件。变量路由返回environment_file与请求的variables；文件型密钥返回secret_files中被请求的绝对路径。没有子项选择器时，返回该连接声明的全部路由；不得把它用于已明确单一变量的请求。

只请求密码时，不返回API key或客户端私钥；只请求私钥文件时，不返回.env路径。未登记项直接报错，不做模糊匹配、全库搜索、全目录读取或自动探测。

给其他AI的交接只包含连接ID、所需变量名、精确文件路径及任务允许的用途；通常让其脚本在本机读取。调用方已有路由时直接使用，不再读取其他连接索引。需要维护才转维护流程，不自动连远端验证。

catalog的secret_files字段示例（全部是非秘密名称与路径）：

```json
{"CLIENT_KEY_FILE":"keys/service.prod.client/client-key.pem"}
```

路由是文件定位协议，不是新的权限边界；共享系统账号仍可访问其权限允许的文件。
