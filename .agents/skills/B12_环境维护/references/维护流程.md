# 维护流程

## 注册与首次导入

先确认连接ID和所需字段；已有会话授权足够时直接执行。私密材料只能来自用户指定的本机文件或安全输入，不能为方便把真实值拼入命令行、公开文档或Skill。

改catalog前按B02对该公共配置文件做CONFIG备份，再执行注册。新连接的定义只含用途、环境、权限、变量名和密钥文件名。

```powershell
python .agents/skills/B12_环境维护/scripts/environment.py register service.prod.client --purpose 客户端认证 --environment prod --permission client --variable SERVICE_USER --variable SERVICE_SECRET --key-file CLIENT_KEY_FILE=client-key.pem
python .agents/skills/B12_环境维护/scripts/environment.py put-env service.prod.client --source <用户指定的本机键值文件>
python .agents/skills/B12_环境维护/scripts/environment.py put-file service.prod.client --name CLIENT_KEY_FILE --source <用户指定的本机私钥文件>
```

脚本仅打开指定源文件和目标连接。源键值文件必须正好包含该连接声明的变量，未知字段、空值或缺失均停止；二进制密钥不解析内容。首次写入采用独占创建和受限权限，默认不覆盖已有文件。用户明确更新已有值时使用--replace，不重复询问一般性维护授权。

## 更新与恢复

```powershell
python .agents/skills/B12_环境维护/scripts/environment.py put-env service.prod.client --source <本机新值文件> --replace
python .agents/skills/B12_环境维护/scripts/environment.py put-file service.prod.client --name CLIENT_KEY_FILE --source <本机新私钥文件> --replace
python .agents/skills/B12_环境维护/scripts/environment.py restore service.prod.client --snapshot <脚本返回的加密快照路径> --replace
```

已有值更新前，Windows用当前用户DPAPI生成.envs/.recovery/<连接ID>/中的加密快照；明文与目标路径一同受保护。写入新值前收紧临时文件ACL，再原子替换目标，输出只含状态、目标路径和加密备份路径。文件型密钥恢复须加--name，且快照绑定的目标路径必须匹配，不能恢复到任意位置。

维护脚本用独占锁避免其他agent同时写入；出现已有锁时停止。若上次进程意外退出，先核对持有者和任务状态再清理失效锁，不自动删锁。维护期间也应避免外部编辑器同时修改目标。

DPAPI依赖当前Windows用户及其保护环境，不能把它当跨机器通用备份；当前实现不使用LocalMachine共享解密标志。其他平台可首次创建本人可读写文件；已有值更新若没有受支持的加密保护，脚本会停止并保留原文件。不要降级成普通.history或明文副本。[Microsoft DPAPI说明](https://learn.microsoft.com/en-us/windows/win32/seccrypto/example-c-program-using-cryptprotectdata)

## 最小验证与记录

维护后按需调用check校验当前连接；不需要联网就能检查变量齐全与密钥文件存在。仅修改一个密钥时先核对该指定文件到位，不额外读取.env值。路由请求不调用check。

返回连接ID、动作、目标路径、备份路径（有则提供）、校验状态；不回显真实值、源文件内容或整个目录。按B03/B08仅记录上述非秘密元数据。

本机新增连接不自动成为发布默认连接。公开模板继续经过白名单与空白示例审查，不能用维护命令把本机真实文件同步进模板。
