# 输出契约

- 路由：id、variables、所需environment_file及secret_files；均为非秘密元数据，不包含其他连接或未请求项。
- 维护：id、action、target、configured或written、backup（仅加密路径，有则提供）。仅失败码可进入错误输出，不能包含秘密原文。
- 账密/API key/secret进入.envs/<连接ID>.env，文件型密钥进入.envs/keys/<连接ID>/<文件名>，加密恢复材料进入.envs/.recovery/<连接ID>/。
- 不把真实值作为output成果；成果仅为上述指定本机文件和脱敏回执。源码、说明、公共清单可版本管理，真实文件始终忽略。
