# 加载方式

## 前置条件

| 条件 | 说明 |
|------|------|
| Python 3.8+ | 硬性要求，无 Python 则整个 skill 无法运行 |
| `pymysql` | `pip install pymysql`，缺失时脚本会给出提示 |

## 连接选择

本工作区“数仓”专指 Doris。C02 只使用 `.envs/catalog.json` 中的 `doris.prod.readonly`，真实配置位于 `.envs/doris.prod.readonly.env`；通过 `.envs/env_manager.py` 加载并检查必填项。平台 MySQL、PostgreSQL、ClickHouse、SQL Server 各走自己的连接与驱动，不调用 C02。

从工作区根目录检查路由与配置（不会联网）：

```powershell
python .envs/env_manager.py route doris.prod.readonly
python .envs/env_manager.py check doris.prod.readonly
```

## 新配置变量

| 变量 | 说明 |
|------|------|
| `DORIS_HOST` | Doris 查询集群地址 |
| `DORIS_PORT` | Doris 查询端口，必填 |
| `DORIS_USER` | 生产只读账号 |
| `DORIS_PASSWORD` | 只读账号密码 |
| `DORIS_DATABASE` | 默认数据库，必填；可用客户端 database 参数选其他授权库 |

客户端从自身脚本位置定位本工作区，固定加载登记的生产只读连接，不依赖命令当前目录。不再读取旧 `input/.env` 或 `DORIS_QUERY_*`；新配置缺失时明确报错，不回退旧配置，也不改用其他身份。当前进程若有与新配置不同的同名 `DORIS_*` 值则停止，避免混用测试写入身份。凭据仅保存在进程内，不永久修改环境。

```python
import importlib.util, pathlib

_skill_script = pathlib.Path(".agents/skills/C02_数仓生产库查询/scripts/doris_query_client.py")
spec = importlib.util.spec_from_file_location("doris_query_client", _skill_script)
mod  = importlib.util.module_from_spec(spec)
spec.loader.exec_module(mod)

client      = mod.DorisQueryClient()                    # 默认 cbebg 库
client_glcd = mod.DorisQueryClient(database="glcd")     # 切换到 glcd 库
```

> 凭证只允许通过环境变量注入，禁止写入脚本、仓库、临时文件或对话记录。
