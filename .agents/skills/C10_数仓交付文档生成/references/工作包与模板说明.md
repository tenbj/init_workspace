# 工作包与模板说明

## 模板

默认模板：`assets/数仓模型交付文档模板.xlsx`。

包含 `01_交付表清单`、`02_1模型名称-字段`、`02_2模型名称-质量指标`、`02_3模型名称-数据自测`。脚本复制模板而不原地修改；模型名过长时按 Excel 31 字符限制截断。

## JSON 工作包

```json
{
  "metadata": {
    "document_version": "V1.0",
    "delivery_date": "2026-08-31",
    "owner": "负责人"
  },
  "model": {
    "name": "模型名称",
    "layer": "DWD",
    "table_name": "db.table",
    "schedule": "每日 06:00",
    "scenario": "使用场景",
    "sources": ["db.source_a", "db.source_b"],
    "remark": "备注"
  },
  "fields": [
    {
      "seq": 1,
      "cn_name": "字段中文名",
      "name": "field_name",
      "type": "string",
      "description": "字段释义",
      "logic": "加工说明",
      "source": "来源表及别名"
    }
  ],
  "quality": [
    {
      "seq": 1,
      "dimension": "完整性",
      "object": "检查对象",
      "rule": "检查规则",
      "threshold": "业务阈值",
      "period": "每日",
      "note": "备注",
      "sql": "WITH ... SELECT COUNT(*) AS quality_value FROM dc;",
      "actual": "生产实测结果",
      "conclusion": "通过"
    }
  ],
  "tests": [
    {
      "seq": 1,
      "scenario": "测试场景",
      "method": "测试方法",
      "object": "核对对象",
      "expected": "预期结果",
      "actual": "实际结果",
      "scope": "测试数据范围",
      "note": "备注",
      "sql": "只读测试SQL"
    }
  ]
}
```

`quality` 必须恰好六条，顺序为完整性、唯一性、有效性、准确性、一致性、及时性。

## 命令

```powershell
python ".agents\skills\C10_数仓交付文档生成\scripts\delivery_workbook.py" `
  --package ".temp\delivery-package.json" `
  --output ".temp\模型交付文档.xlsx" `
  --overwrite
```

仅校验：

```powershell
python ".agents\skills\C10_数仓交付文档生成\scripts\delivery_workbook.py" `
  --output ".temp\模型交付文档.xlsx" `
  --validate-only
```

草稿阶段可加 `--allow-pending`；正式交付禁止使用该参数。

公开模板已移除两张来源平台截图。执行时使用当前任务真实截图填充，不把历史联系人或监控结果作为交付证据。
