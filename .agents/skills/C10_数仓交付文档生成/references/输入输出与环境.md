# 输入、输出与环境约定

## 必需输入

| 输入 | 用途 |
|---|---|
| 目标模型 SQL | 解析字段、来源、分支、主键和加工逻辑 |
| 目标表结构 | 确认类型、Nullable、Key 模型和审计字段 |
| Excel 模板 | 保留组织要求、样式、列宽、打印和筛选设置 |
| 生产只读连接 | 执行六维 DQC 和数据自测 |

目标 SQL 和用户明确指定的 `input/` 材料是业务事实源。若本地 SQL 与生产结果不一致，必须记录差异。

## 环境加载

- Doris 生产数仓查询执行 C02，固定使用 `.envs` 的 `doris.prod.readonly`，通过 `env_manager.py` 加载 `DORIS_*`，不再回退旧配置。
- CK 源选择 `clickhouse.source.readonly`；其他源按实际引擎在 `.envs/catalog.json` 选择已登记连接并使用相应驱动。旧 `input/ck.md`、`input/source_db.md` 不再作为连接凭据入口。
- 平台 MySQL 使用 `mysql.dataplatform.reader`，不属于 Doris 数仓，不调用 C02。配置可用不代表远端权限已经验证。
- 不得输出变量值或把凭据写入 Skill、报告和临时工作包。

## 标准产物

| 产物 | 内容 |
|---|---|
| 交付文档 Excel | 01 清单、02_1 字段、02_2 六维质量指标、02_3 数据自测 |
| 质量与自测 SQL | 六条 DQC 和必要诊断/自测 SQL |
| 独立自测报告 | 环境、范围、六维结果、源目标对账、复算、风险和结论 |

默认将报告和 SQL 写入对应 `output/` 子项目；用户明确指定 `.temp` Excel 时按指定路径写入。模板资产不得原地修改。

## 禁止写入产物的信息

- 数据库密码、Token、Cookie、完整连接串。
- 未经实测的具体行数或“通过”结论。
- 当前模型无关的旧字段、截图、负责人或备注。
- 仅供调试的本机敏感路径。
