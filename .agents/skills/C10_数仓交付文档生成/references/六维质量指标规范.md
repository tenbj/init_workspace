# 六维质量指标规范

## 标准六维

| 维度 | 业务问题 | 推荐检查 |
|---|---|---|
| 完整性 | 应有的数据是否都存在 | 分区连续、每日有数、口径齐全、核心字段非空 |
| 唯一性 | 同一业务对象是否重复 | 目标重复键、主键公式一致性、源候选键重复 |
| 有效性 | 值是否符合业务允许范围 | 枚举白名单、格式、排名、评分、金额与数量范围 |
| 准确性 | 值是否真实反映源数据和计算公式 | 源字段复算、聚合、窗口排名、派生指标复算 |
| 一致性 | 不同环节是否表达同一事实 | 源目标行数、唯一键数、双向键集合与跨表口径 |
| 及时性 | 数据是否按 SLA 到达 | 最新业务日期、分区到达时间、延迟天数 |

“非空性”和“合理性”是检查方法：非空归完整性，范围合理归有效性。

## Excel 填写

- 指标名称：`质量维度-模型名称`。
- 检查类型：只能使用六维标准名称。
- 检查规则：说明检查动作。
- 阈值/标准：写业务条件，不得写 `quality_value=0；>0异常`。
- 实际结果：写业务证据，可附 `quality_value=0`。

## SQL 接口合同

1. 把异常记录或异常汇总放入 `dc`。
2. SQL 最后一条查询固定为：

```sql
SELECT COUNT(*) AS quality_value
FROM dc;
```

3. `quality_value > 0` 表示异常，等于 0 表示通过。
4. 最终结果不同时输出日期、总行数等辅助列；辅助证据由诊断 SQL 查询。
5. 空表、无最新分区必须返回异常，不能因空集合误报 0。

## 六维最低实现

### 完整性

- 最近 N 个自然日实际日期数等于 N。
- 每日记录数大于 0、业务口径齐全。
- 最新分区核心标识字段无空值。

### 唯一性

- 目标 `unique_key` 重复数为 0。
- 目标键等于按业务字段重新计算的键。
- 目标是 Unique Key 模型时，另在一致性检查写入前源基数。

### 有效性

- 枚举白名单和数值范围合并为异常行集合。

### 准确性

- 从上游生成期望记录，通过自然键关联目标。
- 使用 Doris 空安全比较 `<=>`；目标缺失或关键字段/派生指标不同均计异常。

### 一致性

- 比较每个分支的源目标行数和唯一键数。
- 源键 LEFT JOIN 目标键、目标键 LEFT JOIN 源键，统计双向差异。

### 及时性

- 最新业务日期与调度 SLA 预期日期比较。
- T+0 可用 `CURRENT_DATE()`；T+1 或工作日调度必须改成实际 SLA 表达式。
