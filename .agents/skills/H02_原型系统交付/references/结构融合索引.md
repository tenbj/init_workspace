# 结构融合索引

本文件说明 H02 的 11 段 Skill 结构落点，不替代 `SKILL.md` 入口。

## 总览

- **职责摘要**：把 HTML 原型或 H01 包落地成页面、API、数据库、MCP、架构图、ER 图、文档、示例、验证和脱敏项目包。
- **入口文件**：`SKILL.md`
- **详细知识分册**：`references/执行流程.md`、`references/能力与接口设计.md`、`references/文档与AI接入.md`、`references/验证与项目打包.md`、`references/输出契约.md`
- **脚本**：`scripts/init_project.py`、`scripts/validate_project.py`

## 11 段落点

| 段 | 落点 | 说明 |
|---|---|---|
| 1. Skill Metadata | `SKILL.md` frontmatter | `name` 与目录名一致；`description` 保持触发摘要。 |
| 2. Role & Goal | `SKILL.md` 的“这项技能解决什么问题” | 入口只说明从原型到系统交付。 |
| 3. Trigger Conditions | `SKILL.md` frontmatter 与固定动作 | 用户要求把 HTML 原型或 H01 包落地成可运行系统时触发。 |
| 4. Input Schema | `references/执行流程.md` | 输入类型、路径、sha256、项目名、输出目录。 |
| 5. Knowledge Base | 各 references 分册 | 只在触发 H02 后展开读取。 |
| 6. Execution Workflow | `SKILL.md` 固定动作；`references/执行流程.md` | 入口保留主流程，细节在分册。 |
| 7. Decision System | `references/能力与接口设计.md` | API 粒度、MCP 工具、数据库和框架复用判断。 |
| 8. Output Schema | `references/输出契约.md` | 合同字段、输出目录、ready 判定和最终回复要求。 |
| 9. Quality Check | `references/验证与项目打包.md`；`scripts/validate_project.py` | 测试、验证、mock/真实区别、脱敏打包。 |
| 10. Examples | `references/文档与AI接入.md` | HTML、Python、AI 可复制任务示例要求。 |
| 11. Tools & Permissions | `SKILL.md` 边界；`references/验证与项目打包.md` | 源原型只读、凭据 env、GitHub 和许可证边界。 |

## 维护规则

1. `SKILL.md` 继续保持薄入口，不展开成长篇方案。
2. 新增输出字段时，优先更新 `references/输出契约.md`。
3. 新增验证规则时，优先更新 `references/验证与项目打包.md`。
4. 新增接口或 MCP 设计原则时，优先更新 `references/能力与接口设计.md`。

5. 首次两图生成与每轮维护统一在 references/架构与ER图维护.md；绘图细则分别引用 D04/G02。
