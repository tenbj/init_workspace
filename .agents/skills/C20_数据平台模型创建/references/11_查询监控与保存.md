# 查询语句、质量监控与保存

## P8 查询语句

默认为当前目标全表查询：

```sql
-- 查询当前模型全部字段。
select * from 数据库.规范表名
```

平台已经自动生成正确值则保留；输入框为空白才补对应目标库表。不把上游表填入，不擅加过滤条件或LIMIT。此处只核验文本，不执行全表查询。非空但指向其他对象时查发布信息/模型身份，纠正根因后更新文本，不能不经核实直接进入下一步。

SQP默认原文为`select * from cbebg.dwd_ads_sqp_brand_view_ilu_dd`。确认无误后进入质量监控。

## P9 质量监控

内置规则“同步行数校验检查”：**ODS开启，其余分层关闭**。其说明是比较最近更新历史同步行数和来源行数；此条是用户确定的该规则开关，不是禁止所有其他质量指标。

读取实际开关状态，不能只看generic控件或颜色猜；可用checked/aria-checked/当前控件hidden值与样式交叉核对。已正确不重复点击，修改后再回读。按已确认分层决定，不能用上游是ODS推断目标也是ODS。本例DWD原状态false，保留关闭。

ODS完整创建分支尚未演示；若仅接入已存在ODS的质量监控页，可以应用这一明确开关规则，不能从此推出整套ODS同步流程已验证。其他自定义质量治理按用户任务另接 C15/C17，不作为本流程额外必做步骤。

## S6 确认创建

检查P1–P9均有可追溯结果，无未解决且影响保存的差异；用户仅授权到某一步则停在该步，不自动扩大。用户已要求完成创建或明确点击时无需重复确认。

点击一次“确认创建” → 等待 → 在当前页面读取成功提示、已经发生的提交响应和自动返回的模型列表记录。不要刷新确认，不连续点击。核实业务code/msg成功、返回模型ID正确，目标库表、分层、代码路径、调度、范围与确认值一致；如接口未返回某项，记录实际核验范围，不编造已回读。

平台观察到PUT `/prod-api/dap/marksetDataSet`是最后保存请求，SQP返回`code=200,msg=操作成功,data=2795`，随后自动列表返回完整模型配置。接口与编号仅用于识别已发生请求，不硬编码为直接写平台的脚本。

分别记录：

- 初始模型记录是否已创建（S5）；本次整套配置是否保存（S6）。
- 模型实际上线状态；调度平台字段与调度器上线证据分别记录。
- 是否执行首次加载/手动运行，是否验证物理DDL与任务结果；未检查写“未核验”。

SQP最后状态仍为“待上线”。不得写成“已上线可用”“全量完成”。保存完成即达到本Skill实测边界，后续上线/调度运行/数据验收需用户继续授权及实际步骤，不凭记忆编排未演示按钮。
