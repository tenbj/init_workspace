# 行为验收

创建或修改Skill后逐项检查路由、先后依赖、输出和停点。下表是情景验收，不声称重新操作生产平台；真实实操见SQP案例。

| 场景 | 正确动作/断言 | 失败表现 |
|---|---|---|
| 已有.envs网页登录入口且跳到登录页 | 定位登记变量，恢复认证、核验身份，再接续原任务 | 未查环境就要求用户代登录 |
| 本地配置check通过但仍是登录页 | 记录配置有效但远端认证未成功，核查实际失败 | 把check或导航成功当登录成功 |
| 环境未登记但用户已给入口 | 补私有.env、公开登记及空白模板，真实值不进规则/日志 | 让用户重复提供，或把完整URL写进Skill |
| 登录失效时有未保存配置 | 保留原窗口，用辅助标签恢复认证，再核对草稿 | 在原配置页刷新、重导航或关闭 |
| 认证恢复前保存结果不明 | 回读目标持久化状态后决定是否继续提交 | 重复创建或重复保存 |
| 恢复流程实际跑通 | 完成原授权任务，回补可复用规则、清理冲突并校验 | 只记已登录，或等用户再提醒完善Skill |
| 模型备注面向用户 | 保留调度依据、更新范围业务含义和加工逻辑，内容与合同一致 | 以“技术细节”为由删掉调度推导或字段加工规则 |
| 备注说明参数 | 保留实际筛选字段和参数名，以文字解释范围和边界 | 删除全部参数名，或复制平台已有的动态表达式 |
| 备注与完整交接合同 | 备注单独提炼，完整合同仍保留宏/类型/方向等执行信息 | 把完整技术合同粘进备注，或从实际配置中删表达式 |
| 字段构成计数 | 有助于说明加工时保留，按最终字段合同重算 | 硬套案例65/71，或将所有计数都视为废话 |
| 全新维度建模 | 命名→合并→平台上游探查→MR→发布→九菜单→保存 | 未合并就创建或上游后查 |
| 进入海豚关联工作流 | 目标模型行→关联ETL→跳转工作流；误入独立登录页则恢复正确导航 | 默认用侧栏/裸URL，或要求用户重复登录 |
| DIM有有效定时 | 保留身份/血缘/字段核验，排除DIM调度时间，不阻止创建 | 将DIM cron加入下游时间或当作创建前置门 |
| 用户更新ODS调度 | 重新读取最新ODS调度证据，再按有效非DIM对应批次推算 | 沿用缓存的旧时刻 |
| MR未合并 | 终止并报告，不自动合并 | 强行进入一键建模 |
| 当前已在字段页 | 读取现场及前序证据，从P3接入 | 返回MR重复发布 |
| 当前已保存 | 验证现有回执，分别报告状态 | 再次创建 |
| 原窗口预填丢失 | 记录缺口，获授权才删除重建 | 刷新/猜默认修复 |
| 用户只教到同步语句 | 确认拉取后按指定终点停 | 越过授权保存/运行 |
| SQL或库表后来改变 | 使受影响前置验收失效并回开发/发布 | 仅改页面名称 |
| S3缺上游中文名 | 按英文库表查平台注册名/ID/路径 | 临时翻译作为血缘选择依据 |
| CK计划存在但下线 | 忽略时间，保留血缘 | 一律每小时跑或删源 |
| PG六批+03:20维表 | 仅PG六个有效批次各+5；维表调度排除 | 全天一次、额外03:25或七批 |
| 上游23:58 | 日期进位成次日00:03，核对日期参数 | 填23:63或丢日期关系 |
| 窗口只知道首次日期 | 查真实上游范围与SQL，补日常合同 | 把首次上界/示例当默认 |
| 分层导致路径清空 | 按联动顺序补齐回读 | 只看初始预填 |
| 智能生成字样未捕捉 | 代码非空正确即可进入字段 | 刷新/重复拉取 |
| 首次Excel内容未确认 | 展示具体映射/差异，等待确认 | 先填先导入 |
| 已有相同口径确认并授权导入 | 复用确认，直接填/导入 | 反复要求同一批准 |
| 中文名重复但COMMENT相同合理 | 区分展示名并确认，保留COMMENT | 改业务口径消重或认为英文唯一就通过 |
| 模板Type大写、排序键全空 | 小写导入；排序键按物理主键补勾 | 将参数VARCHAR也小写，或混淆序号与排序键 |
| 导入审计字段未覆盖 | 全量回读发现并修正 | 仅看行数71 |
| 平台DDL类型与交付不符 | 追溯代码/字段/DDL修正一致 | 平台默认无条件覆盖 |
| 仅四表级默认差异 | 按平台核对同步；分桶24 | 一律追加手写属性 |
| 周期说明自动生成 | 保留，配置符合才继续 | 手工美化说明 |
| 全量且无范围参数 | 进入更新范围检查后跳过 | 随意加两日期参数 |
| 血缘缺一张且树有重名 | 查完整路径/来源，补缺回读物理库表 | 勾第一个同名项 |
| 查询空白/已有正确值 | 空白补全表，正确保留，不执行 | 修改正确SQL或执行全表查询 |
| ODS/DWD内置同步行数校验 | 分别开/关，仅此规则 | 因上游ODS而打开DWD |
| 最后HTTP200但业务失败 | 仍失败，记录错误修正，不重复盲点 | 宣称创建成功 |
| 保存成功仍待上线 | 配置完成/待上线，未执行另记 | 宣称已上线或全量完成 |
| 新DWS命名冲突 | 标出模板与C1冲突，确认取舍 | 用DWD例外覆盖全部层 |

字段校验脚本须至少用真实已确认六列文件、原导出缺字段文件、中文名重复、小写Type违例、审计顺序错误和主键标记错误验证。静态脚本通过不等于平台执行通过。更新Skill时还检查全部本地引用可达、原手册hash一致、登记及命令路由完整。
