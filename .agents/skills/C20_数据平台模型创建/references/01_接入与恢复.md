# 接入与恢复

## 接入先做什么

先获取当前页面快照与可见弹窗，不导航。读取任务进度、最终交付、已有回执；只对当前缺口补证据。记录目标数据库/表、中文名、模型ID（未创建可空）、MR与代码路径、所在阶段、表单是否保存、用户本次允许到哪一步、原窗口是否仍在。浏览器快照的pageId和uid须现取，不能抄案例。

| 现场 | 接入点与处理 |
|---|---|
| 仅有需求或SQL未交付 | 回 C18 补开发交付；本Skill不替代SQL开发 |
| SQL已交付、尚未发布 | 回 C19；不要假造MR或创建模型 |
| MR未合并 | 核实并记录，终止本次平台创建，不替用户合并 |
| 已合并、未开新增弹窗 | 核对中文名；进入平台后完成上游探查，再打开MR列表 |
| 已在MR列表/新增弹窗 | 不重新点一键建模；核对标题、文件路径、是否已有同库表模型；缺前置证据在保留当前页的情况下补齐 |
| 已在自动配置任一菜单 | 固定当前窗口；读取当前阶段，查已完成阶段证据，验证相关前置项后从该阶段继续 |
| 已完成最后保存、回到列表 | 查既有成功回执及自动返回的模型记录；不重复“确定发布”或创建同表模型 |
| 当前阶段无法判断 | 只读快照、可见标题、已发生响应；仍不清楚时问用户，不靠刷新试探 |
| 刷新/崩溃后预填丢失 | 标记上下文丢失，停下；不声称重新打开等于恢复，不用默认值补空冒充正确 |

新进入阶段不要求重做已确认步骤。关键证据不足时状态为“待核实”，不能由菜单已点击推断通过。首次填写确认已覆盖当前字段与口径则复用，只有未解决的新差异再提问。

## 页面保护与工具规则

- 自一键建模开始直到完成配置，禁止刷新、F5、reload、goto同URL、返回、关闭原页或为了验证重新打开配置。登录和进入管理页只发生在尚未有活动配置窗口时。
- 补上游证据优先读此前响应或本地回执；确需另查时只在独立页签只读查询，保留原页。不能在原配置页切回模型列表。
- 点击前读最新元素；输入后失焦并回读。等待“加载中”消失/值出现，不为了捕捉瞬时字样重复点击。
- 搜索框重绘时，对当前已定位的可见input一次性设置输入并触发正常input/change事件可作为工具兜底；不改Vue内部状态或直接写后台数据代替界面校验。
- 下载和上传确认文件名、绝对路径、非临时后缀及可打开。工具上传不可用时可用系统选择器选择同一已核实文件，禁止通过篡改配置绕过访问检查。
- 网络响应只读取必要业务字段。认证头、Cookie、登录URL密钥不落盘；只读响应不重新发起提交。HTTP 200不等于业务成功。

## 异常恢复

| 异常 | 动作 |
|---|---|
| 发现错误但窗口完整 | 修正最早产生错误的配置或交付，按02分册使受影响后续验收失效后重验；不刷新 |
| 提交等待/超时 | 保持页面，检查已发送请求和业务响应；结果不明先查事实，不再次点击制造重复 |
| 业务校验失败 | 记录具体字段与错误；在原窗口修正后再提交，保存失败不记完成 |
| 中文名重复、上游对象不唯一 | 给出具体候选/冲突，停在当前页向用户确认 |
| 源码变更或MR已合并内容与交付不符 | 停止后续发布，回开发/发布链路处理；不在平台随手改SQL掩盖版本差异 |
| 原始预填丢失 | 报告模型身份、保存状态和缺失项；只有用户已授权删除重建才执行删除检查并重建 |

删除是异常分支，非恢复默认动作。获授权后先核对模型ID、库表、状态及血缘/报表/指标/API/质量等引用，再核对数据库同步、文件导入、ETL、代码关联；非零引用或对象不明停下核实。平台删除/归档成功不等于物理表或代码删除。不得沿用SQP旧模型2794的删除授权删除其他模型。

## 恢复记录

每关键阶段写：当前页、通过/待核实/失败、实际读回值、证据时间与路径、用户确认范围、未保存差异、下一步。所有创建/保存/上线/执行分别记状态。B08中只存恢复卡；完整证据按输出契约保存。中途接入记录发生过哪些历史操作，不必重演它们。
