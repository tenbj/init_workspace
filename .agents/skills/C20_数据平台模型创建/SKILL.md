# C20_数据平台模型创建

## 本地接入

执行前先读 `references/本地接入.md`，确认本项目规则、输入及授权。来源案例不授予本项目权限。

## 这项技能解决什么问题

- 消费 C18 开发交付与 C19 发布结果，完成平台维度建模配置，支持从任意已到达阶段接入。
- 实测完整链路为 DWD / SQL-DORIS；DWS、DMT、DMA沿已确认维度建模规则使用，差异按现场核验。ODS同步、文件导入、DIM建设不是已演示的完整流程。
- 终点是配置保存并核验实际状态；不把保存、上线、调度执行、首次加载混为一件事。

## 先读哪些本地知识

- 每次必读 [接入与恢复](references/01_接入与恢复.md)、[流程与依赖](references/02_流程与依赖.md)、[输出契约](references/输出契约.md)。先读取现场和已有证据，不默认从头执行。
- 然后只读当前阶段对应分册；上游信息缺失时补读信息产生阶段，不因补证据刷新或离开配置窗口。
- 工作区按 B08 维护进度、B02 修改前备份、B03 记忆落盘。编号解析遵循 Skills 管理标准。

## 固定动作

1. 确定当前模型、当前页面、用户授权的结束节点、已有材料及证据时间；未知前序状态不算完成。
2. 全新创建按顺序：先定中文名 → 核实MR合并 → 进入平台 → 探查上游身份、调度和范围 → 形成下游运行合同 → 再查看MR列表、一键建模。
3. 核对新增表单名称、完整域路径和计划备注后，按授权点击“确定发布”；等待自动进入配置，保留原窗口。
4. 按固定菜单顺序逐项完成：发布信息 → 同步语句 → 字段信息 → 建表语句 → 更新周期 → 更新范围 → 数据血缘 → 查询语句 → 质量监控。
5. 每阶段核对实际值与开发交付，记录差异并修正到一致。首次填字段Excel前须确认内容，已有明确确认直接复用。
6. 最终核对通过且在用户授权范围内时点击一次“确认创建”；核实业务成功响应、目标模型和保存状态，记录未完成的上线/执行事项。

## 边界

- **建模全程绝对禁止刷新、重新导航当前URL、返回或关闭原配置窗口。** 自动进入配置后不能靠重新打开恢复预填。页面读取、已有网络响应检查不等于刷新。
- 用户分步带教时仅到指定阶段；已有授权不重复询问。仅要求封装Skill时不操作线上页面。
- 不固化页面ID、控件UID、坐标、浏览器reqid、模型ID、登录凭证或本例时间为通用默认。
- 原始命名手册随包保存；未演示流程、未核验依赖、配置与实际部署不一致均如实标记。关键歧义停在当前页求证。
- 不自动合并MR、删除重建模型、上线、执行SQL或发送消息；这些需相应任务授权。已授权的“确认创建”可按本流程执行，无需另设审批。
