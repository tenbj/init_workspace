# 生成与验收

## 运行

依赖 Python 3.10+ 与 `markdown-it-py`。依赖缺失时脚本给出提示；优先使用已有环境或工作区虚拟环境，避免擅自更改系统解释器。

```powershell
python -X utf8 '.agents/skills/F02_报表使用说明生成/scripts/build_manual.py' --input 'output/<子项目>/01_问题答疑/01_报表使用说明.md' --output 'output/<子项目>/01_问题答疑/01_报表使用说明.html' --status draft --check 'output/<子项目>/03_代码程序/报表说明/生成校验.json'
```

替换 `<子项目>`。修改已有 HTML 先按 B02 备份，再加 `--force`；脚本不调用工作区备份。`--force` 仅覆盖指定 HTML 与校验 JSON。输入 Markdown 永不覆盖。

## Markdown 支持

- 单个 H1 文档名、H2 章节、H3 子节；H2/H3 自动生成唯一 `section-N` 锚点，即使标题重复也不冲突。
- 段落、列表、引用、表格、代码、链接。文内章节链接用 `#section-N`；裁剪后需核对。
- 原始 HTML 按文本显示，脚本链接不会执行。
- 本地 PNG/JPEG/GIF/WebP 图片自动内嵌，路径基于源 Markdown 目录，不能跨出该目录；符号链接亦按实际路径检查。
- 远程图片、SVG、缺失图片、非图片伪装文件报错，不生成依赖外部图片的“离线文档”。可使用用户截图，不伪造界面。
- 无 YAML 前置元数据，版本、对象、日期直接写在正文。

## 验收

1. 报表身份正确；操作有来源；指标分母和合计明确；未知项可见；裁剪后编号连续。
2. 校验 JSON 的 `source_sha256` 对应交付 Markdown；不手改 HTML 正文。
3. 目录可定位 H2/H3，当前章节高亮，键盘可使用导航和按钮。
4. 桌面两栏、窄屏单列；长表格独立横向滚动，图片不超宽；打印隐藏导航和按钮。
5. 无外部脚本、CSS、图片请求。参考链接只在主动点击时联网。
6. `final` 拒绝常见占位符和待确认文字，但仍需语义审查；不能通过删除标记伪造完整。

有浏览器工具时检查桌面、窄屏、目录点击及打印样式；没有时静态检查并说明未做浏览器验证。
