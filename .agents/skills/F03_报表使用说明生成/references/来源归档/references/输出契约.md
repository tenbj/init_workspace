# 输出契约

## 最终交付

- 默认交付 `报表使用说明.md` 与 `报表使用说明.html`，基名由报表名称决定；工作区按命名规则添加编号。
- Markdown 为可编辑正文，HTML 从该文件生成；修改后重新生成 HTML，避免分别维护。
- HTML 带侧栏目录、当前章节高亮、响应式布局、打印样式；CSS/JS 和本地图片内嵌，无 CDN 或服务依赖。
- 用户指定其他格式时尊重要求；本脚本仅直接生成 HTML，不能改扩展名冒充 docx/pdf 转换。
- 浏览器“打印 / PDF”可另存 PDF；分页需预览，不保证固定页数。

## 工作目录

在 B04 定位的子项目内，正式文档放 `01_问题答疑` 或 `02_课题研究` 并维护目录；素材核对表、图片、中间源稿和校验 JSON 放 `03_代码程序/报表说明/`。修改先按 B02 备份。

本地图片需要在 Markdown 所在目录或其下级目录。可从工作目录完成源稿和嵌图渲染，再将源稿、HTML 与图片相对目录一起交付。HTML 可独立携带；Markdown 有图片时需同时提供图片文件。

## 状态与失败

- `draft`：默认状态，显示“草稿”；存在关键待确认项时必须使用。
- `final`：素材核对和内容验收完成后使用，显示“使用说明”。脚本检查不能证明业务真相。
- 虚构示例应明显标记为示例；本 Skill 样例以草稿模式输出。
- 生成失败时返回清晰错误，不覆盖旧 HTML，不宣称成功。
- 校验 JSON 记录状态、源文档 SHA-256、目录数量和图片数量；日志不写入面向用户的正文。

最终回复给出 Skill/文档路径、状态、验证情况以及仍影响使用的限制。
