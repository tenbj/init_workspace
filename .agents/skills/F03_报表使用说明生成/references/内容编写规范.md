# 内容编写规范

## 1. 从证据到文档

以用户指定的报表和资料为范围。截图中背景报表与说明标题不一致时，先区分两者；可以复用版式，不能混用业务内容。

在工作目录保存简短素材核对表：页面/功能/指标、事实、来源位置、状态、缺失说明。来源可以是截图编号与位置、用户文字、文档页码、公式或配置路径。没有实际阅读的材料不得列为已核实证据。

- **已核实**：输入明确写明或实际操作验证；写入正文。
- **待确认**：信息缺失、来源冲突或只能猜测；列明缺口，不填编造的值。
- **不适用**：资料明确没有该功能或用户确认不需要；裁剪相应章节。
- **示例**：教学素材，显著标注“虚构示例”，不得表现为生产验证结果。

用户明确确认的口径优先；冲突影响正确性时说明冲突并询问。不要用“行业常见”补齐当前报表的实际实现。缺少关键公式时可先交付草稿，其他有证据的内容继续完成。

## 2. 大纲及裁剪

封面概况不编号；剩余适用章节按阅读顺序连续编号。模板的序号是初始结构，删除章节后需重新编号。

| 内容模块 | 应写内容 | 适用性 |
|---|---|---|
| 文档信息与报表概述 | 名称、版本、更新时间、对象、入口、用途、数据范围、更新说明；区分文档更新时间与数据刷新时间 | 必备；未知项标注 |
| 快速上手 | 打开报表到获得结果的最短路径；预期结果；初始/保存/当前状态注明类别与来源 | 必备 |
| 页面功能分区 | 区域、位置、功能、使用要点；多页报表列页面间关系 | 必备 |
| 快捷视图 | 视图对应问题、切换入口、改变或保留的设置 | 有功能时写 |
| 维度与指标设置 | 行列维度、指标选择、TOP N、占比、币种与单位 | 按实际能力选小节 |
| 日期与统计周期 | 日期字段含义、粒度、起止是否包含、周起始日、同比环比范围 | 时间分析适用 |
| 筛选条件 | 每项含义、单多选、联动、作用范围、清空重置 | 有功能时写 |
| 图表阅读与交互 | 轴、图例、颜色、空白含义；展开折叠、排序、分页、合计、钻取、聚焦 | 按实际图表写 |
| 数据导出 | 入口、操作、格式、范围、筛选保留、权限与行数限制 | 有功能时写；限制要有依据 |
| 核心指标口径 | 定义、公式、单位、粒度与范围、去重/空值、占比分母、合计计算、来源 | 必备 |
| 常用分析方法 | 业务问题、操作、观察、解读、注意事项 | 必备；限素材支持的分析 |
| 常见问题 | 无数据、值不一致、刷新延迟、导出问题，写可执行排查和反馈入口 | 可选 |

不要给静态 Excel 表格添加钻取、聚光灯或高级筛选；也不要因为只见一张截图就认定其他页面不存在。

## 3. 写法

操作采用“用途 → 入口 → 步骤 → 结果 → 注意事项”。短操作可合并成一段；不为格式写空话。步骤用明确控件原名与位置，例如“在页面右上方的【日期】选择起止日期”。未经素材确认的操作不要写成事实。

快速上手保留最短路径，细节指向后文。页面分区用表格；复杂操作用 H3 分节或配截图。正文面向业务用户，避免构建命令、JSON、测试日志等实现信息。

指标表至少写“指标、业务含义、计算口径、单位/粒度、范围/注意事项、依据”。比例不能默认为平均，合计不能默认为求和。明确广告/自然销售、含税/未税、退款前/后等业务边界。无法确定时保留“待确认”，不要用 0 代替未知值。

分析案例按“问题 → 操作 → 观察 → 解读 → 注意事项”。相关关系不写成因果结论。模拟数字在案例标题或表格附近注明示例身份。

FAQ 先定位页面、日期、筛选和更新时间等实际控件，再指向已知维护人或反馈渠道；渠道未知列待确认，不编造联系人。

## 4. 资料不足与确认策略

- 素材充分：直接生成，不新增固定审批步骤。
- 用户要求先确认大纲：先提供大纲，再按反馈继续。
- 关键口径缺失：询问最影响正确性的缺口，交付带待确认清单的草稿。
- 信息过少：输出明确标注的模板/草稿和输入清单，不能宣布实际报表说明已验证。

完成前将素材核对表与正文逐项对照；模板中的不适用功能、示例业务名和占位符应移除或替换。
