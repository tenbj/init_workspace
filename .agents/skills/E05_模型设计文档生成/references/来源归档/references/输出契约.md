# 输出契约

B04定位output子项目，正式说明放02_课题研究/{NN}_模型设计生成说明.md；运行包放03_代码程序/模型设计/<run>/。

| 路径 | 内容 | 角色 |
|---|---|---|
| inputs/model_design.json | AI核读后的设计合同 | 可恢复中间件 |
| inputs/*盘点.json | 完整单元格、公式缓存、hash和结构 | 证据中间件 |
| deliverables/模型设计.xlsx | 目录、字段、多源、说明、证据、缺口 | 最终件 |
| deliverables/理解与差异说明.md | 范围、依据、假设、冲突、覆盖、缺口及影响 | 最终件 |
| deliverables/*.sql（需要时） | 完整长SQL附件，标来源/提案状态 | 最终件，不执行 |
| qa/生成校验.json | 重开与合同对照 | 验收日志 |
| qa/语义验收.md | 字段、粒度、指标、来源覆盖、未验证项 | 验收日志 |

翻写另有Excel翻写映射页。只要一个Excel时也把必要缺口和证据放进去。

可评审草案：结构通过但有建议、冲突或未确认，允许交付但明确草案。
文档生成完成：结构和AI语义复核通过、缺口如实列明，不表示评审、开发或上线。
字段/映射丢失、结构校验失败：不能声称完成，修复或说明阻断。

最终回复给场景、模型/字段数、Excel路径、关键缺口与验证范围。未知字段存在不称完整物理设计。
输入不存在找唯一合理候选，多候选则问；缺DDL保留未知类型；冲突保留双方。写入受限先完成审阅包和验收再安装。源文件与代码只读。
