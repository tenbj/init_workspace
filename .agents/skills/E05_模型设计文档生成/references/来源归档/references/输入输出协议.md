# 输入输出协议

## 运行

Python 3.10+、openpyxl；读图片需Pillow。使用已有环境，缺依赖明确报告。脚本不联网、不调用LLM或数据库、不执行Excel公式。

```powershell
python .agents/skills/E05_模型设计文档生成/scripts/model_design.py inspect --input <原文档.xlsx> --output <run/inputs/盘点.json>
python .agents/skills/E05_模型设计文档生成/scripts/model_design.py render --input <run/inputs/model_design.json> --output <run/deliverables/模型设计.xlsx> --report <run/qa/生成校验.json>
python .agents/skills/E05_模型设计文档生成/scripts/model_design.py validate --input <run/deliverables/模型设计.xlsx> --report <run/qa/独立检查.json>
```

输出放B04子项目内，脚本拒绝覆盖；重跑前B02备份并选新run。validate仅查结构；render重开还核对字段与映射，仍不能替代AI语义复核。

## JSON合同

完整可运行示例见assets/示例输入.json（虚构，不能当生产事实）。

顶层：
- title、version、mode（code/requirements/rewrite）、models非空数组。
- evidence：每项id唯一，state为已确认/设计建议/待确认/存在冲突；source为真实文件或本轮需求/AI提案，locator为行号、sheet!单元格、需求编号，claim为声明，limitation为限制。
- migration：rewrite必填。source、target、status、note；status为已映射/待确认/原样保留/不适用，覆盖所有实质性源信息。
- source_checks可选：name、table、business_key、result、sql、scope；未执行不得编数值。
- metrics可选：name、period、mart、chinese_name、english_name、algorithm，对应OneData六列。

model必填name、table、layer、domain、state、evidence（ID数组）、fields、design。未知table用null，name用明确业务对象。
可选id、schema、designer、design_date、review_required、development_status、developer、start_date、end_date、business_unit、business_process、model_type、note、summary。未知人名/日期不猜，默认待评审。

design必含下列键，未知填null，不适用写理由：
- grain：一行的含义。
- business_keys、technical_keys：字段名数组或null，无/不适用为[]，与字段标记一致。
- partition、incremental_field、update_strategy、frequency、schedule。
- joins、filters、deduplication。
- metric_rules、null_rules、history_policy。
可扩充语义键，也写入设计说明；各项细分证据/状态可在值中引用证据编号，模型总状态不能代替逐项状态。

fields按最终字段顺序，每项：
- category、subcategory、name、type、description；未知name/type可null但不能标已确认。
- technical_key、business_key：是/否/待确认/不适用。
- state、evidence：字段定义状态和证据ID，必须显式提供。
- note可选：单位、可空性、默认值、约束、原文。
- mappings至少一项。每项branch、source_table、source_field、expression、condition、state、evidence。未知来源也用null和待确认表示。
- 多来源共用一个逻辑字段；常量/系统函数也记映射，不能伪造源列。
- model.state描述整体设计状态，不覆盖字段/映射状态。已确认只表示材料支持，不代表生产验证。

## 模板限制

assets/模型设计空白模板.xlsx独立可用，保留七张附录，清除示例业务内容与旧公式。
--template仅接受同页签/列合同的干净母版。其他目标格式须实现适配并验收，不声称任意模板可直接填充。
单元格超32767字符报错；长SQL另存完整附件，在单元格引用路径与hash，不截断。
SQL/公式按文本写，不执行=AI(...)；盘点保留原公式与缓存。
inspect记录图片数量，不做OCR；有图片时按锚点提取并视觉核读，记录来源与限制。
