# 模板理解与字段规范

## 工作簿结构

来源：用户指定`.temp/品类市场趋势_链接_日.xlsx`，2026-09-16读取，共25页，含实际设计、草稿、历史示例与探查证据。页签清单及hash见assets/模板来源.json。不能把所有页都当本次模型。

| 部分 | 用途 | 生成策略 |
|---|---|---|
| 0 内容概览 | 分类与导航 | 保留入口 |
| 1.1 模型设计目录 | 一模型一行，设计/开发/特征信息 | 按范围重建，不继承作者与状态 |
| 数据源探查 | 源表、业务键、SQL、结果、范围 | 未查询写未执行，历史证据明确标注 |

| 1.3 模型实体设计模板（隐藏） | 字段母版 | 清除收藏表示例再复用 |
| 模型实体页 | 一模型一页，字段映射 | 支持一字段多来源续行 |
| 附.1～附.7（隐藏） | 业务域、数据域、分层、命名、更新后缀、实体、业务过程 | 保留为参考快照，新指定标准优先 |
| 历史广告/FBA/收藏/Sheet12 | 历史示例与操作辅助 | 不带入新文档 |

空白母版保留目录24列；实体页12列，在原11列母版J后补SQL列K，将备注移到L，兼容原扩展页。补充“设计说明”“证据与待确认”“翻写映射”（翻写时）承接额外语义。

## 目录24列

A模型编号；B所属数据域；C数据库；D数仓分层；E模型名称；F概念设计者；G设计完成日期；H是否需要评审；I当前状态；J模型设计文档；K实体开发者；L实体表名（库名.表名）；M开始时间；N完成时间；O备注；P所属业务BU；Q所属数据域；R所属业务过程；S表所属层次；T数据粒度；U分区字段；V增量字段；W更新频率；X更新时间。

- B/Q一致；C与P不能当必然同义；D为DWD等分层，S为事务事实/周期快照等类型。
- T回答一行代表什么，结合业务唯一性、JOIN倍增和指标可加性检查。
- 分区、水位、频率、调度时点是不同信息，_dd不证明几点调度。
- I待评审/待开发/开发中/已完成描述开发状态，不等于文档事实已确认。
- E/J跳实体页，返回定位实际目录行，不固定E4。
- 不继承原F1/G1以230为分母的旧进度公式。

## 实体12列

| 列 | 语义与填写规则 |
|---|---|
| A字段分类 | 主键/店铺/指标/任务执行等业务分组，按模型判断 |
| B二级分类 | 组内主题或维度/指标，不照抄错位标签 |
| C字段序号 | 最终逻辑字段顺序连续，多来源共用序号 |
| D字段名 | 真实物理字段/输出别名；代码场景不擅自改名 |
| E字段数据类型 | 同版本DDL优先，保留长度精度，推断标建议 |
| F字段描述 | 含义、单位、币种、时间粒度、累计/日均口径 |
| G参考字段 | 源列/常量/表达式，与分支逐条对应 |
| H参考库表 | 真实来源，常量不虚构源列 |
| I是否主键字段 | 技术/物理唯一键；Doris DUPLICATE KEY不证明唯一 |
| J是否业务主键 | 业务联合键成员；代理键不自动等于业务键 |
| K SQL | 映射表达式，保留CASE/窗口/聚合；过长引用完整附件 |
| L备注 | 状态/分支条件/空值/冲突/额外约束；批注引用证据ID |

UNION或多个条件来源写入同一字段mappings；多来源行合并A～F/I/J，G/H/K/L逐条展开。读取只对明确合并区继承值，普通空白结合上下文判断，不能全局向下填。

## 命名与分层快照

- cbebg跨境电商业务域、glcd公共数据；mkt市场、inv库存、trd交易、ads广告数据域。
- DWD：业务域.dwd_数据域_{子域}_业务过程或实体_{标签}_更新方式_频率。
- DWS：业务域.dws_数据域_{子域}_聚合最细粒度_{次级粒度}_{标签}_更新方式_频率。
- DMT跨域公共宽表，DMA应用，DIM维度，REF参考，CTRL配置，DWTMP任务中间态。
- ilu增量最新；flu全量最新；ich增量历史/拉链；fsn全量历史快照。
- dd每日、hh每小时、2h两小时、30min半小时、mm每月、rt实时。
- 后缀是命名意图，实际更新看写入/清理/主键/分区/调度。市场业务阈值与Keepa映射不属于通用规则。
