# 模型评审编排

## 这项技能解决什么问题

- 编排“更新标准库 -> 锁定模型设计文档 -> 识别待评审范围 -> 调用模型设计标准化”的端到端流程。
- 本 skill 只负责输入快照、范围收敛、可追溯性和跨 Skill 顺序；下载细节交给 F01，评审执行交给 E01，工作区强制门交给 B 系列。

## 先读哪些本地知识

- 先按 `workspace-spec.json` 注册表解析 `B01`、`B08`、`B04`、`B02`、`B03`、`F01`、`E01` 的当前版本。
- 判断触发、反例和跨 Skill 边界时，读 `references/编排契约.md`。
- 需要锁定输入、判断最新文件或生成待评审范围时，读 `references/输入锁定与待评审范围.md`。

## 固定动作

1. 判断是否属于本 skill：用户需要从标准库、模型设计文档来源开始，只处理“待评审”范围并完成标准化时使用；若用户只要求下载，执行 F01；若已给定标准库和模型设计 Excel 只需评审，执行 E01。
2. 执行 B01 和 B08；定位当前 `模型设计标准化` 子项目，不存在时执行 B04。
3. 正式写入 `output/` 前执行 B02，对当前 `模型设计标准化` 子项目做 PROJECT 备份。
4. 按 `references/输入锁定与待评审范围.md` 锁定标准库和模型设计文档；钉钉/阿里文档下载统一交给 F01。
5. 从锁定模型设计文档生成待评审范围工作簿，确保只有状态为 `待评审` 的实体 sheet 进入 E01。
6. 将最新标准库和待评审范围工作簿交给 E01；交付时汇总 E01 产物路径和本次锁定输入清单。
7. 结束前按 B08 写最终状态，并按 B03 写入必要记忆。

## 什么时候再读本 skill 的 references

- 对“该走 E02、F01 还是 E01”不确定时，读 `references/编排契约.md`。
- 对锁定目录、时间戳命名、最新判定、待评审 sheet 识别或异常停止口径不确定时，读 `references/输入锁定与待评审范围.md`。
- 需要下载、登录、导出或文件校验细节时，转读 F01；需要标准化运行参数、AI 决策结构或交付物解释时，转读 E01。

## 边界

- 不复制 F01 的下载工作流、登录兜底、常用链接维护规则。
- 不复制 E01 的解析、AI 决策、校验和写回脚本细节。
- 不写死 `模型设计标准化` 子项目编号或版本号。
- 不使用未锁定、无时间戳或临时下载文件作为正式标准输入。
- 不直接修改锁定的模型设计快照。
- 用户要求只评审待评审模型时，不让 E01 无差别处理全部实体 sheet。
- 不保存钉钉临时下载 URL、cookie、账号密码或其他访问凭证。
