# 输入锁定与待评审范围

## 固定落点

正式产物落到当前 `模型设计标准化` 子项目，不写死编号和版本。执行时动态定位：

```text
output/*_模型设计标准化/03_代码程序/locked_inputs/
```

目录结构：

```text
locked_inputs/
  standard_library/
    标准库_{yyyyMMddHHmmss}.xlsx
  model_designs/
    {项目短名}/
      {模型设计文档原文件名}_{yyyyMMddHHmmss}.xlsx
  review_scope/
    {项目短名}/
      {模型设计文档原文件名}_{yyyyMMddHHmmss}_待评审范围.xlsx
```

`yyyyMMddHHmmss` 使用执行时本地时间。判断最新文件只看文件名时间戳，不看文件修改时间。

## 标准库锁定

1. 标准库来源若是钉钉/阿里文档，交给 F01 下载；本 skill 只指定最终输出路径。
2. 标准库快照命名为 `标准库_{yyyyMMddHHmmss}.xlsx`。
3. 校验口径：
   - 文件存在且大小非 0。
   - `.xlsx` 能作为 zip 打开。
   - 能读取 workbook 和 sheet 列表。
   - 至少包含 `规则标准库` 和 `映射标准库`。
4. 校验失败时停止，不进入模型评审。

## 模型设计文档锁定

1. 项目短名优先取用户给定名称；没有时，从模型设计文档标题或原文件名清洗得到。
2. 钉钉/阿里文档交给 F01 下载；本地 Excel 文件复制为锁定快照。
3. 锁定快照命名为 `{模型设计文档原文件名}_{yyyyMMddHHmmss}.xlsx`。
4. 校验口径：
   - 文件存在且大小非 0。
   - 能读取 workbook 和 sheet 列表。
   - 至少包含 `1.1 模型设计目录`。
   - 至少存在一个可见实体设计 sheet，且表头同时包含 `字段名` 和 `字段描述`。
5. 锁定快照不直接修改；后续范围筛选必须生成新的待评审范围工作簿。

## 待评审识别

从锁定模型设计文档的 `1.1 模型设计目录` 识别待评审模型：

1. 优先识别列名：`模型编号`、`模型名称`、`实体表名`、`sheet 名称`、`工作表链接`、`状态`、`评审状态`、`模型状态`。
2. 状态列名称不固定时，优先选择列名包含 `状态` 或 `评审` 的列。
3. 状态值精确等于 `待评审` 的行进入本次范围。
4. 待评审行到实体 sheet 的映射优先级：
   - 目录页工作表超链接。
   - 明确的 sheet 名称列。
   - 模型名称或实体表名与 workbook sheet 名一致性匹配。
5. 目标 sheet 必须存在，并包含 `字段名` 和 `字段描述` 表头。

## 范围工作簿

待评审范围工作簿从锁定模型设计文档复制生成：

- 保留 `1.1 模型设计目录` 和 `1.2 模型依赖说明（数据流）`。
- 只让待评审实体 sheet 进入 E01 处理范围。
- 若 E01 当前没有 sheet 白名单参数，通过隐藏非待评审实体 sheet 控制范围。
- 不删除原始信息；如确需删除无关 sheet，必须保留锁定快照可追溯。

## 停止口径

遇到以下情况停止并向用户报告，不猜测继续：

- 标准库缺少 `规则标准库` 或 `映射标准库`。
- 模型设计文档缺少 `1.1 模型设计目录`。
- 找不到状态列。
- 没有状态为 `待评审` 的模型。
- 待评审行无法映射到实体 sheet。
- 目标 sheet 缺少 `字段名` 或 `字段描述`。

## 最小验收

一次 E02 编排至少满足：

- 标准库、模型设计文档和待评审范围工作簿都有时间戳快照。
- 最新标准和最新模型设计可由文件名时间戳唯一确定。
- E01 解析出的实体 sheet 与待评审 sheet 清单一致。
- E01 运行目录中保留输入清单、解析产物、AI 决策、校验报告和交付物。
