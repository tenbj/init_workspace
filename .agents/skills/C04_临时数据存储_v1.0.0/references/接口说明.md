# 接口说明

## `DorisStorageClient()`

连接环境变量配置的 Doris 测试集群，默认使用 `test` 库，Read/Write 权限。

---

## `execute(sql, params=None) → int`

执行单条 DDL 或 DML，返回影响行数。

```python
# 建表
storage.execute("""
    CREATE TABLE IF NOT EXISTS test.temp_result (
        id    INT,
        label VARCHAR(100)
    ) DISTRIBUTED BY HASH(id) BUCKETS 1
    PROPERTIES('replication_num' = '1')
""")

# 插入单行
storage.execute(
    "INSERT INTO test.temp_result VALUES (%s, %s)",
    params=(1, "hello")
)
```

## `execute_many(sql, params_list) → int`

批量执行同一条 DML，返回总影响行数。适合一次性写入大量行。

```python
rows = [(1, "a"), (2, "b"), (3, "c")]
storage.execute_many(
    "INSERT INTO test.temp_result VALUES (%s, %s)",
    params_list=rows
)
```
