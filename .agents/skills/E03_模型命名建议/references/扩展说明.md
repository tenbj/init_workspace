# 模型命名建议执行细则

## 输入与输出

- 输入 1：标准库 Excel，来自用户本轮指定路径。
- 输入 2：模型设计 Excel，来自用户本轮指定路径。
- 输出：模型设计 Excel 的副本，默认 `{原文件名}_命名建议.xlsx`。
- 原文件只读；输出文件已存在时，优先加时间戳后缀，不静默覆盖。

## Excel 定位口径

- 表名默认读取每个模型 sheet 的 `A1` 单元格。
- 字段区优先在前 50 行查找字段名列，常见表头包括 `字段名`、`字段英文名`、`英文名`、`字段编码`。
- 推荐列必须放在字段名列右侧，列名固定为 `推荐字段名`。
- 备注列优先识别 `备注`、`说明`、`字段说明`、`描述`；不存在时在末尾新增 `备注`。
- 第一个字段行指字段表头后第一行有效字段记录；推荐表名写入该行备注单元格，格式为 `推荐表名：xxx`。

## 推荐依据

AI 推荐字段名时按以下证据综合判断：

- 标准库中的标准字段名、中文名、别名、业务定义、数据类型、主题域和历史命名习惯。
- 模型设计文档中的当前字段名、字段中文名、字段说明、数据类型、枚举标识、是否保留、是否删除、来源/计算逻辑等上下文。
- 同一张表内其他字段的命名风格和业务粒度。
- A1 表名、sheet 名和字段集合共同表达的模型主题。

若标准库强匹配，优先沿用标准库命名；若只有语义近似，给出最稳妥的英文 snake_case 建议；若证据不足，写 `待确认`，不要编造强结论。

## AI 决策 JSON

写回脚本接受下面的结构：

```json
{
  "sheets": [
    {
      "sheet": "实体Sheet名",
      "recommended_table_name": "ads_example_table",
      "fields": [
        {
          "row": 8,
          "current_field_name": "原字段名",
          "recommended_field_name": "recommended_field_name"
        }
      ]
    }
  ]
}
```

字段推荐优先按 `row` 写回；没有 `row` 时按 `current_field_name` 匹配。只写 `推荐字段名`，不写原因列。

## 脚本命令

抽取上下文：

```powershell
python ".agents\skills\E03_模型命名建议\scripts\model_naming_workbook.py" extract `
  --standard-lib "input\标准库.xlsx" `
  --model "input\模型设计.xlsx" `
  --out ".temp\model_naming_context.json"
```

写回推荐：

```powershell
python ".agents\skills\E03_模型命名建议\scripts\model_naming_workbook.py" write `
  --model "input\模型设计.xlsx" `
  --recommendations ".temp\recommendations.json" `
  --output "input\模型设计_命名建议.xlsx"
```

## 异常处理

- 标准库过大时，优先读取与表名、字段中文名、主题域相关的 sheet 或筛选后片段。
- 多个 sheet 都有 A1 和字段区时，逐 sheet 处理。
- 找不到字段名列时停止写回，报告需要用户确认字段列，不猜测整列。
- 模型设计是 `.xls` 时，先转换为 `.xlsx` 后再执行脚本。
