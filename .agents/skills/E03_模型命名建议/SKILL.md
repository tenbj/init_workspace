# E03_模型命名建议

## 这项技能解决什么问题

- 按标准库及全部字段上下文给出具体命名建议与中文依据，写入模型Excel副本。
- 不覆盖原字段；保留A1原表名并追加推荐，输出含标准原表、规则及映射建议。

## 先读哪些本地知识

- 先读 `references/本地接入.md` 和两个实际输入Excel。
- 决策前必读 `references/命名决策与写回.md`，完整保留1.5.2的决策顺序和质量门。
- 模板识别、JSON与参数细节见 `references/扩展说明.md`。

## 固定动作

1. 按B04定位output子项目，保存输入引用或快照；输出命名为原文件名加“_命名建议.xlsx”，不覆盖原文件，也不向input写结果。
2. 运行extract，完整读取context.json的标准规则、standard_sheets[*].records及所有模型字段。
3. AI按同当前字段名复用→合规DWD参考字段→标准语义顺序决策；给出具体推荐名、rename/keep和中文依据，不能用待确认或空候选代替。
4. 执行长token、同名一致性、代理主键等规则，生成recommendations.json与可沉淀的新标准建议。历史决策只在输入哈希和版本等条件一致且本轮重验时可参考。
5. 运行write及标准库参数，先生成quality_report.md并通过覆盖率、决策完整性、中文依据及标准映射anti-join质量门，才写副本。
6. 检查原字段与A1被保留、推荐列和建议sheet齐全；交付Excel与必要质量报告。

## 什么时候再读本 skill 的 references

- 所有推荐与写回的硬约束：`references/命名决策与写回.md`。
- 输入识别、JSON示例、脚本接口与异常：`references/扩展说明.md`。

## 边界

- AI负责逐字段语义判断，脚本负责抽取、校验和写回，不把历史静态表当作本轮决策。
- 推荐优先最小必要修改和短词根，标准允许的长词根要有依据；映射建议只包含真正新增且可复制词条。
- 不生成E01完整审计run，不擅自落地字段删除或重命名。
