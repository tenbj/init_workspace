# E03_模型命名建议

## 这项技能解决什么问题

- 用于只做“命名建议”的轻量模型标准化：输入一个标准库 Excel 和一个模型设计 Excel，复制出新的模型设计文档。
- 在模型设计文档的字段名列后新增 `推荐字段名`，按标准库和字段上下文给出建议；表名默认取 A1，推荐表名写入第一个字段的备注中。
- 适合快速评审命名，不生成 E01 那种完整运行目录、批次、评审清单和标准缺口沉淀。

## 先读哪些本地知识

- 先读用户给出的标准库 Excel 和模型设计 Excel；不要默认使用 E01 的运行目录协议。
- 需要字段识别、推荐 JSON 和 Excel 写回细节时，再读 `references/扩展说明.md`。

## 固定动作

1. 确认两个输入文件：标准库 Excel、模型设计 Excel；输出默认放在模型设计文件同目录，命名为 `{原文件名}_命名建议.xlsx`，不得覆盖原文件。
2. 运行 `scripts/model_naming_workbook.py extract` 抽取模型和标准库上下文；若脚本无法识别模板，再按 `references/扩展说明.md` 手动定位字段名列、备注列和字段行。
3. AI 根据标准库、表上下文、字段中文名、字段描述、类型、枚举/保留/删除等信息生成字段名和表名推荐，只给推荐命名，不改原字段名。
4. 将 AI 决策写成 `recommendations.json` 后运行 `scripts/model_naming_workbook.py write`，复制模型设计文档并写入 `推荐字段名` 列；推荐表名写入第一个字段的备注单元格。
5. 最终只向用户交付新的模型设计 Excel 路径；如存在无法判断的字段，在对应 `推荐字段名` 单元格写 `待确认`。

## 什么时候再读本 skill 的 references

- 不确定 Excel 模板识别、推荐依据优先级、JSON 结构、脚本参数或异常处理时，读 `references/扩展说明.md`。

## 边界

- 不覆盖原模型设计文档，不直接改写现有字段名和 A1 表名。
- 不生成完整审计 run 目录、不维护标准缺口清单、不做字段删除/保留落地；这些属于 E01。
- 不把标准库匹配写成硬编码规则库；语义判断由 AI 基于本次输入完成。
