# 钉钉文档下载工作流

本文件处理脚本之外的流程判断、登录、重试、兜底和校验。脚本命令本身见 `脚本使用说明.md`。

## 默认输入

| 字段 | 说明 |
|------|------|
| 源文档 | 用户给出的钉钉/阿里文档链接，或 `常用链接.md` 中的标记名称 |
| 输出文件 | 用户指定路径优先；未指定时必须落到当前 `output/` 子项目 |
| Chrome profile | 默认用 `.temp/F01/alidocs-chrome-profile/` 复用登录态；需隔离时放到当前子项目 `03_代码程序/browser-profile/` |
| 目标格式 | 在线表格默认 `.xlsx`，其他格式按用户要求和页面导出能力选择 |

## 最短执行路径

1. 用户给标记名时，先在 `常用链接.md` 查到文档类型和默认文件名。
2. 确认当前 `output/` 子项目；没有则执行 B04 创建或定位。
3. 写入既有子项目成果前执行 B02；若只写 `.temp/` profile，不需要对 output 做备份。
4. 建好 `03_代码程序/downloads/`。
5. 按 `脚本使用说明.md` 运行 Python 主入口，并显式传入 `--download-dir`、`--output`、`--profile-dir`。
6. 首次登录时让用户在可见 Chrome 中完成登录，然后回命令行继续。
7. 脚本完成后读取输出：确认 `Saved:`、`Bytes:`、`Sheets:`；必要时再执行 `--validate-only`。

## 默认落盘策略

1. 用户明确给出输出路径时，按用户路径保存。
2. 用户未给出输出路径，但当前任务已经绑定某个 `output/<子项目>_v*` 时，保存到该子项目。
3. 当前任务没有绑定子项目时，先执行 B04：按文档用途创建或定位一个中文主题子项目，再保存文件。
4. 子项目内默认路径为：

```text
output/<当前子项目>/03_代码程序/downloads/<文档标记或标题>.xlsx
```

5. 浏览器登录态不是成果文件，默认路径为：

```text
.temp/F01/alidocs-chrome-profile/
```

6. 只有用户要求按项目隔离登录态时，才改用：

```text
output/<当前子项目>/03_代码程序/browser-profile/
```

7. `scripts/alidocs-downloader/config/docs.json` 中的 `downloadDir` 和 `chromeProfileDir` 只是脚本自带兼容默认值；正式执行时优先通过命令参数显式覆盖。
8. 不把测试目录、临时项目目录或上一次执行目录写成长期默认值。

## 脚本失败后的浏览器流程

1. 打开源文档，判断是否进入登录页、授权页或文档编辑页。
2. 如需登录，启动独立可见 Chrome profile，并开启 Chrome DevTools Protocol 调试端口。
3. 请用户在可见窗口中完成扫码、授权或账号登录；不要索要账号密码。
4. 登录后只保留该 profile 内的 cookies/session，不导出明文凭证。
5. 连接调试端口，确认页面已经进入文档编辑页，而不是停留在登录页。
6. 读取页面可见文本和菜单结构，定位导出路径。
7. 触发导出后监听下载事件，确认下载文件名、保存路径和完成状态。
8. 下载完成后执行文件校验，并在需要时把输出文件登记到子项目 `目录.md` 的 `03_代码程序` 分节。

## 重试策略

1. 每次重新尝试导出前，先刷新页面，等待文档编辑页稳定。
2. 不只依赖 `document.readyState=complete`；还要确认工具栏“菜单”已可见、坐标连续稳定，并额外等待数秒让表格应用完成初始化。
3. 不在旧菜单、二级菜单或弹层残留状态下继续点击；否则第一下点击可能只是关闭旧浮层。
4. 刷新后重新执行完整菜单链路：`菜单 -> 表格 -> 下载为 -> Excel (.xlsx，表格整体)`。
5. 优先用页面可见文本重新定位菜单项坐标，不依赖上一次的固定坐标。

## 在线表格导出路径

钉钉在线表格常见导出路径：

```text
菜单 -> 表格 -> 下载为 -> Excel (.xlsx，表格整体)
```

如果菜单文案或层级发生变化，先读取页面可见文本，再按“下载为”“导出”“Excel”“表格整体”等关键词定位，不要凭旧坐标硬点。

## 下载失败兜底

- Chrome 下载面板失败、卡住或 canceled，不代表钉钉导出失败。
- 若页面已经生成导出文件，调试事件里通常会出现 `Browser.downloadWillBegin`。
- 从该事件中拿到真实临时下载 URL 后，应立即用命令行请求并保存到目标路径。
- 临时 URL 通常带签名和过期时间，只能用于本次下载，不写入长期文档或常用链接。

## 文件校验

1. 文件存在且大小非 0。
2. `.xlsx` 文件能作为 zip 打开，并能读取 `xl/workbook.xml`。
3. 能读取工作表名称。
4. 能读取实际行列和关键内容。
5. 若普通读取工具误判只有 `A1`，检查 XML 中的真实单元格，或重置 worksheet dimension 后再读取。

## 安全原则

- 可以保存浏览器会话目录，方便下次免登录。
- 浏览器 profile 会包含登录会话状态，不应提交、发布或分享给无关人员。
- 不保存、不索要、不导出用户账号密码。
- 不长期保存临时下载链接、cookies 明文或其他可复用访问凭证。
