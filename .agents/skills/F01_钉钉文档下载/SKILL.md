# 钉钉文档下载

## 这项技能解决什么问题

- 下载需要登录态的钉钉/阿里文档、在线表格，并保存为本地文件。
- 优先用本 skill 自带脚本完成打开文档、触发导出、捕获临时下载地址、保存和校验。
- 支持用户直接给链接，也支持使用 `references/常用链接.md` 中登记的常用文档标记。

## 先读哪些本地知识

- 用户给出“标准库”等已登记标记时，先读 `references/常用链接.md`。
- 只要准备运行脚本，必须读 `references/脚本使用说明.md`，不要先翻脚本源码。
- 需要人工登录、菜单导出失败、下载事件失败或文件校验异常时，再读 `references/下载工作流.md`。
- 需要新增常用文档链接时，追加到 `references/常用链接.md`，不要把链接堆回 `SKILL.md`。

## 固定动作

1. 确认源文档：优先解析用户给出的常用标记；未登记链接按一次性文档处理。
2. 确认目标：输出文件必须落到用户指定路径，或当前 `output/` 子项目的 `03_代码程序/downloads/`；没有当前子项目时先执行 B04。
3. 修改既有 `output/` 子项目前，先执行 B02；若只是写 `.temp/` 中的浏览器 profile，不算成果文件。
4. 优先执行 `references/脚本使用说明.md` 的 Python 主入口；显式传入 `--output`、`--download-dir`、`--profile-dir`，减少路径猜测和重复登录。
5. 首次运行若脚本打开登录页，请用户在可见 Chrome 中完成扫码、授权或登录；登录后回到命令行继续。
6. 下载完成后必须校验：文件存在、非 0、`.xlsx` 可打开、工作表名称和行列范围符合预期。
7. 脚本无法定位菜单、下载事件或文件校验失败时，按 `references/下载工作流.md` 的人工浏览器兜底流程处理。

## 什么时候再读本 skill 的 references

- 查找或维护常用文档来源：读 `references/常用链接.md`。
- 运行脚本、选择 Python/Node/PowerShell 入口、理解参数和输出：读 `references/脚本使用说明.md`。
- 处理登录、重试、菜单变更、下载失败、临时 URL 兜底和校验异常：读 `references/下载工作流.md`。

## 边界

- 不索要、不保存、不导出用户账号密码；只允许复用浏览器 profile 中的会话状态。
- 不保存带签名和过期时间的临时下载 URL；只在本次下载兜底中即时使用。
- 不绕过钉钉/阿里文档访问控制；无权限时请用户授权或登录。
- 不把浏览器 profile、cookies、临时下载 URL 写入 `output/` 正式文档或常用链接。
- 未经用户要求，不修改 `references/常用链接.md`。
