# 八类验证清单

开发开始即准备检查项和样例，与用户对齐适用性；不要求每张表包含所有字段。区分真实源记录与合成输入。结论标记通过、失败、未执行、不适用，附范围和时间。

| 类别 | 必查事项 | 代表案例和预期 |
|---|---|---|
| 1 时间周期 | 报表年与自然年、周期类型、起止日、周/月/季边界、来源原文、增量时间与业务时间、时区 | 跨年周按来源确认口径；闰日、空日期、端点当天末秒不漏 |
| 2 店铺站点账号 | 身份组合、国家/站点映射、平台、历史停用、空身份、一对多、关联前后行数 | 同账号不同站点不合并；映射重复不扩行；未映射保留/排除须有口径 |
| 3 MSKU | 是否SKU粒度、ASIN映射、空值、大小写、组合SKU和跨店复用 | 同ASIN多MSKU符合粒度；品牌确无MSKU则注明不适用及依据 |
| 4 排名 | 源值或重算、整数、空串/NULL/零/负数/小数、并列、排序范围 | 同周期同排名不同关键词检查冲突；不强制源排名连续 |
| 5 关键词 | 原文或规范化、空串/空白、大小写、非ASCII、引号/符号、截断、作为键的口径 | a-b与ab按确认规则；不去符号合并合法词 |
| 6 比例 | 各源单位和类型、0—1与0—100、真实百分号、精度、NULL与零、异常边界 | 34→0.34仅适用百分数单位；原本0.34比例应保留；超界不自动截断 |
| 7 时间审计 | 创建/更新/采集、COALESCE顺序、写入时间、首次时间重置、时区 | NULL更新时间备用；业务值重跑稳定但NOW变化；说明首次字段真实含义 |
| 8 主键与范围键 | 粒度、技术键、NULL、重复、来源优先级、稳定排序、哈希输入、DELETE覆盖 | 同键优先按确认口径；scope_info复算；成员减少删除旧尾部 |

## 跨类别验收

- 建表字段、INSERT 显式列、SELECT 投影及 Excel 的数量、顺序、名称和类型一致；字段说明包含单位、键、来源和审计语义。
- 时间窗口边界、空窗口、首次全范围、历史回读、幂等重跑、删除成功插入失败后的恢复。
- 关联和去重各节点行数；重复、多源相交、仅单源覆盖分别验证。
- 代表行能逐层解释；新旧差异按业务键定位，不能仅总行数相同就通过。
- 源遗留、未知口径及生产写入未执行情况写入说明；只读通过不等于装载通过。
- Doris 实体表按 [实体表分册](Doris实体表设计与实跑验收.md) 核验结果行数/业务键组数/MD5去重数、主键模型预计丢行数；decimal转换的范围、NULL及舍入；仅实体主键非空；三审计字段及真正需要的CAST。
- 最终版本从正式INSERT提取完整查询并实跑全部投影列；记录参数、哈希、行列、耗时、错误、客户端上限及范围是否完整，不以汇总或旧版证据冒充当前全字段查询验收。
