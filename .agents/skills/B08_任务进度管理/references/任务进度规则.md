# 任务进度规则

## 目录结构

```text
.memory/
  任务进度/
    索引.md
    进行中/
    已完成/
    已取消/
```

`索引.md` 是恢复入口。`进行中/` 中保存 `ACTIVE / PAUSED / BLOCKED / REVIEW / STALE` 任务，完成或取消后移入对应历史目录。

## 状态机

| 状态 | 含义 | 默认动作 |
|------|------|----------|
| ACTIVE | 正在执行 | 继续推进 |
| PAUSED | 主动暂停或等待确认 | 读恢复卡片后继续或询问 |
| BLOCKED | 外部阻塞 | 先处理阻塞项 |
| REVIEW | 主体已完成，待验证或审阅 | 运行验证或交付确认 |
| DONE | 已完成并归档 | 不再默认恢复 |
| CANCELED | 用户取消 | 不再继续 |
| STALE | 长期未更新，需重新判断 | 先确认是否继续 |

## 必写时机

1. 任务开始后，完成目标理解和归属判断时。
2. B02 备份完成后，记录安全点、历史快照和新的 live 路径。
3. 修改 live 文件前，记录计划改什么以及原因。
4. 修改 live 文件后，记录实际变更、涉及文件和下一步验证。
5. 关键命令完成后，记录目的、结果摘要和是否阻塞。
6. 暂停、阻塞、等待用户确认时，立刻写 `PAUSED` 或 `BLOCKED`。
7. 最终回复前，写入完成状态、产物和后续建议。
8. 任务完成后，执行 `Close` 并更新索引。

## 脚本动作

```powershell
powershell -ExecutionPolicy Bypass -File ".agents\skills\B08_任务进度管理\scripts\task_progress.ps1" `
  -Action Start `
  -Title "任务进度管理体系" `
  -Goal "实现可恢复任务进度层" `
  -Next "备份并修改标准、入口、B01 和 B08"
```

```powershell
powershell -ExecutionPolicy Bypass -File ".agents\skills\B08_任务进度管理\scripts\task_progress.ps1" `
  -Action Checkpoint `
  -TaskId "T20260511-2130-任务进度管理体系" `
  -Message "B02 备份完成，准备修改标准和脚本"
```

```powershell
powershell -ExecutionPolicy Bypass -File ".agents\skills\B08_任务进度管理\scripts\task_progress.ps1" `
  -Action UpdateNext `
  -TaskId "T20260511-2130-任务进度管理体系" `
  -Next "运行 B01 验证新增检查项"
```

```powershell
powershell -ExecutionPolicy Bypass -File ".agents\skills\B08_任务进度管理\scripts\task_progress.ps1" `
  -Action Pause `
  -TaskId "T20260511-2130-任务进度管理体系" `
  -Reason "等待用户确认"
```

```powershell
powershell -ExecutionPolicy Bypass -File ".agents\skills\B08_任务进度管理\scripts\task_progress.ps1" `
  -Action Close `
  -TaskId "T20260511-2130-任务进度管理体系" `
  -Result "已完成最小可用任务进度层"
```

```powershell
powershell -ExecutionPolicy Bypass -File ".agents\skills\B08_任务进度管理\scripts\task_progress.ps1" -Action Resume
```

## 手动修复原则

- 只在脚本不可用时手动修复 `索引.md`。
- 进行中任务文件必须能从 `索引.md` 找到。
- `索引.md` 不承载详细日志，只保留恢复入口。
- 完成或取消的任务不继续列入当前任务表。
