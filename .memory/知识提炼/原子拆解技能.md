## 2026-05-11 · atomic-decomposition-skill 项目理解

**核心观点**：
- `atomic-decomposition` 的本质是 Codex Skill 形式的问题拆解器，不是直接建议模板。
- 它把混乱表达分离为事实、感受、判断、假设、目标、约束、行动意图、内容/商业意图和风险信号。
- 它用 P0-P4 保证安全与基础稳定优先于内容输出和商业化。

**关键框架/模型**：
- 原始混沌表述 → 层级拆解 → 原子课题 → 可验证假设 → 最小实验 → 内容选题 → 复盘指标。
- 每个原子课题只能研究一个变量或一个因果关系。
- 低能量用户的执行计划应分为最低配、标准配、满血配，避免过载。

**与其他话题的关联**：
- 减脂内容计划：原子拆解技能可作为把减脂、身体恢复和小红书记录拆成可执行课题的上游方法。
- Skills管理体系：该项目是一个可迁移、薄结构、含脚本与模板的 Skill 示例。
